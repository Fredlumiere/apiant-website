Sincronização de compras item por item do Mindbody para o Klaviyo para vendas adicionais de alto valor.

Por que um único campo de venda acaba com a lógica de upsell

Pacotes de bem-estar de alto valor não são um único produto. Um pacote de retiro de doze semanas, no valor de US$ 6.200, geralmente inclui acomodação básica, plano de refeições, aulas diárias, um pacote de sessões particulares e um adicional opcional (banho de som, créditos para massagem, sessão individual com um coach). Cada item dessa fatura representa uma oportunidade de venda adicional, venda cruzada e renovação.

O problema começa quando seu CRM só vê o valor total do pedido. Exemplo hipotético: o Silver Fern Wellness Retreat (ilusório) vende pacotes de US$ 4.000 a US$ 8.000 em turmas recorrentes de doze semanas. O Klaviyo, sem nenhuma alteração, consegue ver que um cliente pagou US$ 5.800 na última terça-feira. O Klaviyo não consegue ver que o pacote incluía três créditos de massagem e nenhuma sessão de coaching individual. Assim, o fluxo pós-compra ou dispara ofertas genéricas de upsell (incomodando metade dos compradores que já compraram o que está sendo oferecido), ou não dispara de jeito nenhum.

O que as ferramentas prontas para uso não oferecem

A carga útil de uma venda no Mindbody inclui itens de linha, mas a maioria das ferramentas genéricas de integração consolida a venda em uma única linha antes de chegar ao Klaviyo. O motivo geralmente está na modelagem de dados: o evento "Pedido Realizado" do Klaviyo espera uma matriz de itens, e integrar corretamente a carga útil de venda aninhada do Mindbody a essa matriz (com SKUs, preços e tags de categoria adequados) é o tipo de trabalho que é eliminado em um "Zap rápido". O resultado é um pedido de uma única linha no Klaviyo, sem itens de linha, sem visibilidade de complementos e sem cálculos de upsell.

A abordagem APIANT

CRMConnect Mindbody para Klaviyo inclui Sincronização de itens de compra e venda como um recurso de primeira classe. Os dados de vendas fluem do Mindbody para o Klaviyo com cada item intacto, de modo que o perfil e a carga útil do evento do Klaviyo mantêm a estrutura intacta para segmentação e lógica de fluxo.

O mecanismo unificado de processamento de dados do APIANT é agnóstico em relação ao formato. A carga útil de vendas do Mindbody é mapeada por meio de XPath (um padrão aberto da W3C) para o esquema de eventos do Klaviyo sem perda de aninhamento. Cada item de linha possui seu próprio SKU, preço, categoria e quantidade. Essa é a parte que torna possível a lógica de upsell.

Três funcionalidades do aplicativo API são cruciais aqui:

  • Sincronização de itens de compra e venda para a lista de itens estruturada.
  • Sincronização de perfil de cliente em tempo real Assim, o perfil do comprador está atualizado e pode ser segmentado.
  • Rastreamento de visitas Assim, o acompanhamento pós-compra pode ser direcionado dependendo se o cliente realmente começou a usar o produto que comprou.

Como funciona a sincronização de itens individuais no Klaviyo

A compra de um pacote de retiro é registrada no Klaviyo como um evento estruturado. O formato é aproximadamente o seguinte:

{
  "event": "Placed Order",
  "customer_properties": {
    "$email": "client@example.com",
    "mindbody_client_id": "MB-44918"
  },
  "properties": {
    "OrderId": "MB-INV-71204",
    "Total": 5800.00,
    "Currency": "USD",
    "Items": [
      { "SKU": "RETREAT-12W-DLX", "Name": "12-Week Deluxe Package", "Price": 4200, "Category": "Retreat Base" },
      { "SKU": "MEAL-VEG-12W", "Name": "Vegetarian Meal Plan", "Price": 800, "Category": "Meal Plan" },
      { "SKU": "MASSAGE-CR-3", "Name": "Massage Credits x3", "Price": 450, "Category": "Add-On" },
      { "SKU": "SOUND-BATH-1", "Name": "Sound Bath Session", "Price": 350, "Category": "Add-On" }
    ]
  }
}

Agora, a Klaviyo pode segmentar por "comprou um pacote de 12 semanas sem acompanhamento individual", ou "comprou um plano alimentar, mas sem complementos", ou "gastou mais de US$ 5.000, mas não utilizou nenhum crédito de massagem".

Criando ofertas adicionais para pacotes de alto valor

O fluxo de upsell possui três gatilhos, cada um vinculado ao que é ausente a partir dos itens da lista:

  1. Não foi contratado nenhum serviço de coaching particular. Três dias após o início do retiro, envie um e-mail oferecendo um desconto em uma sessão introdutória individual com um coach sênior. Suprima qualquer pessoa cujos itens de linha já incluam um código SKU de coaching.
  2. Plano de refeições adquirido, sem adicionais. Após sete dias, envie um e-mail com a pergunta "Você sabia?" sobre os créditos para banho de som e massagem, com preço especial para o pacote.
  3. Pacotes adicionais adquiridos, mas nenhuma reserva de aula agendada para os próximos 14 dias. Envie um e-mail de reengajamento com uma programação personalizada.

Cada filial lê os itens já presentes no perfil. Ninguém é pressionado a comprar algo que já adquiriu. Só isso já é suficiente para evitar que seus clientes de alto valor cancelem a assinatura.

Acumulando recompensas de fidelidade em compras repetidas

O segundo fluxo utiliza os mesmos dados, porém em um intervalo de tempo maior. Use os itens de linha para calcular o valor vitalício por categoria:

  • Gastos totais em massagens acima de US$ 1.500 ao longo da vida: convite para o nível "fundadores" com prioridade na reserva.
  • Dois retiros completos em doze meses: plano de refeições gratuito no terceiro retiro.
  • Um retiro mais quatro extras: acione um pedido de indicação com um código personalizado.

Os cálculos são executados no Klaviyo usando o Items matriz em cada evento de "Pedido Realizado". A integração apenas mantém a matriz precisa.

Aumento representativo do AOV em pacotes de US$ 4 mil a US$ 8 mil

Imagens ilustrativas, não um cliente real:

  • Taxa de adesão de complementos (e-mail genérico pós-compra): aproximadamente de 8 a 12%.
  • Taxa de adesão a produtos adicionais com upsells que reconhecem itens específicos: um aumento para a faixa de 20 a 28%, principalmente porque a oferta certa chega ao comprador certo.
  • Valor médio de aquisição (AOV) por inscrição no retiro: um aumento de 6 a 11% em grupos representativos.
  • Taxa de cancelamento de inscrição no fluxo pós-compra: menor, porque a lógica de supressão impede o problema de "estarmos tentando vender algo que você já comprou".

Esses mecanismos são acionados por mecanismos, não por mágica. Os itens de linha possibilitam o direcionamento preciso. O direcionamento preciso impulsiona o elevador.

Para levar para o construtor

  • Insista na sincronização item por item entre o Mindbody e o Klaviyo. O total agregado do pedido é um beco sem saída de marketing em faixas de preço elevadas.
  • Construa sua lógica de upsell com base no que é ausente a partir da lista de itens. É aí que reside o próximo passo comprável.
  • Use o gasto vitalício por categoria (massagem, coaching, refeições) para definir os níveis de fidelidade. A receita total é um indicador muito genérico para um negócio de retiros com pacotes.
