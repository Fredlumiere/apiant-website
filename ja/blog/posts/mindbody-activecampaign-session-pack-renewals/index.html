セッションパック数が3を下回ったときにActiveCampaignの更新メールを送信する

Fred Lumiere 2025年4月15日 5分で読める
#フィットネス＆ウェルネス#心身#アクティブキャンペーン#CRMConnect#双方向同期

クラスパックやセッションパックは、フィットネスCRMにおいて不遇な存在だ。会員制は自動支払いで、ドロップインは明らかに単発利用だ。パックはその中間で、中途半端な位置づけだ。顧客は10回分のセッションを購入し、週1回のペースで利用していく。そして8回目のセッションあたりで、トレーナーは「更新の話し合い」をすることになっている。しかし、半分のケースではトレーナーが忘れてしまう。残りの半分では、トレーナーが2回分遅れて思い出し、顧客は3週間の休止期間を経て、それが無期限の休止期間になってしまう。

仮説：ノースリッジ・ストレングス（例示）は、6人のトレーナーと180人のセッションパック利用者を抱える単一拠点のパーソナルトレーニングスタジオです。同社は手動監査を実施したところ、パック利用者の約22％が前回のパックを失効させ、更新していないことが判明しました。これらの利用者のほとんどは、意識的に辞めることを決めたわけではなく、トレーニングのリズムが崩れたために来なくなっただけでした。

トレーナーたちは怠けていたわけではありません。彼らはクライアントへのコーチングと契約更新管理システムの運用を両立させようとしていただけです。その役割は、トレーナー1人あたり約30人以上のクライアントを担当する規模には対応しきれません。

CRMConnectが毎晩同期する内容

CRMConnect Mindbody から ActiveCampaign は 残りのセッションとパックの状態 ActiveCampaignの連絡先情報は継続的に更新されます。アプリページには、「各クライアントの会員ステータス、有効期限、残りのセッションを自動的に追跡し、更新やアップセルを簡単に管理できます。」と記載されています。プロフィール、予約、訪問情報は即座に同期されます。予約と販売パイプラインは15分ごとに更新され、日々の訪問情報は1日1回照合されます。

各連絡先の関連フィールドは自動的に入力されます。

  • remaining_sessions （整数値、訪問ごとに更新）
  • pricing_option_name （例：「10パックパーソナルトレーニング」）
  • pricing_option_expiration_date
  • last_visit_date, last_visit_staff, last_visit_service
  • membership_status （有効、期限切れ、停止中など）
  • total_visits

なぜなら remaining_sessions Mindbodyへのアクセス後、数秒以内に更新されるため、アンケートに基づく推定値ではなく、正確な閾値に基づいて自動化を構築できます。

ActiveCampaignにおける典型的なパッククライアントレコードは次のようになります。

{
  "email": "client@example.com",
  "pricing_option_name": "10-Pack Personal Training",
  "remaining_sessions": 2,
  "pricing_option_expiration_date": "2026-06-30",
  "last_visit_date": "2026-05-16",
  "last_visit_staff": "Mira",
  "membership_status": "Active",
  "total_visits": 38
}

ActiveCampaignでしきい値自動化を構築する

ActiveCampaign（条件付きロジックにはPlus以上が必要）で、登録済みのオートメーションを1つ構築します。 remaining_sessions drops below 3 AND membership_status = Active.

連絡1：当日夕方。 トレーナーからのテキストメッセージのような短いメール。「[名前]さん、[料金プラン名]の残りセッション数は[remaining_sessions]です。1週間休まないように、次のパックをアカウントにドロップしましょうか？」送信者をパーソナライズして last_visit_staff だから個人的な内容として読めるのだ。

タッチ2：48時間後 remaining_sessions は依然として0より大きく、変化していません。 ワンクリック更新リンクで、やや強めの促し。

タッチ3：最終セッションと同日。 「本日最後のお客様です。[予約時間]にお会いしましょう。」 next_scheduled_appointment このメールが重要なのは、対面での更新に関する会話を自然なものにするからです。トレーナーはクライアントが更新に関するメールを受け取ったことを知っているので、対面での更新依頼が気まずくなくなります。

タッチ4：新しいパックを購入していない場合、パックの有効期限から3日後。 ソフトな再エンゲージメント、場合によっては少額のボーナスセッションの提供など。

レイヤー1の安全性：もし last_visit_date is more than 14 days ago1～3回目の接触はスキップして、直接顧客再獲得に取り掛かりましょう。すでに離れつつある顧客には、更新提案は効果がありません。まずは顧客の習慣を再構築する必要があります。

トレーナーごとにオファーをパーソナライズする

あまり活用されていないテクニックの一つとして、更新メールはスタジオ名ではなくトレーナー名で送るべきだという点があります。クライアントは「ノースリッジ・ストレングス」ではなく、ミラやトマスといったトレーナー個人と関係を築いているのです。

トレーナーごとのメールテンプレートを作成し、ActiveCampaignの動的コンテンツルールをキーとして使用します。 last_visit_staff各トレーナーには、それぞれ独自の紹介者名、署名、そして理想的には独自の特典オファー（「新しいパックの初回セッションは無料です」など）が設定されます。トレーナーは何もする必要はありません。すべて自動化システムが処理します。

CRMConnectがActiveCampaignに作成するMindbody予約パイプライン（アプリページの説明：「ActiveCampaignにライブ予約パイプラインを自動的に作成し、予約状況、スケジュール変更、残りのセッションを明確に追跡します」）は、スタジオマネージャーに、パックの有効期限が近づいている顧客を週単位で分かりやすく表示します。マネージャーはパターンを把握できます。「ミラの顧客は75％で更新され、トマスの顧客は45％で更新されます。1週間ペアにしてみましょう。」

代表的な更新件数：180件の顧客

この規模のスタジオにおける代表的な導入事例では、パック更新率（前回のパックの最終セッションから7日以内に新しいパックが購入された場合と定義）は、通常、ベースラインの60～70%から90日以内に80～88%の範囲に上昇します。最大の要因は、パーソナライズされた「次のパックをドロップしますか？」というメールであるタッチ1です。このメールは、スムーズな次のステップを提示するため、コンバージョン率を高めます。

約8週間ごとに1パックを契約する顧客が180社いるスタジオでは、毎月約75～100件の更新契約が見込まれます。更新率が15ポイント向上すれば、本来なら離脱してしまうであろう顧客を毎月約11～15社取り戻すことができます。10パックあたり600ドル（例）とすると、これは毎月約7,000～9,000ドルの収益回復に相当し、自動化システム1つで年間約9万ドルの収益回復が見込めます。

これらの数値はあくまで参考値であり、実際の結果はパック価格と平均パック更新間隔によって大きく左右されます。

ビルダーテイクアウト

  • コピーすべきもの： の < 3 remaining sessions 閾値とトレーナーがパーソナライズした送信者。この文脈では、一般的なスタジオブランドのメールは、トレーナーブランドのメールの約半分のコンバージョン率にとどまります。
  • 注意すべき点： remaining_sessions 更新はほぼリアルタイムで行われますが、信頼できる情報源はMindbodyであり、ActiveCampaignではありません。どちらのシステムでも、スタッフが手動でセッション数を「減らす」ことはしないでください。また、ActiveCampaignの取引パイプライン機能とより高度な自動化トリガーを使用するには、Plusプラン以上が必要です。SMSリマインダーはProfessionalプランが必要です。
  • このパターンが当てはまらない場合： 会員制でパック販売を行っていないスタジオは、この変更による恩恵を受けられません。非常に大規模なパック（50回以上のセッション）を提供しているスタジオは、緊急性を感じにくいため、トリガーとなる閾値を高く設定する必要があります（おそらく残り5回、あるいは8回程度）。
