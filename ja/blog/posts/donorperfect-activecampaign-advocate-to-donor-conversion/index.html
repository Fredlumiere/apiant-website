署名者を新規寄付者に変える：DonorPerfectからの寄付をトリガーとするActiveCampaignの自動化機能

Fred Lumiere 2025年4月15日 6分で読めます
#非営利団体#ドナーパーフェクト#アクティブキャンペーン#CRMConnect

土地信託団体にとって、支持者リストは最も活用されていない資産の一つです。請願書の署名者、イベントへの参加申し込み者、意見提出者、行動喚起メールの購読者など、メールアドレスを提供するほど関心はあるものの、まだ寄付をするほどではない何千人もの人々。支持者から初めての寄付者へと至る過程こそ、多くの環境保護NPOが最も成長の機会を逃している部分なのです。

引き継ぎがスムーズに行われることはほとんどない。支援者がActiveCampaignに送信されるフォームを通じて請願書に署名する。その後、その支援者がDonorPerfectに送信される年末募金ページを通じて25ドルを寄付する。2つの記録は別々のシステムに保存される。支援者育成シーケンスはアクションアラートを送信し続けるが、寄付者育成シーケンスは開始されない。連絡先は間違った方向に進み続け、その後6か月以内に離脱してしまう。

支持者を寄付者へと転換させる仕組みは、一見単純そうに聞こえる。しかし、現実には、あらゆる非営利団体のデータ問題が抱えるのと同じ理由で、うまくいかないのだ。

ActiveCampaignは、何らかの操作によってDonorPerfectからの寄付情報を表示しない限り、その情報を確認できません。手動でのエクスポートは時間がかかりすぎて実用的ではありません。開発責任者が毎週の寄付CSVファイルをアップロードする頃には、寄付者はすでに3件のアクションアラートを受け取っており、それらを開封しなくなっています。

Zapierなどのポイントツーポイントツールは、単純なケース（DonorPerfectでの新しい寄付がActiveCampaignに新しい連絡先を作成する）には対応できますが、より複雑なケースには対応できません。つまり、連絡先が既にActiveCampaignに支持者として存在しており、システムが古いタグを削除し、新しいタグを追加し、連絡先を支持活動トラックから寄付者育成トラックに切り替える必要がある場合です。その際、識別情報を失ったり、レコードを重複させたりする必要はありません。

DonorPerfect が新しいアピール コードを追加したり、ActiveCampaign が API レスポンスを再構築したりすると、四半期の間、この処理を行う DIY スクリプトが中断されます。

APIANTアプローチ

DonorPerfectおよびActiveCampaign向けのCRMConnectは、連絡先を単一のエンティティとして扱い、支持者状態と寄付者状態の両方を同時に保持できます。トラック切り替えを実際に機能させる機能は次のとおりです。

  • リアルタイムの寄付者情報同期 DonorPerfectが寄付を記録した瞬間に、ActiveCampaignのカスタムフィールドに最初の寄付日と最後の寄付日を書き込みます。
  • フラグからタグへの同期 DonorPerfect フラグを ActiveCampaign タグに即座に変換し、フラグがクリアされるとそれらを削除します。削除方法は以下のとおりです。 Advocate Only そして適用する First Time Donor 同じ同期サイクル内で。
  • 簡単な寄付トラッキング 各ギフトを、金額、キャンペーン、勧誘内容を添付したActiveCampaignの取引としてギフトパイプラインに記録します。
  • CodeSync DonorPerfectのアピールコードをActiveCampaignのドロップダウン値として反映させることで、セグメンテーションが時間の経過とともにずれるのを防ぎます。
  • 双方向同期 ActiveCampaignのエンゲージメントスコアとジャーニーステータスをDonorPerfectのカスタムフィールドに書き込むことで、開発チームはDonorPerfectから離れることなくジャーニーの状態を確認できます。

支援者から寄付者へのスイッチを接続する

具体例：ブルーリッジ流域トラストは、7,500人の支援者と共に24,000エーカーの土地を保護する土地信託団体である（架空の例であり、実在する組織ではない）。

ステップ1．本人確認を行います。 CRMConnectの重複排除機能は、デフォルトではメールアドレスに基づいてマッチングを行います。支援者登録フォームと寄付フォームでメールアドレスフィールドを共有できる場合、ID照合は自動的に機能します。支援プラットフォームで別の識別子を使用する場合は、カスタムフィールドマッピングを設定して、同一人物を1つの連絡先に集約してください。

ステップ2．線路分岐器を組み立てる。 ActiveCampaignで、トリガーされる自動化を作成します。 First Gift Date is set （同期されたカスタムフィールドをトリガーとして使用します）。最初の3つのアクション：

  • タグを削除する: Advocate, Petition Signer, Action Alert Subscriber.
  • タグを追加する: First Time Donor, Donor 2026 （または会計年度）
  • 連絡先をアドボカシーリストからドナー育成リストに移動します。

これがループを閉じる鍵となります。アドボカシータグを削除しない限り、連絡先はアドボカシー育成のサイクルに留まり、寄付者向けのサイクルと並行して誤ったメッセージを受け取ることになります。

ステップ3．21日間の培養手順を計画する。 自然保護非営利団体の寄付者開拓活動は、取引的なものではなく、努力の賜物であると感じられるべきである。

  • 0日目：事務局長または土地保護責任者からの個人的な感謝のメッセージ。保護対象となる流域名と、寄付によって可能となる活動について記載する。
  • 3日目：最近取得した土地や地役権に関する記事と、保護対象地の短い動画。質問は不要です。
  • 7日目：会員限定の施設見学への招待状。見学場所は、寄付者の郵便番号から車で行ける範囲にある。
  • 14日目：流域と保護された面積を示す影響マップ。寄付者の寄付金は貢献として視覚化されている。
  • 21日目：一般的な定期アップグレードではなく、「年間を通して流域を保護する600人の月額会員に加わりませんか」という形で、控えめな定期寄付の依頼を行う。

ステップ4．レベルを指定してパーソナライズする。 取引に同期されたギフト金額を使用して、育成シリーズを分岐させます。

  • 50ドル未満の場合：関係構築に重点を置き、摩擦の少ない次のステップ（ボランティア活動、ウェビナー、アンケートなど）を提案する。
  • 50ドルから499ドルの場合：会員特典のリマインダー（ニュースレター、イベントの事前招待など）と、さりげない定期寄付のお願いを含める。
  • 500ドル以上の寄付：開発担当者に連絡を取り、個別にアプローチする。自動化された育成プロセスは一切行わない。代わりに、寄付者の寄付履歴と既知の関心事項を添付したHubSpotまたはActiveCampaignのタスクを送信する。

ステップ5．取引パイプラインを構築する。 CRMConnectを設定して、DonorPerfectの各寄付をActiveCampaignの取引としてGifts Pipelineに書き込むようにします。寄付のライフサイクルに合わせて、新規寄付、承認済み、育成中、更新済み、失効済みのステージを作成します。ステージを使用することで、連絡先レベルのタグを汚染することなく、各寄付者がジャーニーのどの段階にいるかを追跡できます。

人々を困らせるような特殊なケース

署名したその日に弁護してくれる弁護士。 署名者の中には、すぐに寄付者になる人もいます。寄付者育成シーケンスを開始する前に、4～6時間の猶予期間を設けてください。そうすることで、署名確認が届く前に25ドルの寄付に対するお礼メールを送ってしまうことを防ぐことができます。

匿名で寄付をする人。 寄付者の中には、匿名での寄付を希望する方もいます。その意向を尊重しましょう。「フラグをタグとして同期」機能では、DonorPerfectからActiveCampaignに匿名フラグをタグとして転送し、寄付者育成ワークフローでは匿名寄付に対するパーソナライゼーショントークンを無効にする必要があります。

メールアドレスを2つ持っている世帯。 DonorPerfectの世帯アカウントには、異なるメールアドレスを持つ2人の成人が登録されていることがよくあります。寄付促進キャンペーンは、主要な連絡先に対して実行され、二次的な連絡先には重複して実行されないようにしてください。主要な寄付者を特定するには、DonorPerfectの世帯関係フィールドを使用してください。

激しく跳ね返る。 ActiveCampaignはメールをバウンスとしてマークします。カスタムフィールド同期を使用してそのステータスをDonorPerfectに書き戻すことで、ダイレクトメールチームが郵送確認のために連絡先をフラグ付けできます。

実際の生産現場ではどのような様子か

ブルーリッジのような規模の土地信託団体（収益310万ドル、支援者7,500人）を例にとると、従来年間4～6%程度だった支援者からの寄付率が、適切な支援者育成フローを構築することで、通常9～12%に上昇します。6,000人のアクティブな支援者に対して、これは年間240～360人の新規寄付者が増えることを意味します。平均初回寄付額が45ドル、12ヶ月間のLTVが約90～130ドルとすると、初年度の収益増は2万ドル～4万5千ドルとなり、将来の継続寄付の基盤も十分に構築できます。

質的な成果も同様に重要です。アドボカシーチームは、消えてしまうファネルの上部に餌を与えているような感覚から解放されます。開発チームは、新規寄付者を手作業で特定する手間を省き、システムを運用し始めます。

建築業者の持ち帰り

  • トラックの切り替えが重要な作業です。寄付者タグを追加するよりも、支持者タグを削除することの方が重要です。削除しないと、連絡先は両方のメッセージを受け取り、両方のトラックから離脱してしまいます。
  • 寄付額に応じて、関係構築のプロセスを分岐させましょう。初回寄付額が25ドルの人と500ドルの人には、次に求める内容が異なります。
  • 500ドル以上の寄付は、自動処理ではなく担当者が対応します。自動処理は、ごく一部の寄付者向けです。高額寄付については、直接担当者が連絡を取るべきです。
