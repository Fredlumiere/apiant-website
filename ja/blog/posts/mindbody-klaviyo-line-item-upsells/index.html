高額商品のアップセル向けに、MindbodyからKlaviyoへの商品購入情報の同期機能を追加

Fred Lumiere 2024年11月20日 5分で読める
#フィットネス＆ウェルネス#心身#クラヴィヨ#CRMConnect#データエンジン

単一の販売フィールドがアップセルロジックを阻害する理由

高額なウェルネスパッケージは、単一の商品ではありません。6,200ドルの12週間のリトリートパッケージには、通常、基本宿泊費、食事プラン、毎日のクラス受講料、プライベートセッションのセット、そしてオプションの追加オプション（サウンドバス、マッサージクレジット、コーチとの1対1セッションなど）が含まれています。請求書のすべての項目は、アップセル、クロスセル、そして更新の機会となります。

CRMが注文合計金額しか認識できない場合に問題が発生します。仮に、Silver Fern Wellness Retreat（例示）が12週間のローリングコホートで4,000ドルから8,000ドルのパッケージを販売しているとします。Klaviyoは、顧客が先週の火曜日に5,800ドルを支払ったことしか認識できません。しかし、パッケージに3回のマッサージクレジットと0回のプライベートコーチングセッションが含まれていることは認識できません。そのため、購入後のフローは、一般的なアップセルを実行するか（既にアップセル対象の商品を購入している顧客の半数を不快にさせる）、あるいは全く実行されないかのどちらかになります。

市販のツールに欠けているもの

Mindbodyの販売データには明細項目が含まれていますが、一般的な連携ツールのほとんどは、Klaviyoに到達する前に販売データを1行に集約してしまいます。その理由は通常、データモデリングにあります。Klaviyoの「注文完了」イベントはアイテム配列を想定しており、Mindbodyのネストされた販売データを正しく配列に（適切なSKU、価格、カテゴリタグを使用して）組み込む作業は、「クイックZap」で省略されてしまうからです。その結果、Klaviyoでは明細項目も追加オプションの表示もアップセル計算も含まれない、1行の注文データになってしまいます。

APIANTアプローチ

CRMConnect MindbodyからKlaviyoへの接続には以下が含まれます 購入・売上明細の同期 第一級の機能として、MindbodyからKlaviyoへ販売データが各明細項目をそのまま保持した状態で流れるため、Klaviyoのプロファイルとイベントペイロードには、セグメンテーションとフローロジックに必要な構造がそのまま保持されます。

APIANT内部の統合データ処理エンジンは、フォーマットに依存しません。Mindbodyの販売ペイロードは、XPath（W3Cのオープン標準）を介してKlaviyoのイベントスキーマにマッピングされ、ネスト構造が失われることはありません。各明細項目には、独自のSKU、価格、カテゴリ、数量が含まれています。これがアップセルロジックを可能にする部分です。

ここでは、APIアプリの3つの機能が重要な役割を果たします。

  • 購入・売上明細の同期 構造化項目リストの場合。
  • リアルタイムのクライアントプロフィール同期 つまり、購入者プロファイルは最新であり、セグメント化可能である。
  • 来店追跡 したがって、購入後のサポートは、顧客が実際に購入した製品を使い始めたかどうかによって分岐させることができる。

Klaviyoにおける明細項目同期の仕組み

リトリートパッケージの購入は、Klaviyo上で構造化されたイベントとして登録されます。その形式は概ね以下のとおりです。

{
  "event": "Placed Order",
  "customer_properties": {
    "$email": "client@example.com",
    "mindbody_client_id": "MB-44918"
  },
  "properties": {
    "OrderId": "MB-INV-71204",
    "Total": 5800.00,
    "Currency": "USD",
    "Items": [
      { "SKU": "RETREAT-12W-DLX", "Name": "12-Week Deluxe Package", "Price": 4200, "Category": "Retreat Base" },
      { "SKU": "MEAL-VEG-12W", "Name": "Vegetarian Meal Plan", "Price": 800, "Category": "Meal Plan" },
      { "SKU": "MASSAGE-CR-3", "Name": "Massage Credits x3", "Price": 450, "Category": "Add-On" },
      { "SKU": "SOUND-BATH-1", "Name": "Sound Bath Session", "Price": 350, "Category": "Add-On" }
    ]
  }
}

Klaviyoは、「個別コーチングなしで12週間のパッケージを購入した」、「食事プランを購入したが追加オプションは購入していない」、「5,000ドル以上使ったがマッサージクレジットを一切使用していない」といったように、顧客をセグメント化できるようになりました。

高額パッケージ向け追加オプションの設計

アップセルフローには3つのトリガーがあり、それぞれが ない 明細項目から：

  1. 個人指導は購入していません。 リトリート開始から3日目に、シニアコーチとの個別セッションを割引価格で提供するメールを送信する。既にコーチング関連の商品・サービスが含まれている参加者には送信しない。
  2. 食事プランを購入しました。追加オプションはありません。 7日目に、サウンドバスとマッサージのクレジットについて、「ご存知でしたか？」というメールを送り、セット価格を案内する。
  3. 追加オプションを購入しましたが、今後14日以内にレッスンの予約はありません。 厳選されたスケジュールに基づいて、再エンゲージメントメールを送信する。

各ブランチは、プロフィールに既に登録されている商品項目に基づいて表示されます。既に購入した商品を再度勧められることはありません。これだけでも、高額商品を購入する顧客の購読解除を防ぐのに十分です。

リピート購入にロイヤルティ特典を重ねる

2つ目のフローは、同じデータに対して、より長い期間で実行されます。項目を使用して、カテゴリ別に生涯価値を計算します。

  • 生涯マッサージ利用額が1,500ドルを超えると、「創設者」ティアにご招待し、優先予約をご利用いただけます。
  • 12ヶ月間に2回の本格的なリトリートに参加：3回目のリトリートの食事プランは無料です。
  • リトリート1回と追加オプション4つ：パーソナライズされたコードを使って紹介依頼をトリガーできます。

数学はKlaviyoを使用して実行されます Items 各「注文完了」イベントごとに配列が作成されます。この統合により、配列の精度が維持されます。

4,000ドル～8,000ドルのパッケージにおける代表的な平均注文額増加率

あくまでも参考例であり、実際の顧客像ではありません。

  • 追加添付率の基準値（一般的な購入後メール）：約8～12パーセント。
  • 明細項目を考慮したアップセルによる追加購入率は、主に適切なオファーが適切な購入者に届くため、20～28％の範囲に上昇します。
  • リトリート参加者一人当たりの平均注文額：代表的なコホートにおいて6～11％の増加。
  • 購入後のフローにおける購読解除率：抑制ロジックによって「既に購入した商品を再度売り込もうとしている」という問題が解消されるため、低下する。

これらは仕組みに基づいたものであり、魔法ではありません。項目ごとに正確なターゲティングが可能になり、その正確なターゲティングが成果向上につながります。

ビルダーテイクアウト

  • MindbodyとKlaviyo間では、明細項目レベルでの同期を強く求めましょう。高額商品の場合、合計注文金額だけではマーケティング上の行き詰まりが生じます。
  • アップセルロジックは、 不在 アイテム配列から取得します。そこに、購入可能な次のステップがあります。
  • 生涯利用額（マッサージ、コーチング、食事など）をロイヤルティティアの基準として用いる。総収益は、パッケージ型リトリートビジネスには大雑把すぎる。
