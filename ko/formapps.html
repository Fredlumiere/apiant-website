개념

FormApps란?

FormApp은 APIANT 자동화 엔진에 직접 연결된 사용자 지정 UI입니다. 자동화 편집기에서 구성한 설정이 FormApp에 바로 표시되므로 최종 사용자에게 기본 플랫폼의 복잡성을 노출하지 않고 깔끔하고 브랜드화된 구성 환경을 제공합니다.

커스텀 UI

폼, 대시보드, 설정 패널, 인테이크 마법사 등 사용자에게 필요한 모든 인터페이스. 드래그 앤 드롭 빌더로 구축. 자체 브랜드로 제공.

APIANT 자동화 엔진

500개 이상의 커넥터, AI 처리, 조건부 로직, 데이터 변환, 오류 처리, 보이지 않는 곳에서 실행되는 전체 플랫폼.

보이지 않는 레이어

고객은 APIANT를 전혀 보지 못합니다. 귀하의 것이라고 생각합니다.

FormApps는 APIANT가 제품 뒤에서 보이지 않게 되는 방법입니다. 통합 인프라가 사용자에게 네이티브로 보이고 느껴집니다. 실제로 그렇기 때문입니다.

시나리오: HubSpot에 연결
고객이 제품 내에서 "HubSpot에 연결"을 클릭합니다. FormApp이 인증, 필드 매핑 및 구성을 처리합니다. APIANT가 백그라운드에서 자동화를 실행합니다. 고객은 제품을 떠나지 않습니다. APIANT를 전혀 보지 못합니다. 귀하의 것이라고 생각합니다.

제품에 임베드

FormApps는 iframe 또는 SDK를 통해 SaaS 제품 내부에 직접 임베드됩니다. 리디렉트도, 외부 브랜딩도 없습니다.

화이트 라벨 지원

귀하의 브랜드, 귀하의 도메인, 귀하의 룩앤필. APIANT는 그가 있어야 할 곳인 커튼 뒤에 있습니다.

그 뒤에 완전한 자동화

모든 FormApp은 APIANT 자동화 엔진(커넥터, 로직, AI, 데이터 처리, 오류 처리)의 전체 기능을 지원받습니다.

사용 사례

FormApps로 무엇을 구축할 수 있습니까?

FormApps는 APIANT 플랫폼의 프론트 도어입니다. 통합 로직을 트리거, 구성, 표시해야 하는 모든 인터페이스가 FormApp이 될 수 있습니다.

통합 설정 패널

SaaS 제품 내부에 설정 패널을 직접 임베드하세요. 고객이 인터페이스를 벗어나지 않고 플랫폼을 연결하고, 필드를 매핑하고, 동기화 설정을 관리할 수 있습니다.

파트너 플랫폼의 CX 앱

ActiveCampaign의 App Studio와 같은 플랫폼 내에서 전체 인앱 연동 경험을 제공합니다. 설정, 구성 및 상태를 파트너 제품 내에서 직접 표시합니다.

AI 기반 접수 양식

AI를 사용하여 필드를 자동 완성하고, 데이터를 검증하고, 양식이 제출되는 순간 복잡한 자동화를 트리거하는 지능형 접수 양식을 구축하세요. 정적인 양식이 아닙니다. 스마트한 양식.

셀프서비스 포털

최종 사용자에게 자체 통합을 관리할 수 있는 권한을 제공하세요. 동기화 상태 확인, 설정 조정, 연결 재인증을 모두 관리하는 브랜드 포털을 통해 가능합니다.

내부 도구

내부 운영을 위해 UI, 자동화, AI를 하나의 화면에 결합하세요. 스택의 모든 시스템에 연결되는 대시보드, 관리자 패널, 워크플로 도구를 구축하세요.

아키텍처

설정에서 UI로의 파이프라인

Automation Editor에서 구축한 자동화 설정이 FormApps에 직접 표시됩니다. 변환 레이어 없이. 별도의 UI 빌드 없이. FormApp이 곧 설정 UI입니다.

자동화 편집기

각 고객이 통합을 사용하는 방식을 형성하는 컨트롤인 체크박스, 드롭다운, 다중 선택 등 설정을 정의합니다.

FormApp 빌더

설정이 자동으로 표시됩니다. 배치하고, 브랜딩하고, 로직과 AI를 추가하세요. 컨트롤을 처음부터 다시 만들 필요가 없습니다.

귀하의 제품

최종 사용자는 제품 내에서 깔끔한 설정 패널을 봅니다. 자동화 로직을 구동하는 동일한 설정과 상호작용합니다.

Automation Editor의 설정 레이어(각 고객이 연동을 사용하는 방식을 제어하는 체크박스, 드롭다운, 다중 선택)를 기억하시나요? 이 설정이 FormApps에 직접 표시됩니다. SaaS 회사의 고객이 제품 내에서 연동 구성 패널을 열면, 자동화 로직을 구동하는 것과 동일한 설정을 보고 상호작용하게 됩니다. 변환 레이어가 없습니다. 별도의 UI 빌드가 없습니다. FormApp이 곧 설정 UI입니다.

기능

기술 역량

FormApps는 단순한 폼이 아닙니다. APIANT 플랫폼의 전체 기능을 지원받는 프로그래밍 가능한 UI 표면입니다.

드래그 앤 드롭 UI 빌더

시각적으로 인터페이스를 구축하세요. 코드를 작성하지 않고도 필드, 섹션 및 구성 요소를 정렬할 수 있습니다.

조건부 논리 및 분기

사용자 입력 및 데이터 조건에 따라 필드, 섹션 또는 전체 단계를 표시하거나 숨깁니다.

AI 기반 필드

플랫폼의 기본 AI 기능을 기반으로 하는 자동 완성, 지능형 기본값, AI 기반 유효성 검사 기능을 제공합니다.

자동화 설정에 직접 액세스

체크박스, 드롭다운, 다중 선택 등 모든 것이 자동화 에디터의 통합 로직에 의해 구동됩니다. 재구축할 필요가 없습니다.

iframe 또는 SDK로 임베드 가능

어떤 웹 애플리케이션에든 FormApp을 추가하세요. 간단하게는 iframe으로, 더 깊은 통합과 이벤트 처리에는 SDK로 사용할 수 있습니다.

전체 플랫폼 접근

모든 FormApp은 APIANT 자동화 엔진에 완전히 접근할 수 있습니다: 500개 이상의 커넥터, 데이터 엔진, AI, 오류 처리, 모니터링.
