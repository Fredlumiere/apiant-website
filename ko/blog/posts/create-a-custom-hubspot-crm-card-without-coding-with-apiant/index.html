APIANT를 사용하면 코딩 없이도 맞춤형 HubSpot CRM 카드를 쉽게 만드는 방법을 알아보세요.

대상 고객: HubSpot 관리자

HubSpot CRM 카드 이해하기

HubSpot CRM 카드는 HubSpot 내에서 다양한 소스의 핵심 정보와 상호 작용에 빠르게 접근할 수 있도록 지원하여 워크플로우를 향상시키는 동적인 도구입니다. 외부 앱 및 HubSpot 생태계와 원활하게 통합되도록 설계된 이 카드를 통해 사용자는 CRM을 벗어나지 않고도 지원 티켓, 청구 정보, 맞춤형 애플리케이션 인사이트와 같은 주요 데이터를 확인할 수 있습니다. 기본적으로 API와 상호 작용하는 방식입니다.

이 튜토리얼에서는 연락처의 날씨 정보를 가져와 날씨 지도에 연결하는 CRM 카드를 만들어 보겠습니다. OpenWeatherMap.org API.

HubSpot 공개 앱 만들기

맞춤형 CRM 카드를 만들기 전에 다음 사항을 확인해야 합니다. HubSpot 공개 앱을 직접 만들어 보세요원하지 않으시면 공개적으로 등록하지 않으셔도 되지만, 등록하셔도 됩니다! 🤑 이렇게 하면 고객의 HubSpot 허브를 APIANT 플랫폼에 연결할 수 있습니다.

나만의 공개 앱을 만들려면 다음의 간단한 단계를 따르세요.

HubSpot 개발자 계정이 없으시면 다음 링크에서 계정을 만드세요. developers.hubspot.com

앱을 만들고 싶으신가요?

앱 관리를 클릭하세요

오른쪽 상단의 '앱 만들기'를 클릭하세요.

앱에 이름, 설명, 로고(원하는 경우)를 입력한 다음 '승인'을 클릭하세요.

리디렉션 URL을 입력하세요. APIANT에서 HubSpot Admin Free 또는 HubSpot Admin Pro 플랜을 사용 중인 경우 apiant.com/oauth를 입력할 수 있습니다. 테넌트 또는 전용 플랜을 사용 중인 경우 서버 URL을 입력하세요. 서버 URL을 모르는 경우 도메인 이름을 입력하면 앱이 APIANT 서버에 연결될 때 시스템에서 알려주므로 그때 다시 입력할 수 있습니다.

사용하려는 스코프를 입력하세요. APIANT 계정을 사용하면 CRM 카드 외에도 훨씬 더 많은 작업을 수행할 수 있습니다! (완전한 API 앱 구축 포함). 따라서 아래와 같이 권장하는 스코프를 제시합니다. 24개의 트리거와 73개의 액션 현재 이용 가능한 상품은 다음과 같습니다(2024년 3월 17일 기준).

스코프는 앱이 HubSpot의 데이터에 액세스하거나 작업을 수행할 수 있는 권한을 결정합니다. 앱을 설치하는 사용자는 앱에서 요청하는 스코프를 승인해야 합니다. 앱 기능에 필요한 스코프 수를 최소화하는 것이 좋습니다.

화면 하단에서 앱을 저장하세요.

APIANT에서 자동화 기능을 구축하여 데이터 가져오기 URL을 얻으세요.

APIANT 계정이 필요하신가요? 여기를 클릭하세요 HubSpot 관리자 계정을 무료로 신청하려면 다음 단계를 따르세요.

자동화 시스템을 처음부터 구축하는 대신 설치하려면 다음 경로에서 설치할 수 있습니다. 여기.

이제 APIANT 계정에서 CRM 카드와 연동되는 자동화 기능을 구축해 보겠습니다.

자동화 편집기에서 자동화 생성을 클릭합니다.

트리거 십자 표시를 클릭하고 트리거 찾기를 선택하세요.

HTTP 요청을 검색하고 HTTP 요청 수신(즉시)이라는 트리거를 선택하세요.

+ 버튼을 클릭하여 새 쿼리 매개변수를 입력하세요.

매개변수로 hs_object_id를 입력하세요.

데이터 필드 가져오기를 클릭하세요

HubSpot에 붙여넣어야 할 웹 서비스 URL이 표시됩니다. 복사 아이콘을 클릭하여 클립보드에 복사하세요.

창 오른쪽 하단에 있는 '트리거 저장'을 클릭하세요.

자동화를 저장하기 위해 '대문자로 변환'이라는 임시 작업을 추가합니다.

대문자 변환 작업은 비워두셔도 됩니다. 자동화를 다시 편집할 때 저희가 삭제하겠습니다.

자동화에 이름을 지정하고 저장하세요.

이제 HubSpot에서 CRM 카드를 만드는 데 필요한 모든 것을 갖추었습니다. HubSpot 개발자 계정으로 돌아가서 카드를 생성하세요.

공용 앱에서 CRM 카드 만들기

HubSpot 공개 앱 설정이 완료되었으니 이제 CRM 카드를 만들 차례입니다. 카드 레이아웃과 콘텐츠를 정의하게 됩니다.

기능 아래의 CRM 카드를 클릭하세요.

CRM 카드 생성 버튼을 클릭하세요.

CRM 카드 이름을 입력하세요. 저희는 '날씨'라고 하겠습니다. 이는 연락처 레코드가 되며, HubSpot에서 해당 연락처 레코드(hs_object_id)를 APIANT 계정으로 전송합니다.

APIANT 자동화에서 생성한 웹 서비스 URL을 데이터 가져오기 URL에 붙여넣으세요.

카드 속성을 클릭하고 속성 추가를 클릭하여 다음 속성을 입력하십시오.

Max는 위에서 보이는 것처럼 각 속성 유형이 일치하는지 확인해야 합니다.

이제 끝입니다! '만들기'를 클릭하여 CRM 카드를 생성하세요.

새로운 HubSpot 공개 앱을 APIANT 계정에 연결하기

자동화 구축을 완료하기 전에 새 HubSpot 공개 앱을 APIANT 계정에 연결해야 합니다.

메뉴에서 연결을 클릭하세요.

앱 연결 버튼을 클릭하세요

HubSpot을 선택하세요

내 공개 앱을 선택하세요

화면의 지시사항을 따르세요(HubSpot 개발자 콘솔 열기 등). - 확인을 클릭하세요.

이제 공개 앱의 데이터 가져오기 URL에 입력할 URL을 받게 됩니다.

대화 상자에서 클라이언트 ID, 클라이언트 시크릿 및 설치 URL을 복사하세요.

공용 앱을 연결할 HubSpot 계정을 선택하고 [계정 선택]을 클릭하세요.

연결을 승인하면 공개 앱이 APIANT 계정에 연결됩니다.

APIANT에서 CRM 카드와 상호 작용하는 자동화 기능을 구축하세요.

APIANT에서 자동화를 편집하세요:

그런 다음 클릭하여 대문자 변환 작업을 제거하세요. 이는 저장을 위한 임시 자리 표시자였습니다.

현재 자동화 시스템에는 트리거(웹 서비스)만 있습니다.

예시의 경우, HubSpot에서 데이터를 수신하고, OpenWeatherMap API에서 데이터를 가져와 HubSpot으로 다시 전송하려면 다음 코드를 추가해야 합니다.

  1. HubSpot에서 연락처 정보를 가져와 우편번호를 확인하세요.

  2. OpenWeatherMap을 사용하여 우편번호를 지리적 코드로 변환합니다.

  3. 지오코드를 기반으로 오픈웨더맵에서 현재 날씨 정보를 가져오세요.

  4. CRM 카드 속성에 OpenWeatherMap 데이터를 입력합니다.

  5. CRM 카드에 날씨 지도 링크를 추가하는 메뉴 옵션을 만드세요.

  6. JSON 데이터를 HubSpot CRM 카드에 반환합니다.

시작해 볼까요!

1. HubSpot에서 '연락처 가져오기'라는 작업을 추가합니다.

트리거의 hs_object_id를 연락처 ID 필드에 매핑합니다.

2. 우편번호로 지오코딩하는 작업을 추가합니다.

HubSpot 연락처의 우편번호를 '우편번호로 지오코딩' 작업의 '우편번호' 필드에 매핑합니다. 다이어그램 도구를 사용하여 이 작업을 수행하는 것을 선호하는 경우(저는 선호합니다!), 방법은 다음과 같습니다.

3. 이제 Openweathermap에서 "현재 날씨 정보 가져오기" 작업을 추가하고 이전 작업에서 얻은 경도와 위도를 지도에 표시합니다.

4. HubSpot 액션 'CRM 카드'를 추가하고 표시 값을 설정합니다.

CRM 카드에 생성한 5개의 속성을 추가하고 (동그라미 안의 '+' 기호를 사용하여) 위의 '현재 조건 가져오기' 작업에서 가져온 해당 값에 매핑합니다.
CRM 카드 속성 이름 OpenWeatherMap의 지도 데이터
정황 날씨 설명
임시 메인 온도
temp_max 메인 온도 최대
temp_min 주 온도 최소
바람 풍속

이 속성들은 우리가 CRM 카드에 추가했던 속성들과 동일하다는 점에 주목하세요.

카드 이름을 원하는 대로 정하세요. 저는 여기서는 "[지도에 표시된 이름]의 날씨 정보"라고 했습니다. 이 내용이 카드에 표시될 위치입니다.

6. 이제 HubSpot의 마지막 액션인 CRM 카드: iframe 메뉴 옵션 추가를 추가해 보겠습니다.

액션에 필요한 모든 필드를 매핑하고 저장하세요.
CRM 카드: iframe 메뉴 옵션 필드 이름 추가 입력란에 / 지도를 입력하세요
CRM 카드 JSON 지도: CRM 카드 JSON 이전 조치로부터 CRM 카드: 표시 값 설정
메뉴 라벨 날씨 지도
URL https://openweathermap.org/city/ [현재 상태 가져오기 작업에서 방출된 ID] 이것이 iframe 내에서 openweathermap 웹사이트의 날씨 도시 ID를 전달하는 내용입니다.
너비 1200
키 1000

7. 마지막으로, 모든 데이터를 HubSpot으로 다시 전송하기 위해 자동화의 끝에 'HTTP 응답 반환'이라는 작업을 추가합니다.

위 작업에서 생성된 CRM 카드 JSON을 응답 데이터에 매핑하고 작업을 저장합니다.

자동화 설정을 저장하고 활성화하세요. 끝입니다! 🙌
