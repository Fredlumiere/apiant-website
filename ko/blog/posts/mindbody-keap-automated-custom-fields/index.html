Mindbody의 Keap 사용자 정의 필드 자동화: 설정 시간을 며칠에서 몇 분으로 단축

Fred Lumiere 2025년 2월 10일 읽는 데 6분 소요
#피트니스 & 웰빙#심신#유지하세요#CRMConnect#데이터 엔진

지난 2년 동안 CRM 시스템을 바꾼 퍼스널 트레이너에게 첫 달이 어땠는지 물어보세요. 그들은 스프레드시트, 데이터 가져오기, 그리고 Keap에서 Mindbody의 모든 사용자 지정 필드를 수동으로 다시 만드는 느리고 고된 작업에 대해 이야기할 것입니다.

고품질 개인 트레이닝 스튜디오의 각 트레이너는 고객별로 목표, 체성분, 부상 이력, 훈련 선호도, 식단 고려 사항, 주요 일정, 가정용 장비 선호도, 일정 제약 조건 등 8~15개의 맞춤 데이터 포인트를 추적합니다. Mindbody에서는 이러한 데이터가 고객 인덱스 또는 사용자 지정 필드로 저장됩니다. Keap에서는 기본적으로 이러한 필드가 존재하지 않습니다. 따라서 각 필드를 하나씩 생성하고, 유형을 결정하고, 레이블을 작성한 다음, Mindbody에서 데이터를 가져와 채우는 매핑 로직을 작성해야 합니다.

성실한 트레이너라도 필드 생성, 마인드바디 매핑, 테스트 가져오기 등을 고려하면 시간당 최대 4개의 사용자 지정 필드를 구축할 수 있습니다. 필드가 15개라고 가정하고, 서로 다른 보기 방식을 원하는 트레이너 수를 곱하면 설정 작업만 해도 며칠이 걸립니다. 대부분의 스튜디오는 중간에 포기하고 결국 아무도 신뢰하지 않는 불완전한 Keap만 남게 됩니다.

가상 사례: 그래닛 베이 퍼스널 트레이닝(예시)은 트레이너 5명과 140명의 고밀도 고객을 보유한 단일 지점 스튜디오로, 이 시스템을 수동으로 두 번 시도했습니다. 두 번 모두 필드 생성 단계에서 실패했습니다. 트레이너들은 말 그대로 2주 동안 점심시간을 이용해 Keap 사용자 정의 필드를 만들었지만, 결국 지쳐서 모든 기능을 Mindbody에 추가하고 목표 추적을 위한 별도의 스프레드시트를 사용하는 방식으로 되돌아갔습니다.

CRMConnect가 첫날에 생성하는 필드는 무엇인가요?

CRMConnect Mindbody와 Keap이 함께 제공됩니다. 자동화된 사용자 정의 필드 생성앱 페이지에서 발췌: "CRMConnect는 설정 과정에서 Keap에 Mindbody의 필수 데이터 필드를 자동으로 생성하여 첫날부터 정확한 고객 데이터 추적을 보장하며, 수동 구성이 필요하지 않습니다."

통합 첫날, Keap에는 웰니스 비즈니스에 필수적인 기능들이 구축됩니다.

  • 프로필 필드: mindbody_client_id, pricing_option_name, membership_status, total_visits, last_visit_date, last_visit_service, last_visit_staff, next_scheduled_appointment
  • 회원 자격 및 계약 분야: membership_expiration_date, remaining_sessions, contract_id, auto_pay_status
  • 구매 및 소개 필드: intro_offer_purchased, intro_offer_purchase_date, last_purchase_item, last_purchase_amount, last_purchase_date
  • 참여 분야: first_visit_date, total_visits, lifetime_revenue

표준 설정 외에도 CRMConnect는 지도를 제공합니다. Mindbody 클라이언트 인덱스 및 사용자 지정 클라이언트 필드 Keap 사용자 정의 필드와 자동으로 일치하도록 변환합니다. 예를 들어 Mindbody 사용자 정의 필드를 사용해 온 개인 트레이닝 스튜디오의 경우입니다. client_goals (체중 감량, 유연성, 근력, 스포츠 종목별, 부상 후 재활 등 구조화된 세트)를 선택하면 사용자가 Keap 드롭다운 메뉴에 값을 수동으로 입력하지 않아도 Keap에서 해당 필드가 정확하게 표시됩니다.

트레이너의 첫날 고객 기록은 다음과 같습니다.

{
  "email": "client@example.com",
  "firstname": "Riya",
  "mindbody_client_id": "MBO-2025-00451",
  "primary_trainer": "Sam",
  "client_goals": ["strength", "post-injury"],
  "injury_notes": "Right shoulder, post-surgical 2024",
  "preferred_session_day": "Tuesday/Thursday morning",
  "pricing_option_name": "12-Pack Personal Training",
  "remaining_sessions": 9,
  "total_visits": 33,
  "last_visit_date": "2026-05-14",
  "last_visit_staff": "Sam",
  "next_scheduled_appointment": "2026-05-19T07:00:00"
}

판매 데이터 동기화를 통해 시간이 지나도 필드의 유용성을 유지하는 방법

첫날은 쉬운 부분입니다. 어려운 부분은 고객이 새로운 패키지를 구매하고, 주요 목표를 달성하고, 목표를 변경하고, 선호도를 업데이트하는 향후 12개월입니다. 고정된 필드는 쓸모가 없습니다. 지속적으로 업데이트되는 필드가 자동화를 가능하게 합니다.

CRMConnect의 영업 데이터 동기화는 즉각적입니다. 프로필, 예약 및 영업 정보는 몇 분 내에 동기화됩니다(Mindbody에서 Keap으로의 동기화는 즉시, Keap에서 Mindbody로의 동기화는 15분마다 실행됨). 구매 서비스 태깅 기능은 구매 발생 시 관련 Keap 태그를 자동으로 관리합니다. "고객 구매 내역을 기반으로 Keap 태그를 자동으로 관리하여 업셀링 캠페인, 갱신 알림 및 개인화된 커뮤니케이션을 위한 정확한 고객 세분화를 지원합니다."

따라서 새로운 12개들이 팩을 구매하는 고객은 자동 업데이트를 받게 됩니다. pricing_option_name, remaining_sessions, last_purchase_item, last_purchase_amount및 last_purchase_date, 그리고 적절한 구매 태그(purchased-12pack-pt-2026q2 (또는 유사한) 해당 필드를 기반으로 구축된 Keap 자동화는 몇 초 내에 변경 사항을 감지합니다. 갱신 캠페인이 실행되고, 마일스톤 달성 축하 메시지가 실행되고, 교육 담당자 작업 알림이 실행됩니다.

사용자 정의 필드는 누군가가 수동으로 업데이트하는 것이 아니라, 항상 최신 상태를 유지하기 때문에 유용하게 사용됩니다.

사용자 지정 코드 없이 트레이너별 보기 구축하기

해당 필드가 설정되면 각 트레이너는 사용자 지정 코드 작업 없이 자신만의 Keap 저장 검색 보기를 만들 수 있습니다.

샘의 견해: 필터링 primary_trainer = Sam AND membership_status = Active정렬 기준 next_scheduled_appointment이것은 샘의 일일 업무 목록입니다. 신규 고객은 자동으로 추가되고, 기존 고객은 멤버십이 만료되면 목록에서 제외됩니다.

패키지 갱신 보기: 필터링 remaining_sessions <= 3 AND membership_status = Active, 그룹화됨 primary_trainer각 트레이너는 자신만의 재교육 과정을 가지고 있습니다.

주요 이정표 보기: 필터링 total_visits >= 100 AND milestone_100_celebrated is empty주요 성과 달성 축하 메시지와 상품권 발송을 자동으로 처리합니다(스튜디오의 고객 유지 전략).

부상자 현황 보기: 필터링 injury_notes is known AND last_visit_date in last 7 days수석 트레이너가 최근 훈련을 받았지만 현재 부상이 있는 고객을 파악하여 자세 점검을 위한 후속 상담을 진행할 수 있도록 합니다.

이 모든 것은 사용자 지정 코드를 필요로 하지 않습니다. 강사가 스프레드시트를 관리할 필요도 없습니다. 필드는 자동으로 채워지고, 화면도 자동으로 업데이트됩니다.

140개 고객사에서 상담원 준비 시간 절약 효과

이 규모의 스튜디오에 CRMConnect를 도입한 대표적인 사례를 살펴보면, 일반적으로 자체 구축 방식에서 요구되는 수동 설정 작업(강사 1인당 4~6시간, 강사 5명 기준, 관리자 필드 생성 작업 8~12시간 추가)이 CRMConnect의 사전 구축된 필드 세트를 사용하면 약 1시간의 설정 시간으로 간소화됩니다. 즉, 설정 단계에서 강사와 관리자의 시간을 약 30~40시간 절약할 수 있습니다.

초기 설정 외에도, 스튜디오에서 새로운 프로그램을 도입할 때 기존 필드를 소급해서 추가할 필요가 없기 때문에 지속적인 시간 절약 효과를 볼 수 있습니다. 예를 들어, Mindbody에서 새로운 "Mobility Mondays" 워크숍이 시작되면, 워크숍 참석 정보가 Keap 필드 관리자를 건드리지 않고도 구매 태그로 자동으로 Keap에 입력됩니다.

그래닛 베이의 경우, 질적인 측면에서 가장 큰 성과는 트레이너들이 Keap을 처음으로 실제로 사용하게 되었다는 점입니다. 두 번의 수동 설정 시도가 실패한 후, 세 번째 시도에서 자동 필드 설정을 통해 성공적으로 전환되었는데, 이는 트레이너들이 직접 설정 작업을 할 필요가 없었기 때문입니다. 트레이너들이 기존에 별도의 스프레드시트에 기록해 두었던 고객 정보, 즉 목표와 부상 이력 등이 Mindbody에 이미 입력되어 있었고 CRMConnect가 이를 자동으로 매핑해 준 덕분에 그대로 유지되었습니다.

이 수치는 예시일 뿐이며, 설정 시간 절약 효과는 사용자가 입력한 Mindbody 사용자 지정 필드 수와 기존 필드 이름 지정 방식의 일관성에 따라 크게 달라집니다.

건설업체 테이크아웃

  • 복사할 내용: 자동화된 필드 생성 기능을 활용하고 굳이 직접 필드를 만들려고 애쓰지 마세요. Mindbody에서 제공하는 필드보다 "더 나은" Keap 필드를 만들고 싶은 유혹이 들겠지만, 그런 유혹에 넘어가지 마세요. 처음 60일 동안은 통합 기능에 내장된 필드를 그대로 사용하고, 그 이후에는 구체적인 자동화 작업에 필요한 경우에만 필드를 추가하세요.
  • 주목해야 할 점: 자동 필드 생성 기능은 표준 건강 데이터 포인트를 처리합니다. 완전히 사용자 정의된 Mindbody 인덱스는 CRMConnect 구성 단계에서 매핑해야 합니다. 또한, 예약 및 판매 정보는 Mindbody와 Keap 간에 단방향으로 동기화되며, 고객 프로필만 양방향으로 동기화됩니다. Keap에서 Mindbody 필드 변경을 시도하지 마십시오.
  • 이 패턴이 맞지 않을 때: 클라이언트 데이터가 최소한으로 구성된 소규모 스튜디오(예: 단순 방문 상담, 목표 추적 기능 없음)는 풍부한 필드 데이터 세트를 활용하기 어렵습니다. 표준 데이터 세트만으로도 충분하기 때문입니다. 반대로, 매우 특수한 Mindbody 데이터 모델을 사용하는 스튜디오는 비표준 인덱스를 제대로 매핑하기 위해 컨설팅 시간이 필요할 수 있습니다.
