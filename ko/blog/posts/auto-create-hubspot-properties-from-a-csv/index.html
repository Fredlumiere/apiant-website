Claude 코드를 사용하여 CSV 파일에서 HubSpot 속성을 자동으로 생성하세요

Fred Lumiere 2024년 9월 18일 3분 읽기
#허브스팟

APIANT 기반의 무료 가져오기 자동화 도구를 사용하여 HubSpot 속성(연락처, 거래 또는 회사)을 자동으로 생성하는 방법입니다.

대상 고객: HubSpot 관리자

HubSpot 관리자를 위한 무료 APIANT 계정으로 CSV 파일을 사용하여 HubSpot 속성을 자동 생성하는 단계입니다.

먼저 APIANT 계정이 필요합니다…

HubSpot 관리자이시고 HubSpot 관리자용 무료 APIANT 계정을 원하시나요? 그렇다면 아래에서 신청서를 제출하세요.

이름*

성*

직책*

이메일*

휴대폰 번호*

회사명*

타겟 솔루션

그런 다음 이 구글 시트를 복사하고 편집하세요.

여기 있습니다 구글 스프레드시트 링크.

원하는 만큼 행을 추가하세요.

속성을 생성할 HubSpot 개체를 선택하세요.

  • 연락하다
  • 거래
  • 회사

속성 그룹 이름을 지정하세요.

속성을 목록에 추가하고 HubSpot에서 사용자 지정 속성을 만들지 않으려면 "아니요"를 선택하여 당분간 해당 속성을 무시할 수 있습니다.

표시 이름 또는 API 이름을 선택하세요.

드롭다운 메뉴에서 속성 유형을 선택하세요.

  • 날짜 선택기
  • 날짜 및 시간
  • 드롭다운 선택
  • 여러 줄 텍스트
  • 다중 선택
  • 숫자 필드
  • 한 줄 텍스트
  • 단일 켜짐/꺼짐 체크박스
  • HubSpot 네이티브

마지막으로 부동산 설명을 입력하세요.

각 속성별로 행 하나씩 모든 정보를 입력했으면 시트를 CSV 파일로 다운로드하세요.

APIANT 계정에 템플릿 자동화 기능을 설치하세요.

여기 있습니다 링크 템플릿이라고 불리는 CSV 파일에서 HubSpot 사용자 지정 속성을 생성합니다.

설치가 완료되면 메뉴에서 HubSpot 허브를 연결하세요.

시스템의 공개 앱을 선택하고 허브에 로그인하세요.

자동화 기능을 켜세요

이것은 자동화 기능이므로 재생 버튼을 누르세요. 양식 앱 기반 트리거

CSV 파일을 업로드하려면 클릭하세요.

속성이 자동으로 생성되고 보고서가 생성됩니다.

자동화 설정을 필요에 따라 자유롭게 수정하세요(드롭다운 메뉴나 다중 선택 항목에 값을 추가하는 것도 가능합니다).
