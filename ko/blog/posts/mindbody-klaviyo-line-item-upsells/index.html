고가 상품 추가 판매를 위한 Mindbody와 Klaviyo 간의 품목별 구매 동기화

Fred Lumiere 2024년 11월 20일 5분 읽기
#피트니스 & 웰빙#심신#클라비요#CRMConnect#데이터 엔진

단일 판매 필드가 업셀링 로직을 무력화시키는 이유

고가의 웰니스 패키지는 단일 상품으로 판매되지 않습니다. 6,200달러짜리 12주 리트리트 패키지에는 보통 기본 숙박, 식사, 일일 수업, 개인 세션 패키지, 그리고 선택 사항인 추가 서비스(사운드 배스, 마사지 크레딧, 코치와의 1:1 코칭)가 포함됩니다. 청구서의 모든 항목은 추가 판매, 교차 판매, 그리고 갱신 기회입니다.

문제는 CRM 시스템이 주문 총액만 볼 때 발생합니다. 예를 들어, 실버 펀 웰니스 리트리트(Silver Fern Wellness Retreat)는 12주 단위로 진행되는 4,000달러에서 8,000달러 상당의 패키지를 판매한다고 가정해 보겠습니다. Klaviyo 시스템은 아무런 수정 없이도 고객이 지난 화요일에 5,800달러를 결제했다는 사실만 확인할 수 있습니다. 하지만 패키지에 마사지 크레딧 3회가 포함되어 있고 개인 코칭 세션은 전혀 포함되어 있지 않다는 사실은 알 수 없습니다. 따라서 구매 후 프로세스는 일반적인 추가 판매 제안을 표시하거나(이미 해당 상품을 구매한 고객의 절반에게 불쾌감을 줄 수 있음), 아예 추가 판매 제안을 표시하지 않게 됩니다.

시중에서 판매되는 공구들이 놓치는 점

Mindbody의 판매 데이터에는 품목이 포함되어 있지만, 대부분의 범용 데이터 통합 도구는 Klaviyo에 도달하기 전에 판매 데이터를 단일 행으로 축소합니다. 그 이유는 대개 데이터 모델링 때문입니다. Klaviyo의 "주문 완료" 이벤트는 품목 배열을 예상하는데, Mindbody의 중첩된 판매 데이터를 해당 배열에 올바르게 (적절한 SKU, 가격 및 카테고리 태그를 사용하여) 변환하는 작업은 "빠른 Zap" 작업에서 생략되는 경우가 많습니다. 결과적으로 Klaviyo에는 품목이 없고, 추가 옵션이 표시되지 않으며, 업셀링 계산도 되지 않는 단일 행 주문이 표시됩니다.

APIANT 접근법

CRMConnect Mindbody와 Klaviyo에는 다음이 포함됩니다. 구매 및 매출 항목 동기화 이는 최상위 기능으로 제공됩니다. Mindbody에서 Klaviyo로의 판매 데이터는 각 품목이 그대로 유지된 채로 전송되므로 Klaviyo 프로필과 이벤트 페이로드는 세분화 및 흐름 로직을 위한 구조를 그대로 유지합니다.

APIANT 내부에 있는 통합 데이터 처리 엔진은 형식에 구애받지 않습니다. Mindbody 판매 페이로드는 XPath(개방형 W3C 표준)를 통해 중첩 구조를 유지하면서 Klaviyo의 이벤트 스키마로 매핑됩니다. 각 품목에는 고유한 SKU, 가격, 카테고리 및 수량이 포함되어 있습니다. 바로 이 부분이 업셀링 로직을 가능하게 하는 핵심 요소입니다.

API 앱의 세 가지 기능이 여기서 중요한 역할을 합니다.

  • 구매 및 매출 항목 동기화 구조화된 항목 목록의 경우.
  • 실시간 고객 프로필 동기화 따라서 구매자 프로필은 최신 정보이며 세분화가 가능합니다.
  • 방문 추적 따라서 구매 후 관리 전략은 고객이 실제로 구매한 제품을 사용하기 시작했는지 여부에 따라 세분화될 수 있습니다.

Klaviyo에서 품목별 동기화는 어떻게 이루어지나요?

클라비요에서 진행되는 리트릿 패키지 구매는 구조화된 이벤트로 진행됩니다. 대략적인 형태는 다음과 같습니다.

{
  "event": "Placed Order",
  "customer_properties": {
    "$email": "client@example.com",
    "mindbody_client_id": "MB-44918"
  },
  "properties": {
    "OrderId": "MB-INV-71204",
    "Total": 5800.00,
    "Currency": "USD",
    "Items": [
      { "SKU": "RETREAT-12W-DLX", "Name": "12-Week Deluxe Package", "Price": 4200, "Category": "Retreat Base" },
      { "SKU": "MEAL-VEG-12W", "Name": "Vegetarian Meal Plan", "Price": 800, "Category": "Meal Plan" },
      { "SKU": "MASSAGE-CR-3", "Name": "Massage Credits x3", "Price": 450, "Category": "Add-On" },
      { "SKU": "SOUND-BATH-1", "Name": "Sound Bath Session", "Price": 350, "Category": "Add-On" }
    ]
  }
}

이제 Klaviyo는 "개인 코칭 없이 12주 패키지를 구매한 고객", "식단 플랜은 구매했지만 추가 옵션은 구매하지 않은 고객", 또는 "5,000달러 이상을 지출했지만 마사지 크레딧을 전혀 사용하지 않은 고객"과 같이 고객 유형을 세분화할 수 있습니다.

고가 패키지 상품에 대한 추가 판매 상품 설계

업셀링 흐름에는 세 가지 트리거가 있으며, 각각은 다음 사항과 연결되어 있습니다. 없어진 품목 목록에서:

  1. 개인 코칭은 구매하지 않았습니다. 워크숍 시작 3일째 되는 날, 수석 코치와의 1:1 소개 코칭을 할인된 가격으로 제공하는 이메일을 보내세요. 이미 코칭 상품이 포함된 고객은 제외하세요.
  2. 식단 플랜만 구매했고, 추가 옵션은 없습니다. 7일째 되는 날, 사운드 배스와 마사지 이용권 패키지 가격에 대한 "알고 계셨나요?" 이메일을 보내세요.
  3. 추가 옵션은 구매했지만 향후 14일 이내에 예정된 수업은 없습니다. 엄선된 일정으로 재참여 유도 이메일을 발송하세요.

각 지점은 프로필에 이미 등록된 품목을 기준으로 정보를 읽어옵니다. 이미 구매한 상품을 추가로 판매하는 일은 없습니다. 이 점만으로도 고가 상품 구매자들이 구독을 취소하지 않도록 하는 데 충분합니다.

반복 구매 시 로열티 보상 혜택 중첩 적용

두 번째 흐름은 동일한 데이터를 사용하지만 더 긴 기간에 걸쳐 실행됩니다. 항목별 내역을 사용하여 범주별 평생 가치를 계산합니다.

  • 평생 마사지 이용액이 1,500달러 이상인 고객님께는 우선 예약 혜택을 제공하는 "창립자" 등급으로 초대합니다.
  • 12개월 동안 두 번의 본격적인 수련회 참가 시, 세 번째 수련회 식사는 무료로 제공됩니다.
  • 리트릿 1회 이용권과 추가 옵션 4가지: 맞춤 코드를 사용하여 추천 요청을 보내세요.

이 계산은 Klaviyo에서 다음을 사용하여 실행됩니다. Items 각 "주문 완료" 이벤트에 대한 배열입니다. 통합 기능은 배열의 정확성을 유지하는 역할을 합니다.

4천 달러~8천 달러 패키지의 대표적인 평균 주문 금액(AOV) 상승 요인

이 이미지는 예시용 합성 이미지이며 실제 고객의 모습이 아닙니다.

  • 추가 상품 첨부율 기준치(일반 구매 후 이메일): 약 8~12%.
  • 품목별 추가 판매를 통한 부가 상품 부착률: 20~28% 범위로 상승했는데, 이는 주로 적절한 상품이 적절한 구매자에게 전달되었기 때문입니다.
  • 리트릿 참가 등록당 평균 주문 금액(AOV): 대표 참가자 집단 대비 6~11% 상승.
  • 구매 후 과정에서의 구독 취소율이 낮아졌습니다. 이는 차단 로직이 "이미 구매하신 상품을 추가로 판매하려고 합니다"라는 문제를 방지하기 때문입니다.

이것들은 마법이 아니라 기계적인 원리에 의한 것입니다. 항목별 세부 사항을 통해 정확한 타겟팅이 가능해지고, 정확한 타겟팅이 리프트를 작동시키는 원동력이 됩니다.

  • 현재 상황을 바탕으로 업셀링 로직을 구축하세요. 결석한 아이템 배열에서 가져온 것입니다. 바로 그곳에 구매 가능한 다음 단계가 있습니다.
  • 고객 충성도 등급을 설정할 때는 평생 동안 이용한 항목별 지출액(마사지, 코칭, 식사)을 활용하세요. 패키지형 휴양 사업에는 총 매출액만으로는 너무 단순합니다.
