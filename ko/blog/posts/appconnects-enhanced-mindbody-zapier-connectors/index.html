AppConnect의 향상된 Mindbody-Zapier 커넥터

Fred Lumiere 2025년 3월 10일 5분 읽기
#심신#피트니스 & 웰빙#자피어#앱커넥트

AppConnect의 사전 구축 커넥터에 대한 흥미로운 개선 사항: 더 많은 데이터, 더 많은 가능성

AppConnect의 사전 구축된 커넥터에 대한 중요한 개선 사항을 발표하게 되어 기쁩니다. 대부분의 커넥터가 필요에 따라 추가 API 호출을 수행하도록 업그레이드되어 데이터가 Zapier에 도달하기 전에 중요하고 포괄적인 정보를 받을 수 있게 되었습니다.

예를 들어, "06 - 신규 멤버십(즉시) - Mindbody → Zapier" 커넥터에는 이제 자세한 고객 정보가 포함되어 있어 고객과의 소통을 효과적으로 개인화할 수 있습니다.

여기를 클릭하여 모든 커넥터를 확인하세요.

다음은 AppConnect의 향상된 커넥터 전체 목록이며, 각 커넥터에 대한 자세한 설명서 링크가 포함되어 있습니다.

고객 관리:

  • 신규 클라이언트(즉시)

사용 사례: Mindbody 신규 고객을 이메일 마케팅 플랫폼에 자동으로 추가하여 맞춤형 환영 이메일을 발송하세요.

  • 클라이언트 업데이트(즉시)

사용 사례: Mindbody에서 업데이트된 고객 정보를 CRM 시스템에 동기화하여 모든 기록이 최신 상태인지 확인하십시오.

  • 클라이언트 업데이트됨(가져오기)

사용 사례: 정기적으로 고객 데이터를 가져와 모든 통합 플랫폼에서 정확한 기록을 유지합니다. 여기에는 정확한 회원 상태 정보도 포함됩니다.

  • 비활성화된 클라이언트(즉시)

사용 사례: 활동이 중단된 고객을 메일링 리스트에서 삭제하여 타겟 고객에게 효과적이고 관련성 있는 메시지를 전달하세요.

⠀ 수업 예약 관리:

  • 신규 수업 예약(즉시)

사용 사례: 고객이 수업을 예약한 직후 확인 이메일이나 SMS 알림을 보내세요.

  • 수업 예약 업데이트 (즉시)~

사용 사례: 수업 예약 시간이나 장소 변경 등 변경 사항이 있을 경우 고객에게 알려주세요.

  • 수업 예약 취소 (즉시)

사용 사례: 고객이 수업 예약을 취소할 경우 후속 연락이나 설문조사를 발송하세요.

⠀ 예약 관리:

  • 새로운 예약 (즉시)

사용 사례: 새로운 약속을 직원들의 캘린더에 자동으로 추가하여 예정된 세션을 직원들이 알 수 있도록 하세요.

  • 업데이트된 예약 시스템 (즉시 이용 가능)

사용 사례: Mindbody에서 변경 사항이 발생하면 예약 시스템에서도 예약 세부 정보를 업데이트하세요.

  • 예약 취소 (즉시)

사용 사례: 취소 사항이 발생하면 직원들에게 알려 일정을 조정하도록 하십시오.

⠀ 영업 관리:

  • 신규 판매 (즉시)

사용 사례: 재무 추적을 간소화하려면 회계 소프트웨어에 신규 매출을 기록하세요.

  • 새로운 판매 품목 (즉시)

사용 사례: 판매된 품목을 기준으로 재고 관리 시스템의 재고 수준을 업데이트하세요.

  • 신규 판매 품목별 결제 (즉시)

사용 사례: 상세한 재무 보고를 위해 결제 수단과 금액을 모니터링하십시오.

⠀ 고객 계약 관리:

  • 신규 고객 계약 (즉시)

사용 사례: 고객이 신규 계약을 체결하면 환영 자료 발송과 같은 온보딩 워크플로를 시작합니다.

  • 고객 계약서 업데이트 (즉시)

사용 사례: 계약 업데이트에 따라 다른 시스템에서 클라이언트의 접근 권한 또는 권한을 조정하십시오.

  • 고객 계약 취소 (즉시)

사용 사례: 고객이 계약을 해지할 때 고객 유지 전략이나 피드백 요청을 실행하세요.

⠀ 회원 관리:

  • 신규 멤버십(즉시)

사용 사례: 신규 회원에게 회원 가입 정보 및 혜택을 포함한 맞춤형 환영 이메일을 보내세요.

  • 멤버십 취소 (즉시)

사용 사례: 취소 사유를 파악하고 재참여를 위한 인센티브를 제공하기 위해 후속 연락을 취하십시오.

⠀ 수업 시간표 관리:

  • 새 수업 일정(즉시)

사용 사례: 새로운 수업 일정을 웹사이트나 앱에 자동으로 업데이트하여 고객에게 정보를 제공하세요.

  • 클래스 업데이트(즉시)

사용 사례: 수강생들에게 강사나 장소 등 수업 세부 정보 변경 사항을 알려주세요.

  • 최신 수업 시간표 (즉시 업데이트)

사용 사례: 혼란을 방지하기 위해 모든 플랫폼에 최신 수업 시간표가 반영되도록 하십시오.

  • 수업 일정 취소 (즉시)

사용 사례: 수업 취소 사실을 고객에게 알리고, 참여를 유지하기 위한 대안을 제시하십시오.

⠀ 위치 관리:

  • 새 위치(즉시)

사용 사례: 새로운 사업장 위치를 디렉토리 목록 및 마케팅 자료에 자동으로 추가하세요.

  • 위치 정보 업데이트(즉시)

사용 사례: 모든 플랫폼에서 위치 정보를 업데이트하여 일관성을 유지하십시오.

  • 위치 비활성화(즉시)

사용 사례: 폐점한 매장은 온라인 목록에서 삭제하여 고객 혼란을 방지하세요.

Zapier에서 Mindbody 자동화(추가 기능)로 전환:

  • Mindbody에서 클라이언트를 추가하거나 업데이트합니다.

사용 사례: 웹 양식을 통해 새로운 잠재 고객 정보가 수집되면 Mindbody에서 해당 정보를 자동으로 추가하거나 업데이트합니다.

  • ~ Mindbody에서 수업에 클라이언트를 추가하세요

사용 사례: 다른 애플리케이션에서 수행한 작업(예: 구매 완료)을 기반으로 고객을 자동으로 수업에 등록합니다.

이러한 개선 사항을 통해 더욱 정교하고 데이터 기반의 자동화를 구축할 수 있으며, 이를 통해 비즈니스를 더욱 원활하고 효율적으로 운영할 수 있습니다.
