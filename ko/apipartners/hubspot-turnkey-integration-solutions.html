HubSpot 개요

HubSpot은 마케팅, 영업 및 서비스를 하나의 CRM으로 통합하는 고객 플랫폼입니다. CRMConnect는 이미 사용 중인 플랫폼의 데이터를 HubSpot으로 가져와 연락처, 목록 및 워크플로가 고객의 실제 활동을 반영하도록 합니다.

API App의 차별점은?

API 앱은 단순한 커넥터가 아닙니다. HubSpot을 비즈니스 운영 플랫폼과 통합하는 전문가가 개발한 솔루션입니다. 복잡한 워크플로우를 정확하게 처리하도록 설계되어 효율성을 높이고 새로운 기회를 창출하며 비즈니스 성장을 촉진합니다.

심층 통합 기능

지능형 데이터 처리:
대량 예약, 취소, 일정 변경과 같은 복잡한 시나리오를 처리하기 위한 고급 로직
실시간 동기화:
연결된 모든 시스템에서 데이터 정확성을 유지하는 자동화된 양방향 업데이트
산업별 로직:
각 CRMConnect 앱은 해당 플랫폼에 맞춰 설계되었습니다. Mindbody에서는 고객, 방문 및 회원 정보를, Cliniko에서는 환자 및 예약 정보를, DonorPerfect에서는 기부자 및 기부금 정보를 관리할 수 있습니다.
구성 가능한 워크플로:
기술적 전문 지식 없이도 사용자 지정 가능한 비즈니스 규칙 및 자동화 경로

플랫폼을 선택하세요

현재 HubSpot에 연결되는 CRMConnect 앱은 플랫폼별로 하나씩 총 세 가지가 있습니다. 사용 중인 앱을 선택하세요.

Mindbody와 HubSpot

자주 묻는 질문

HubSpot CRMConnect는 어떤 플랫폼과 호환되나요?

오늘 세 가지: 마인드바디 + 허브스팟, 클리니코 + 허브스팟및 DonorPerfect + HubSpot각각은 해당 플랫폼에 맞춰 개발되고 사용자 계정에 설정된 별도의 앱입니다.

HubSpot 앱 마켓플레이스에서 '설치'를 클릭했습니다. 그 다음에는 어떤 일이 발생하나요?

위 목록에서 사용하시는 플랫폼을 선택하고 상담 예약을 하세요. 저희가 고객님의 HubSpot 계정과 플랫폼 계정을 연결하고, 동기화할 항목을 확인한 후, CRMConnect 설정을 도와드립니다.

HubSpot에는 어떤 데이터가 수집되나요?

플랫폼에 따라 다릅니다. CRMConnect는 Mindbody의 고객, 방문, 구매 및 멤버십 정보, Cliniko의 환자, 예약 및 청구서, DonorPerfect의 기부자 프로필 및 기부 내역을 HubSpot으로 가져옵니다. 각 제품 페이지에 동기화되는 항목이 나열되어 있습니다.

동기화된 데이터를 기반으로 자동화를 구축할 수 있나요?

네. 데이터가 HubSpot에 입력되면 다른 HubSpot 데이터와 마찬가지로 HubSpot 워크플로를 사용하여 자동화를 구축할 수 있습니다.

HubSpot이나 제가 사용하는 플랫폼의 API가 변경되면 어떻게 되나요?

APIANT는 상위 API 변경 사항을 모니터링하고 지속적으로 통합을 유지 관리합니다. 로직이 중앙 집중화되어 있으므로 수정 사항이나 업그레이드가 해당 API 앱을 사용하는 모든 고객에게 계정별 마이그레이션 없이 한 번에 배포됩니다.
