클리니코 개요

Cliniko는 전 세계 95개국 이상에서 수천 명의 의료진이 사용하는 완벽한 진료 관리 애플리케이션입니다. 일정, 진료 기록, 청구서, 결제 등을 관리하세요. 개인 의료진, 대규모 팀 및 그 사이의 모든 의료진에게 적합합니다.

API App의 차별점은?

API 앱은 단순한 커넥터가 아니라 Cliniko와 사용 중인 도구를 원활하게 통합하는 강력하고 전문가가 만든 솔루션입니다. 복잡한 워크플로를 정밀하게 처리하도록 설계되어 효율성을 높이고, 새로운 기회를 창출하며, 비즈니스 성장을 촉진합니다.

심층 통합 기능

지능형 데이터 처리:
대량 예약, 취소, 일정 변경과 같은 복잡한 시나리오를 처리하기 위한 고급 로직
실시간 동기화:
연결된 모든 시스템에서 데이터 정확성을 유지하는 자동화된 양방향 업데이트
산업별 로직:
환자 기록, 진료 기록, 청구서, 여러 의료진 관리와 같은 의료 서비스 관련 시나리오를 처리하는 기본 제공 기능
구성 가능한 워크플로:
기술적 전문 지식 없이도 사용자 지정 가능한 비즈니스 규칙 및 자동화 경로

Cliniko 및 HubSpot

Cliniko와 HubSpot 간에 환자 데이터를 원활하게 동기화합니다. 인구 통계, 예약 내역 및 재무 지표를 자동으로 전송하여 타겟 커뮤니케이션으로 환자 참여를 강화합니다. 수동 데이터 입력을 제거하고 환자 관계의 완전한 뷰로 의료 기관을 강화하세요.

Cliniko 및 Salesforce

강력한 양방향 통합을 제공합니다. 15분마다 즉각적인 Salesforce-Cliniko 동기화 및 Cliniko-Salesforce 업데이트를 통해 강력한 양방향 통합을 제공합니다. 고급 매칭 및 중복 제거 기능을 통해 환자, 예약, 가족, 클리닉 위치를 체계적으로 관리하여 정확한 데이터, 향상된 환자 관리, 간소화된 클리닉 운영을 보장합니다. 전 세계적으로 신뢰받는 솔루션.

자주 묻는 질문

어떤 Cliniko 데이터가 동기화되는지, 그리고 단방향인지 양방향인지 궁금합니다.

클리니코 API 앱은 환자 프로필, 예약(과거 및 예정), 치료 세부 정보, 청구서 및 결제 내역, 의료진 배정 정보, 사용자 지정 필드를 동기화합니다. 동기화는 양방향으로 이루어지며, CRM에서 생성된 새로운 잠재 고객은 클리니코에 환자로 등록될 수 있고, 클리니코의 환자 활동 내역은 자동으로 CRM으로 다시 전송됩니다.

APIANT는 보호 대상 의료 정보를 어떻게 처리하나요?

모든 Cliniko 배포는 전용의 격리된 APIANT 서버에서 실행됩니다. 테넌트를 공유하지 않으므로 다른 고객의 워크로드와 데이터가 혼합되지 않습니다. 자격 증명은 암호화되고, 웹훅 엔드포인트는 HTTPS만 사용하며, 관리 콘솔에서 역할 기반 제어를 통해 액세스 권한이 관리됩니다. 특정 규정 준수 요구 사항(HIPAA, GDPR, 지역별 개인정보 보호법)이 있는 경우, 귀사의 의료 환경에 적합한 배포 구성에 대해 저희 팀과 상담하십시오.

저희는 여러 명의 의료진과 여러 지점을 보유하고 있습니다. 하나의 통합 시스템으로 이 모든 것을 관리할 수 있을까요?

네. 하나의 CRM 계정으로 여러 클리니코(Cliniko) 사업체 및 의료진과 동기화할 수 있습니다. 환자는 진료 장소와 담당 의료진에 따라 CRM에 태그되며, 모든 의료진의 진료 기록이 일관성 있게 유지됩니다. 이는 여러 의료진이 근무하는 클리닉, 지역 네트워크, 그리고 여러 지역에 걸쳐 보고하는 의료 관련 그룹에 중요한 기능입니다.

Cliniko는 현재 APIANT를 통해 어떤 CRM 시스템과 연결되어 있습니까?

현재 세 가지 완벽한 Cliniko API 앱(Cliniko + HubSpot, Cliniko + ActiveCampaign, Cliniko + Salesforce)을 제공합니다. 각 앱은 해당 CRM의 기본 기능(연락처 필드, 사용자 정의 개체, 파이프라인, 자동화 트리거)을 모두 지원합니다. 다른 CRM 또는 마케팅 도구가 필요한 경우, AI Co-Pilot이 일반적으로 며칠 내에 커넥터를 구축해 드립니다.

환자 후속 관리, 예약 불참자 복구, 치료 알림 등을 자동화할 수 있을까요?

네. 예약 상태, 치료 이력, 방문 날짜가 실시간으로 CRM에 전송되므로, 예약 불참, 후속 조치 지연, 치료 계획 완료 등 Cliniko에서 발생하는 모든 이벤트에 대해 CRM의 기본 도구(HubSpot 워크플로, ActiveCampaign 자동화, Salesforce Flow)를 사용하여 자동화를 구축할 수 있습니다. 메시지 처리는 CRM에서 담당하고, APIANT는 데이터의 정확성을 유지합니다.

설치에는 실제로 얼마나 시간이 걸리나요?

일반적인 단일 진료소 구축의 경우, Cliniko와 CRM 계정 연결 및 필드 매핑 확인 후 며칠 내에 설정이 완료됩니다. 여러 지점을 운영하는 진료소나 맞춤 설정이 많이 포함된 클리닉의 경우, 통합 구축 자체보다는 구성 작업에 시간이 더 소요됩니다. 저희 팀이 온보딩 과정을 안내해 드립니다.

클리니코가 API 변경 사항을 배포하면 어떻게 되나요?

APIANT는 상위 API 변경 사항을 모니터링하고 통합을 지속적으로 유지 관리합니다. 로직이 중앙 집중화되어 있기 때문에(설정 vs. 로직 아키텍처), 수정 또는 업그레이드 사항이 해당 API 앱을 사용하는 모든 고객에게 개별 클리닉 마이그레이션 없이 동시에 배포됩니다. 따라서 자체 통합을 업데이트하라는 알림을 받지 않습니다.
