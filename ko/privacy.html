3. MCP 서버 인프라

요약하자면, APIANT는 고객이 자체 전용 서버 및 도메인에 배포할 수 있는 MCP(모델 컨텍스트 프로토콜) 서버 인프라를 제공합니다. 고객의 APIANT 기반 MCP 서버를 통해 데이터가 처리될 때, 요청된 작업을 실행하는 데 필요한 데이터만 처리합니다. MCP 상호 작용 데이터를 사용하여 AI 모델을 학습시키거나, 광고를 제공하거나, 사용자 프로필을 구축하지 않습니다.

APIANT MCP 서버 작동 방식

APIANT는 고객("빌더")이 자체 전용 인프라 및 도메인에 MCP 호환 서버를 배포할 수 있도록 지원합니다. 이러한 MCP 서버를 통해 빌더의 최종 사용자는 자연어를 사용하여 AI 플랫폼(예: Anthropic의 Claude)을 통해 빌더의 통합 및 자동화 기능과 상호 작용할 수 있습니다. 최종 사용자가 빌더의 MCP 서버에 연결하면 AI 플랫폼이 빌더의 APIANT 기반 서버로 도구 호출 요청을 보냅니다. APIANT는 기본 플랫폼 인프라를 제공하며, 최종 사용자는 APIANT에 직접 연결하는 것이 아니라 빌더의 서버에 연결합니다.

MCP 서버를 통해 처리되는 데이터는 무엇입니까?

APIANT 기반 MCP 서버를 통해 데이터가 처리될 때 다음과 같은 데이터 범주가 포함될 수 있습니다.

  • 인증 자격 증명: OAuth 2.0 토큰 또는 기타 자격 증명은 개발자 서버에 대한 접근 권한을 확인하고 부여하는 데 사용됩니다.
  • 도구 호출 매개변수: 요청된 각 작업을 실행하는 데 필요한 구체적인 입력값(예: 애플리케이션 이름, 워크플로 구성 또는 검색 쿼리).
  • 도구 호출 응답: 빌더 서버가 요청에 대한 응답으로 반환하는 결과는 AI 플랫폼으로 전달되어 최종 사용자에게 표시됩니다.
