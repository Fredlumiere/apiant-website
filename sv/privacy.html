3. MCP-SERVERINFRASTRUKTUR

Kort sagt: APIANT tillhandahåller MCP-serverinfrastruktur (Model Context Protocol) som våra kunder distribuerar på sina egna dedikerade servrar och domäner. När dina data behandlas via en kunds APIANT-drivna MCP-server behandlar vi endast de data som är nödvändiga för att utföra de begärda åtgärderna. Vi använder inte MCP-interaktionsdata för att träna AI-modeller, visa reklam eller bygga användarprofiler.

Hur APIANT MCP-servrar fungerar

APIANT gör det möjligt för sina kunder ("byggare") att driftsätta MCP-kompatibla servrar på sin egen dedikerade infrastruktur och domäner. Dessa MCP-servrar gör det möjligt för byggarens slutanvändare att interagera med byggarens integrationer och automatiseringar via AI-plattformar (som Claude av Anthropic) med hjälp av naturligt språk. När en slutanvändare ansluter till en byggares MCP-server skickar AI-plattformen verktygsanropsförfrågningar till byggarens APIANT-drivna server. APIANT tillhandahåller den underliggande plattformsinfrastrukturen; slutanvändare ansluter till byggarens server, inte direkt till APIANT.

Vilka data behandlas via MCP-servrar

När data bearbetas via en APIANT-driven MCP-server kan följande datakategorier vara inblandade:

  • Autentiseringsuppgifter: OAuth 2.0-tokens eller andra autentiseringsuppgifter som används för att verifiera identitet och auktorisera åtkomst till byggarens server.
  • Parametrar för verktygsanrop: De specifika indata som krävs för att utföra varje begärd åtgärd (till exempel programnamn, arbetsflödeskonfigurationer eller sökfrågor).
  • Svar på verktygsanrop: Resultaten som returneras av byggarens server som svar på förfrågningar, vilka vidarebefordras tillbaka till AI-plattformen för visning för slutanvändaren.

APIANT gör inte ta emot den fullständiga texten från konversationer mellan slutanvändare och AI-plattformar. Endast den strukturerade verktygsanropsdata som krävs för att utföra specifika åtgärder bearbetas på byggarens APIANT-drivna server.

Hur vi använder MCP-data

APIANT, som leverantör av plattformsinfrastruktur, använder data som behandlas via MCP-servrar enbart för att:

  • Tillhandahålla och driva plattformsinfrastrukturen för byggarens räkning
  • Övervaka serverprestanda, drifttid och felfrekvenser
  • Felsök problem och förbättra tillförlitligheten hos MCP-serverinfrastrukturen
  • Följa tillämpliga rättsliga skyldigheter

Hur vi lagrar och behåller MCP-data

  • Autentiseringstokens lagras i minnet under hela sessionen och sparas inte efter frånkoppling.
  • Verktygssamtalloggar (parametrar och svar) kan sparas under en begränsad period för felsökning och operativa ändamål. Dessa loggar rensas inom 90 dagar om inte en längre lagringsperiod krävs enligt lag.
  • Inga användarprofiler är byggda från MCP-interaktionsdata.

Vad vi INTE gör med MCP-data

  • Vi gör inte använda MCP-interaktionsdata för att träna AI- eller maskininlärningsmodeller.
  • Vi gör inte sälja MCP-interaktionsdata till tredje part.
  • Vi gör inte använda MCP-interaktionsdata för reklam, profilering eller marknadsföringsändamål.
  • Vi gör inte dela MCP-interaktionsdata med tredje part förutom i den utsträckning det är nödvändigt för att tillhandahålla Tjänsterna eller enligt lag.

Dina rättigheter gällande MCP-data

Om du är slutanvändare av en byggares APIANT-drivna MCP-server, vänligen kontakta byggaren direkt angående dina datarättigheter. Om du är APIANT-kund (byggare) kan du begära åtkomst till, korrigering eller radering av personuppgifter som behandlas via din MCP-serverinfrastruktur genom att kontakta oss på privacy@apiant.comSe "VILKA ÄR DINA RÄTTIGHETER TILL SEKRETESS?" nedan för ytterligare information.
