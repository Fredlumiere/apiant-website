将 Mindbody 中的订单明细同步到 Klaviyo，用于高价追加销售

Fred Lumiere 2024年11月20日 阅读时间：5分钟

为什么单一销售字段会扼杀追加销售逻辑

高价健康套餐并非单一产品。一个价值 6200 美元的十二周静修套餐通常包含基本住宿、膳食计划、每日课程额度、私人疗程套餐以及可选附加项目（例如声波浴、按摩券、一对一教练指导）。账单上的每一项都蕴含着追加销售、交叉销售和续订的机会。

当你的客户关系管理系统（CRM）只能看到订单总额时，问题就出现了。假设：银蕨健康静修中心（Silver Fern Wellness Retreat，仅举例）以12周为一个周期，销售4000美元至8000美元的套餐。未经任何修改的Klaviyo系统只能看到一位客户上周二支付了5800美元。但Klaviyo无法看到该套餐包含三次按摩服务，却不包含任何私人辅导课程。因此，售后流程要么触发通用的追加销售信息（这会惹恼一半已经购买了被追加销售产品的买家），要么根本不触发。

现成工具的不足之处

Mindbody 的销售数据包含多个商品项，但大多数通用的数据整合工具会在将销售数据发送到 Klaviyo 之前将其合并为一行。原因通常是数据建模问题：Klaviyo 的“已下单”事件需要一个商品数组，而将 Mindbody 嵌套的销售数据正确桥接到该数组（包含正确的 SKU、价格和类别标签）这类工作通常会被“快速 Zap”工具忽略。最终导致 Klaviyo 中只显示一行订单，没有商品项，无法显示附加产品，也无法计算追加销售。

APIANT 方法

CRMConnect Mindbody 到 Klaviyo 包括 采购和销售明细同步 作为一项一流功能，销售数据从 Mindbody 完整地流入 Klaviyo，每个销售明细项都保持不变，因此 Klaviyo 的用户画像和事件负载也完整地保留了细分和流程逻辑所需的结构。

APIANT 内部的统一数据处理引擎与数据格式无关。Mindbody 的销售数据通过 XPath（一种开放的 W3C 标准）映射到 Klaviyo 的事件模式中，且不会丢失嵌套结构。每个销售项目都包含自己的 SKU、价格、类别和数量。正是这些元素使得追加销售逻辑成为可能。

API 应用的三个功能在此起着决定性作用：

  • 采购和销售明细同步 用于结构化项目列表。
  • 实时同步客户端配置文件 因此，买家画像是最新的，并且可以进行细分。
  • 访问跟踪 因此，售后培育可以取决于客户是否真正开始使用他们购买的产品。

Klaviyo 中的行项目同步是什么样的

购买度假套餐后，Klaviyo 会将其视为一个结构化的活动。其大致形式如下：

{
  "event": "Placed Order",
  "customer_properties": {
    "$email": "client@example.com",
    "mindbody_client_id": "MB-44918"
  },
  "properties": {
    "OrderId": "MB-INV-71204",
    "Total": 5800.00,
    "Currency": "USD",
    "Items": [
      { "SKU": "RETREAT-12W-DLX", "Name": "12-Week Deluxe Package", "Price": 4200, "Category": "Retreat Base" },
      { "SKU": "MEAL-VEG-12W", "Name": "Vegetarian Meal Plan", "Price": 800, "Category": "Meal Plan" },
      { "SKU": "MASSAGE-CR-3", "Name": "Massage Credits x3", "Price": 450, "Category": "Add-On" },
      { "SKU": "SOUND-BATH-1", "Name": "Sound Bath Session", "Price": 350, "Category": "Add-On" }
    ]
  }
}

现在 Klaviyo 可以根据以下情况进行细分：“购买了 12 周套餐但没有私人教练”、“购买了膳食计划但没有附加服务”或“花费超过 5,000 美元但没有使用任何按摩积分”。

为高价套餐设计附加追加销售方案

追加销售流程有三个触发点，每个触发点都与以下内容相关： 丢失的 从明细项来看：

  1. 没有购买私人辅导。 静修活动开始三天后，发送邮件提供与资深教练一对一入门课程的折扣优惠。屏蔽所有商品清单中已包含教练服务项目的订单。
  2. 已购买套餐，无其他附加项目。 七天后，发送一封“你知道吗”电子邮件，介绍声浴和按摩积分，并提供捆绑价格。
  3. 已购买附加课程，但未来 14 天内没有预订课程。 根据预先设定的时间表触发重新互动邮件。

每个分支都只读取用户个人资料中已有的商品信息。不会向用户推销他们已经购买过的东西。仅此一点就足以防止高价买家取消订阅。

对重复购买商品进行多层忠诚度奖励

第二个流程使用相同的数据，只是时间窗口更长。使用明细项按类别计算生命周期价值：

  • 终身按摩消费超过 1500 美元：受邀加入“创始人”级别，享有优先预订权。
  • 十二个月内参加两次完整的静修活动：第三次静修活动免除餐费。
  • 一次度假体验，外加四项附加服务：使用个性化代码触发推荐请求。

该数学运算在 Klaviyo 中运行，使用 Items 每次“已下单”事件都会生成一个数组。集成功能的作用是确保数组的准确性。

4000-8000美元套餐的代表性平均订单价值提升

图片仅为示意图，并非真实客户：

  • 附加组件附加率基线（通用购买后电子邮件）：大约 8% 到 12%。
  • 附加销售率（通过感知商品明细进行追加销售）提升至 20% 至 28%，主要是因为合适的商品能够触达合适的买家。
  • 每次静修活动的平均价值：在代表性群体中提升 6% 至 11%。
  • 购买后流程中的退订率较低，因为抑制逻辑阻止了“我们正在向您推销您已经购买过的东西”的问题。

这些都由机制驱动，并非魔法。详细的项目清单使得精准定位成为可能。精准定位驱动着提升。

建筑商外卖

  • 务必确保 Mindbody 和 Klaviyo 之间逐项同步。在高价位产品中，汇总订单总额是营销的死胡同。
  • 基于以下内容构建你的追加销售逻辑： 缺席的 从 items 数组中。这就是可购买的下一步物品所在的地方。
  • 对于打包度假服务业务而言，使用终身类别消费（按摩、指导、餐饮）来划分会员等级过于简单粗暴。
