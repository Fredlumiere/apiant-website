自动 Zoom 点名：完善混合普拉提课程的考勤机制

ZoomConnect 的自动点名功能会在每次课程结束后将 Zoom 与会者登录到 Mindbody，从而恢复准确的套餐跟踪和续订触发机制。

为什么混合式考勤跟踪休息时间

一家混合式普拉提工作室开设线上线下混合课程，学员既有到工作室上课的，也有通过Zoom线上参与的。教练使用Mindbody iPad签到到工作室的学员。Zoom学员虽然出现在会议中，但Mindbody系统中却没有人记录他们的出勤情况。结果：出勤报告错误，会员卡的课程次数没有减少，一位参加了四节线上课程的学员，一个月后仍然显示她有十节课的课程记录。

最终，工作室老板在月底才发现此事，不得不通过交叉比对 Zoom 日志和 Mindbody 预订记录来补全 80 条出勤记录，并损失了本应已经收到的收入。

出勤率差异也会对市场营销产生后续影响。例如，一位参加了四节线上课程但出勤记录为零的会员，在工作室的自动化系统中会被识别为“流失风险会员”。工作室会向她发起挽回活动，但由于她每次都按时参加，所以活动效果并不理想。错误的数据会导致错误的营销策略，最终导致会员完全忽略工作室的邮件。

自动点名是如何运作的

Zoom 会在会议结束后生成参会者报告。Mindbody 也接受通过 API 写入参会记录。将两者通过 Zapier 连接起来，意味着要根据姓名或邮箱将 Zoom 参会者与 Mindbody 的预约进行匹配，但如果客户使用她丈夫的笔记本电脑加入会议，或者将她的名字输入为“Liz”而不是“Elizabeth”，匹配就会失败。

这些简单的解决方案会漏掉 15% 到 25% 的参会者。更糟糕的是，它们有时还会将参会者信息错误地分配给其他客户（例如，将丈夫的邮箱地址匹配到妻子的账户），这比完全漏掉参会者信息更严重，因为它会破坏数据。

DIY 工具忽略了隐私和用户同意这一层面。跨系统共享 Zoom 会议记录需要正确的 OAuth 权限范围、数据处理方式和数据保留策略。许多自制流程会将参会者列表存储在意想不到的地方，从而悄悄违反 Zoom 的服务条款。而专门设计的集成方案则会尊重权限范围，并将数据保留在集成方案的授权范围内。

APIANT 方法

ZoomConnect 的自动点名功能利用安全唯一的链接解决了这个问题。每位已预订的客户都会获得一个与其 Mindbody 预订绑定的唯一 Zoom 加入链接。当客户加入时，系统会通过该链接准确识别客户身份。课程结束后，ZoomConnect 会自动将客户的出勤情况记录到 Mindbody，减少其套餐次数，从而完成整个流程。

单设备访问控制功能可防止学员与朋友共享链接。该链接一次只能在一台设备上使用。例如，如果学员用手机加入，而她的丈夫试图用笔记本电脑加入，第二次尝试将被拒绝。这样既能保障收入安全，又无需讲师充当“门卫”。

迟到加入的处理本身就是一个值得解决的问题。例如，一位学员在60分钟的课程开始12分钟后加入，应该仍被计入出勤；而一位学员在课程最后5分钟加入，则可能不应该被计入出勤。ZoomConnect的出勤阈值可以根据课程类型进行配置。工作室只需设置一次规则（默认规则：在课程开始20分钟内加入，且至少持续15分钟，则计为出勤），系统就会始终如一地执行该规则。这样一来，无需教师进行主观判断，也不会出现不同课程之间规则不一致的情况。

取消操作的处理方式是对称的。如果学员在课程开始前两小时内取消预订，其专属链接将失效，候补名单上的学员将立即获得一个专属链接。这样，点名册上将以实际到场学员名单为准，而非最初的预订名单，从而避免了大多数考勤统计错误。

更新触发器终于按时触发

  1. 在 ZoomConnect 中启用“安全唯一链接”。默认情况下，每个链接只能连接一台设备。
  2. 开设混合式课程。到店学员照常使用 iPad 签到。线上学员点击提醒邮件中的链接。
  3. ZoomConnect 知道 Zoom 会议中有哪些人，因为每个链接都与身份绑定。
  4. 课程结束后，ZoomConnect 会将每位参与线上课程的学员的出勤情况记录到 Mindbody 系统中。课程访问量会相应减少。出勤报告会进行统计。

  5. 运行月末报告。数据无需回填即可匹配，因为它们一直都匹配。

  6. 设置每种课程类型的出勤阈值。 默认规则是“在开课后20分钟内加入，且至少参与15分钟”。30分钟的速成课程可能需要更严格的规则，而90分钟的研讨会可能需要更宽松的规则。

  7. 查看第一周的考勤报告。 将 ZoomConnect 的点名结果与工作室保留的任何手动记录进行比较。如果系统计数过多或过少，请调整阈值。

280 位客户时的代表套餐续订率

假设：一家混合式普拉提工作室每周开设 22 节混合课程，其中约 40% 的学员在线参与。采用自动点名后，在线参与率从约 78% 提升至约 99%。第一月，通过返还套餐收入（已参加但未扣减的课程）可收回约 1400 美元，之后保持零流失。工作室老板在月末核对学员出勤情况所需的时间也降至零。

会员体验方面有一项值得一提的改进。会员们相信他们的套餐使用次数会正确递减，因为工作室的报告与他们记忆中的到访次数相符。在前台询问剩余使用次数不再是讨价还价，而是变成了确认确认。对工作室系统的信任最终会转化为对工作室整体的信任。

值得了解的特殊情况

掉线重连是最棘手的情况。例如，一位学员的WiFi在课程中途断线，她通过手机重新加入。由于链接标识相同，ZoomConnect会将这视为同一位学员的出勤。系统不会重复计算她的出勤，也不会扣除她的出勤积分。

同一家庭成员共同观看（一次付费预订，两人同时观看）由单设备访问控制 (One-Device Access Control) 处理。系统仅允许付费客户观看，一同观看的配偶不会被重复计算。如果工作室希望明确允许家庭成员共同观看（有些工作室会提供此功能，但需支付少量额外费用），ZoomConnect 支持家庭成员双人配置。

在“不可取消”期限内取消的订单，其取消记录会与常规取消记录分开标记。工作室可根据其政策收取延迟取消费用。出勤记录会被正确标记为“延迟取消”，而不是“未到场”或“已到场”，从而确保报告的准确性。

建筑商外卖

  • 基于电子邮件的参会者匹配是行不通的。只有基于身份的链接才是可扩展的方法。
  • 未减价礼包造成的收入流失是隐形的，直到你发现它为止。大多数工作室都在进行收入流失，只是他们自己不知道流失了多少。
  • 每个链接限用一台设备并非惩罚，而是保护虚拟课堂收入的最低标准。
