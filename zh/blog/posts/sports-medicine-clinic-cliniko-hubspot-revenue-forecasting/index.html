使用 HubSpot 中的 Cliniko 发票流程为运动医学诊所构建实际收入预测

Fred Lumiere 2026年2月9日 阅读时间：4分钟
＃卫生保健#Cliniko#HubSpot#CRM连接#双向同步

每个发展中的诊所都会经历这样一个阶段：周一早上的预测表格不再是工具，反而成了累赘。首席财务官不得不手动重建它。医生们对表格上的数据感到困惑。领导层还在争论错误的数字，因为正确的数字已经过时四天了。最终，决策只能凭感觉做出。

举个例子：假设北点运动医学诊所是一家大型诊所，拥有8名医生，年营业额约为240万美元。计费活动记录在Cliniko发票系统中。销售渠道、交易和预测仪表盘则存储在HubSpot中。每周一，首席财务官会导出这两个系统的数据，在Excel中合并，计算30/60/90天预测，然后通过电子邮件发送出去。到了周三，数据就出错了。到了周五，没人再相信这些数据了。

为什么现成的工具在这里会失效

在这种情况下，标准做法是在 Cliniko 和 HubSpot 之间插入会计软件（例如 Xero 或 QuickBooks），然后在会计层之上构建预测模型。这种方法适用于税务预测，但不适用于运营预测，因为会计层是基于开具发票或收到现金进行数据记录的，而不是基于预约安排的。等到收入数据进入 QuickBooks 时，预测的窗口期已经关闭了。

另一种常见模式是，将 Cliniko API 生成的自定义 BI 仪表板导入 Looker 或 Power BI，虽然能为管理层提供美观的图表，但却无法实现实际操作。一线员工无法基于仪表板采取行动。HubSpot 才是销售、市场营销和患者生命周期活动真正发生的地方。将预测功能从 HubSpot 中分离出来，只会创建两个互不信任的记录系统。

APIANT 方法

CRMConnect Cliniko 与 HubSpot 集成，将 Cliniko 预约和 Cliniko 发票分别对应为两个独立的 HubSpot 销售管道。预约管道是您的领先指标（已预订的交易显示日历上的收入）。发票管道是您的已确认收入（发票交易显示已开票、已付款或已核销的金额）。将两者结合起来，您就能获得一个真正的 30/60/90 天预测，该预测会随着 Cliniko 的每次更新而更新，而不是每次 CFO 打开电子表格时才更新。

混凝土台阶

  1. 启用发票流程。每张 Cliniko 发票都会在 HubSpot 中创建一个交易记录，包含发票编号、开票日期、状态、净额、税额、总金额、已应用折扣和患者信息。交易阶段与 Cliniko 发票状态（草稿、待处理、已付款、已作废）相对应。
  2. 启用预约流程。每次 Cliniko 预约都会在 HubSpot 中创建一个交易，其中包含预约日期、执业医师、营业地点、预约类型以及根据计费项目计算出的预约交易金额。阶段与 Cliniko 预约状态相对应。
  3. 同步病例信息。对于每个患者病例，将会话限制、最高可计费金额和活跃状态作为属性添加到 HubSpot 联系人中。这样可以避免重复计算保险计划即将达到上限的患者。
  4. 构建 30/60/90 预测。预测值是以下各项之和：(a) 已付款阶段的发票管道交易，且开票日期在该期间内（已确认），加上 (b) 待处理阶段的发票管道交易，且开票日期在该期间内（极有可能），加上 (c) 已预约或已到达阶段的预约管道交易，乘以您历史的到达到账单比率（预测）。
  5. 按执业医师和服务项目进行细分。预约流程中已包含执业医师和预约类型信息。构建一个 HubSpot 控制面板，其中包含按执业医师、按服务项目（初次评估、后续跟进、治疗模块、套餐就诊）划分的预测，以及每周的预测差异。
  6. 将营销支出纳入考量。由于每个联系人信息中都已包含 HubSpot 原始数据，您现在可以生成真正的营销投资回报率报告：按广告系列或渠道划分的广告支出和发票收入。

结果

与 Northpoint 情况类似的诊所，其预测准确率通常会从电子表格基准的 75% 到 80%（第三周预测值与实际值之比）提升到 90% 以上，前提是发票和预约流程运行正常。更重要的是，预测会在一周内更新。管理层不再纠结于上周一的数据，而是在周四早上就能采取行动。首席财务官每周可以节省 4 到 6 个小时用于手动重建预测数据的时间。营销投资回报率的讨论也终于以已开票收入而非表单填写量作为分母。

定期护理包不重复计算

运动医学销售大量多疗程套餐：例如6次治疗疗程、12周重返运动计划、术后康复疗程等。病例信息同步功能会显示每个活跃病例的疗程次数限制和剩余容量，以便预测系统能够正确识别实际计费时（通常是预付费用）的套餐收入，避免预测已预付的未来疗程收入。如果没有病例信息同步功能，套餐患者往往会在预测中被重复计算（一次是在销售时，另一次是在每次预约疗程时）。

建筑商外卖

  • 预测结果由两条数据管道（预约作为领先指标，发票作为已确认指标）加上案例信息（作为容量检查）组成。在构建仪表板之前，请先构建这三条数据管道。
  • 电子表格运行缓慢并非因为电子表格本身不好，而是因为需要人工刷新。应该将刷新操作移到集成流程中。
  • 只有当分母是已开票收入而非表单填写量时，营销投资回报率的讨论才能真正变得严肃起来。“发票流程”正是让这种讨论变得真诚的关键所在。
