常见问题

我们目前承接定制集成项目。为什么要在 APIANT 上实现产品化，而不是按小时计费呢？

定制项目的工作模式会将您的收入限制在团队的计费工时内。而 APIANT 的产品化模式则颠覆了这种模式：只需构建一次集成，即可将其作为周期性 SaaS 产品出售，每个新客户几乎都能带来纯利润。平台成本固定，逻辑共享，第 500 个客户的成本几乎与第一个客户相同。这就是咨询公司和集成公司之间的区别。

我们如何对 APIANT 进行白标定制，以便我们的客户看到我们的品牌，而不是你们的品牌？

您的专属 APIANT 服务器运行在您的子域名上，并采用您的品牌标识。表单应用会嵌入到您的产品或门户网站中，并使用您的颜色和文案。客户流程中不会出现 APIANT 的徽标，不会重定向到第三方结算页面，设置界面中也不会显示任何供应商信息。您的客户只了解您，而不是我们。

如果客户需要与我们从未接触过的应用程序集成怎么办？

将 AI 助手指向 API。它会读取文档、确定身份验证、构建所需组件、针对实际端点进行测试并进行自我纠正。第二天早上，您的工作流程架构师就能获得可用于生产环境的构建模块，并将其封装到自动化流程中。这样，您无需增加人手即可拓展到大型 iPaaS 平台忽略的垂直领域（例如兽医、捐赠者管理、小众特许经营工具）。

我们能否将 APIANT 作为我们自己定价的一部分进行转售，还是客户直接向 APIANT 付款？

两种模式都存在。大多数系统集成商都运营自己的产品：您以市场可接受的价格销售集成产品，客户向您付款，您向 APIANT 支付平台费用。您的利润率与订阅用户数量成正比。如果您更倾向于将客户直接推荐给 APIANT，那也行得通。请与我们联系，探讨适合您情况的定价方案。

一台 Pro 或 Scale 服务器实际最多可以运行多少个客户？

这取决于每个客户的交易量，而非连接数。典型的专业版部署（每月 499 美元，10 个连接）可以轻松支持数十位客户处理轻到中等负载。扩展版（每月 1500 美元，50 个连接）则适用于客户数量较多的生产级工作负载。当速率限制或吞吐量达到上限时，您可以选择升级到更高层级或使用多个专用服务器。我们会根据实际流量模式与您协商确定合适的方案。

凌晨 2 点，客户的集成出现故障，技术支持会是什么样的？

APIANT 负责管理平台（服务器、正常运行时间、平台更新）。您只需管理其上的集成。每个自动化流程都拥有可搜索的执行历史记录，包含完整的请求和响应正文，因此您的支持团队可以在几分钟内而非几小时内完成诊断。企业级服务包含合同规定的服务级别协议 (SLA) 以及优先升级至 APIANT 工程团队的权限；详情请咨询。

我们已有集成代码。我们可以将其迁移到 APIANT 吗？还是需要从头开始编写？

之所以在自动化编辑器中重新构建，是因为该平台会为您处理速率限制、重试、错误处理、监控和多位置路由（这些功能您很可能在现有代码中需要从头编写）。程序集编辑器加上 AI Co-Pilot 可以显著缩短重新构建时间，最终产品可以销售给同一垂直领域的所有其他客户。迁移方面的讨论通常会在第一次范围界定会议中进行。

如果 Claude Code 可以构建集成，为什么我的客户还需要我或 APIANT 呢？

Claude Code 是构建者。它仍然需要一个平台来构建，也需要一个商业模式来销售成果。APIANT 就是这个平台：它提供专用服务器、确定性执行引擎、白标层和管理控制台。而您就是商业模式：您了解垂直行业，您拥有客户关系，您将集成打包成产品并定价。Claude Code 压缩了工程部分。它不了解您客户的业务，也不代表您的品牌。这些仍然由您负责。
