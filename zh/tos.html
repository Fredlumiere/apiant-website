1. 关于平台

该平台通过触发用户数据修改，自动执行某些独立第三方应用程序和服务（无论基于 Web 还是离线，统称为“第三方应用程序”）之间的命令（“任务”），从而实现这些应用程序和服务之间的工作流程自动化（这些任务的任意组合称为“自动化”）。除了每个第三方应用程序的预编程任务外，该平台还包含一个 API 集成程序集编辑器工具（“程序集编辑器”），可用于开发新的、独特的任务。

1A. MCP 服务器基础架构

该平台允许客户在其专用的 APIANT 基础设施（包括客户自己的服务器和域名，统称为“MCP 服务器基础设施”）上部署兼容模型上下文协议（“MCP”）的服务器。MCP 服务器基础设施是服务的组成部分，并受本协议条款的约束。关于客户对 MCP 服务器基础设施的使用：

（i）客户的MCP服务器部署在客户专用的APIANT基础设施上。客户MCP服务器的最终用户连接到客户的服务器，而不是直接连接到APIANT；

（ii）客户对其与最终用户的关系负全部责任，包括适用于通过人工智能平台（以下简称“人工智能平台”）连接到客户的 MCP 服务器的最终用户的任何服务条款、隐私政策和数据处理披露；

（三）客户承认，AI 平台与客户的 MCP 服务器之间传输的数据会经过 AI 平台提供商的基础设施，并受该提供商的数据处理惯例的约束，客户和 APIANT 对此均无控制权；

（四）客户全权负责确保其对MCP服务器基础设施的使用以及通过客户的MCP服务器处理的数据符合所有适用的法律、规则和法规，包括隐私法；
