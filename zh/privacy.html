3. MCP 服务器基础设施

简而言之：APIANT 提供 MCP（模型上下文协议）服务器基础设施，我们的客户可将其部署在自己的专用服务器和域名上。当您的数据通过客户的 APIANT MCP 服务器进行处理时，我们仅处理执行请求操作所需的数据。我们不会使用 MCP 交互数据来训练 AI 模型、投放广告或构建用户画像。

APIANT MCP 服务器的工作原理

APIANT 使客户（“构建者”）能够在自己的专用基础设施和域上部署兼容 MCP 的服务器。这些 MCP 服务器允许构建者的最终用户通过 AI 平台（例如 Anthropic 的 Claude）使用自然语言与构建者的集成和自动化功能进行交互。当最终用户连接到构建者的 MCP 服务器时，AI 平台会将工具调用请求发送到构建者基于 APIANT 的服务器。APIANT 提供底层平台基础设施；最终用户连接到构建者的服务器，而不是直接连接到 APIANT。

MCP服务器处理哪些数据

当数据通过 APIANT 支持的 MCP 服务器进行处理时，可能涉及以下几类数据：

  • 身份验证凭据： OAuth 2.0 令牌或其他凭证用于验证身份并授权访问构建器的服务器。
  • 工具调用参数： 执行每个请求操作所需的具体输入（例如，应用程序名称、工作流配置或搜索查询）。
  • 工具调用响应： 构建器服务器响应请求返回的结果，会将这些结果转发回 AI 平台，以便显示给最终用户。

APIANT 确实 不是 接收终端用户与人工智能平台之间对话的完整文本。只有执行特定操作所需的结构化工具调用数据才会在构建者的 APIANT 服务器上进行处理。

我们如何使用MCP数据

作为平台基础设施提供商，APIANT 使用通过 MCP 服务器处理的数据仅用于：

  • 代表建设者提供和运营平台基础设施
  • 监控服务器性能、正常运行时间和错误率
  • 调试问题并提高 MCP 服务器基础架构的可靠性
  • 遵守适用的法律义务

我们如何存储和保留MCP数据

  • 身份验证令牌 会话期间数据会保存在内存中，断开连接后数据不会保留。
  • 工具调用日志 （参数和响应）可能会出于调试和运行目的保留一段有限的时间。除非法律要求更长的保留期限，否则这些日志将在 90 天内清除。
  • 没有用户配置文件 由 MCP 交互数据构建而成。

我们不会对MCP数据进行以下操作

  • 我们确实 不是 使用 MCP 交互数据来训练任何 AI 或机器学习模型。
  • 我们确实 不是 将 MCP 交互数据出售给第三方。
  • 我们确实 不是 将 MCP 互动数据用于广告、用户画像或营销目的。
  • 我们确实 不是 除为提供服务所必需或法律要求外，不会与第三方共享 MCP 交互数据。

关于MCP数据的权利

如果您是使用 APIANT 构建的 MCP 服务器的最终用户，请直接联系构建商了解您的数据权利。如果您是 APIANT 客户（构建商），您可以联系我们，请求访问、更正或删除通过您的 MCP 服务器基础架构处理的任何个人数据。 privacy@apiant.com。 看 ”您的隐私权有哪些？更多详情请见下文。

如果您身处欧盟或英国，则本节内容适用于您。

《通用数据保护条例》(GDPR) 和英国《通用数据保护条例》(UK GDPR) 要求我们解释处理您的个人信息所依据的有效法律依据。因此，我们可能依据以下法律依据处理您的个人信息：

  • 同意。 如果您已授权（即同意）我们出于特定目的使用您的个人信息，我们可能会处理您的信息。您可以随时撤回您的同意。了解更多信息 撤回您的同意.

  • 合法权益。 当我们认为为实现我们的合法商业利益而合理必要，且这些利益不凌驾于您的利益、基本权利和自由之上时，我们可能会处理您的信息。例如，我们可能会出于以下某些目的处理您的个人信息：

  • 法律义务。 我们可能会在认为有必要遵守我们的法律义务的情况下处理您的信息，例如与执法机构或监管机构合作、行使或捍卫我们的合法权利，或者在涉及我们的诉讼中披露您的信息作为证据。
