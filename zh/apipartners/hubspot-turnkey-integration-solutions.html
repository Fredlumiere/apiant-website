HubSpot概述

HubSpot 是一个客户平台，它将市场营销、销售和服务整合到一个 CRM 系统中。CRMConnect 可以将您现有平台的数据导入 HubSpot，从而使您的联系人、列表和工作流程能够反映客户的实际行为。

API 应用程序的独特之处？

API 应用不仅仅是连接器，它们是专家打造的解决方案，可将 HubSpot 与您企业运行的平台无缝集成。这些应用旨在精准处理复杂的工作流程，从而提高效率、开拓新机遇并促进业务增长。

常见问题

HubSpot CRMConnect 支持哪些平台？

今天有三个： Mindbody + HubSpot, Cliniko + HubSpot和 DonorPerfect + HubSpot每个应用都是独立的，专为该平台打造，并针对您的账户进行设置。

我在 HubSpot 应用市场点击了“安装”。接下来会发生什么？

请从上方列表中选择您使用的平台并预约通话。我们会将您的 HubSpot 帐户和平台帐户连接起来，确认需要同步的内容，并为您设置 CRMConnect。

HubSpot会接收到哪些数据？

这取决于平台。CRMConnect 将 Mindbody 的客户、访问、购买和会员信息，Cliniko 的患者、预约和发票信息，以及 DonorPerfect 的捐赠者资料和捐赠历史记录导入 HubSpot。每个产品页面都会列出同步的内容。

我能否基于同步数据构建自动化流程？

是的。一旦数据导入 HubSpot，您就可以像处理其他 HubSpot 数据一样，使用 HubSpot 工作流构建自动化流程。

当 HubSpot 或我的平台更改其 API 时会发生什么？

APIANT 会监控上游 API 的变更，并持续维护集成。由于逻辑是集中式的，因此修复或升级会一次性推送至该 API 应用上的所有客户，无需逐个账户进行迁移。

我的平台未列出，我该怎么办？

使用 APIANT.AI 在本页顶部。描述 HubSpot 和您的其他应用程序之间应该发生的情况，代理程序将构建、测试并运行集成。免费套餐足以完成构建。
