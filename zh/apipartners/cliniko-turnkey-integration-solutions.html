Cliniko 概览

Cliniko 是一款完整的执业管理应用程序，全球超过 95 个国家的数以千计的医疗从业人员都在使用它。它可以管理日程表、治疗记录、发票、付款等。它既适用于个人执业者，也适用于大型团队，还适用于介于两者之间的任何情况。

API 应用程序的独特之处？

API 应用程序不仅仅是连接器，它们还是功能强大的专业解决方案，可将 Cliniko 与您所依赖的工具无缝集成。它们旨在精确处理复杂的工作流程，从而提高效率、释放新机遇并促进业务增长。

常见问题

哪些 Cliniko 数据会被同步？是单向同步还是双向同步？

Cliniko API 应用可同步患者档案、预约（包括过往和即将到来的预约）、治疗详情、发票和付款信息、医生分配以及自定义字段。同步是双向的：在 CRM 中创建的新潜在客户可以作为患者信息推送到 Cliniko，而 Cliniko 中的患者活动也会自动回传到 CRM。

APIANT如何处理受保护的健康信息？

每个 Cliniko 部署都运行在专用的、隔离的 APIANT 服务器上。没有共享租户，数据不会与其他客户的工作负载混杂。凭据经过加密，Webhook 端点仅支持 HTTPS，访问权限由管理控制台中基于角色的控制机制进行管理。对于特定的合规性要求（HIPAA、GDPR、地区隐私法），请与我们的团队联系，讨论适合您诊所的部署配置。

我们有多名执业人员，分布在多个地点。一个集成方案能否满足所有这些需求？

是的。一个 CRM 账户可以与多个 Cliniko 业务和医生账户同步。患者信息会根据就诊地点和医生在 CRM 系统中进行标记，确保每位医生记录的信息保持一致。这对于拥有多位医生的诊所、区域医疗网络以及跨地域汇报的联合医疗机构来说至关重要。

Cliniko目前通过APIANT连接哪些CRM系统？

目前提供三款即用型 Cliniko API 应用：Cliniko + HubSpot、Cliniko + ActiveCampaign 和 Cliniko + Salesforce。每款应用都涵盖了各自 CRM 的原生功能集（联系人字段、自定义对象、销售管道、自动化触发器）。如果您需要其他 CRM 或营销工具，AI Co-Pilot 通常可以在几天内构建连接器。

我们能否实现患者随访、爽约提醒或治疗提醒的自动化？

是的。由于预约状态、治疗记录和就诊日期会实时同步到 CRM 系统，您可以在 CRM 的原生工具（例如 HubSpot 工作流、ActiveCampaign 自动化、Salesforce Flow）中构建自动化流程，以便在 Cliniko 发生任何事件时触发，例如：错过预约、逾期复诊、治疗计划完成。CRM 负责消息传递，APIANT 则负责确保数据的准确性。

安装过程实际需要多长时间？

对于标准的单诊所部署，一旦 Cliniko 和 CRM 账户连接完毕且字段映射确认无误，通常几天即可完成设置。多地点诊所和高度定制化的诊所则需要更长时间，因为配置工作较多，而非集成构建本身。我们的团队将指导您完成整个上线流程。

Cliniko推出API变更时会发生什么？

APIANT 会监控上游 API 的变更，并持续维护集成。由于逻辑是集中式的（设置而非逻辑架构），因此修复或升级会同时推送至该 API 应用上的所有客户，无需针对每个诊所进行迁移。您不会收到更新集成的通知。
