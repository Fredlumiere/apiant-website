DonorPerfect 概览

DonorPerfect 是领先的非营利组织筹款和捐赠者管理软件平台，提供全面的捐赠者跟踪、礼物处理、报表和成员互动工具。

API 应用程序的独特之处？

DonorPerfect 集成应用，支持 Mailchimp、QuickBooks、Stripe 以及您的非营利组织平台。预构建、生产级，由 APIANT 构建和维护。

常见问题

DonorPerfect 与我们的客户关系管理系统或电子邮件平台之间会同步哪些捐赠者数据？

捐赠者资料、捐赠历史、定期捐赠状态、活动和基金跟踪、认捐余额、软性捐赠以及自定义字段。该集成可确保双方的捐赠者记录近乎实时地保持准确，因此在 DonorPerfect 中记录的捐赠会显示在 CRM 或电子邮件平台中，并包含足够的信息以触发相应的致谢或维护流程。

我们能否实现捐赠者致谢和捐赠级别升级活动的自动化？

是的。捐赠记录和累计捐赠数据会实时导入CRM系统，这意味着您现有的邮件平台（HubSpot、ActiveCampaign、Keap、Mailchimp）可以根据捐赠者的真实行为触发税务收据、感谢邮件、大额捐赠提醒和升级邀请。CRM系统负责邮件发送；APIANT则负责确保数据的准确性和及时更新。

DonorPerfect目前可以连接到哪些CRM和电子邮件平台？

目前有四款 DonorPerfect API 应用可供使用：DonorPerfect + HubSpot、DonorPerfect + ActiveCampaign、DonorPerfect + Keap 和 DonorPerfect + Mailchimp。这些应用涵盖了大多数非营利组织的营销技术栈。如果您需要其他工具（例如 Salesforce NPSP、Constant Contact 等），AI 助手通常可以在几天内（而非几个月）构建连接器。

如何处理定期捐赠、认捐和多年承诺？

定期捐赠的状态、计划和余额会以结构化数据的形式导入客户关系管理系统 (CRM)，以便您可以根据定期捐赠者的状态进行细分和沟通。认捐余额和付款历史记录会同步，从而确保防流失和追回认捐的自动化流程能够基于准确的数据运行。多年期捐赠承诺也遵循同样的模式：集成反映的是 DonorPerfect 的账簿，而非快照。

该集成能否处理多个活动、资金和募捐代码？

是的。活动、基金和募捐代码数据会与捐赠记录同步，捐赠者细分可以根据任意组合进行构建。对于同时开展数十个募捐活动的非营利组织而言，这正是通用确认邮件与针对特定活动的捐赠者关系维护自动化之间的区别所在。

我们有严格的数据隐私和捐赠者保密规定。APIANT是如何处理这些问题的？

每个 APIANT 部署都运行在专用服务器上，不与其他服务器共享。凭据经过加密，连接仅支持 HTTPS，管理控制台中的基于角色的访问控制机制可管理哪些用户可以查看或修改集成。对于特定的捐赠者隐私政策、GDPR 或区域数据驻留要求，请与我们的团队联系，讨论合适的部署配置。

我们需要聘请一名开发人员来运行这个项目吗？

不。交钥匙 API 应用是配置好的，无需编写代码。字段映射、活动管理和同步频率都是设置项。负责集成的人员需要了解捐赠者运营流程，而不是工程技术。对于超出交钥匙默认设置范围的自定义逻辑，APIANT 团队（或经认证的系统集成商）会在平台上进行处理。
