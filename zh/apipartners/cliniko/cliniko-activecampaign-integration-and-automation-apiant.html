Cliniko + ActiveCampaign 集成的核心功能

在 ActiveCampaign 中自动将 Cliniko 数据转化为可操作的洞察力和自动化功能，从而简化您的运营并增进与患者的关系。

单向患者数据同步

从 Cliniko 到 ActiveCampaign，自动同步重要的患者详细信息，包括预约总数、终身价值、患者备注和转诊信息。无需动动手指，即可保持联系人的准确性和时效性。

预约完成标记

当联系人在 Cliniko 中完成预约时，自动将标签应用到 ActiveCampaign 联系人。创建有针对性的细分市场，及时提供相关通信，提高患者参与度。

发票同步到 ActiveCampaign 交易

使用来自 Cliniko 的发票数据自动更新 ActiveCampaign 交易，包括终生消费、最新发票金额和发票号码。深入了解患者价值，实现有针对性的跟进。

Cliniko 预约跟踪

自动更新 ActiveCampaign 联系人上次预约的日期和时间、上次完成的预约以及访问的地点。轻松实现个性化沟通和自动化及时跟进。

个人和团体预约更新

利用来自 Cliniko 的准确预约详细信息自动更新 ActiveCampaign 联系人，包括个人和团体会话。实现精确细分、有针对性的信息传递和高效的患者参与。

您需要了解的一切

为什么这款 API 应用程序比 Make、Appy Pie 或 Pipedream 等 DIY 工具更好？
该应用程序接口应用程序是一个交钥匙、专业设计的集成解决方案，由在这两个应用程序领域都具有深厚知识的专家构建。

DIY 工具会让您自己构建、调试和管理集成，而我们的集成则与之不同，我们的集成是预先构建的，经过全面测试，并包含复杂的逻辑，可确保数据流准确、可靠、准时。

它是可配置的，因此您无需编码即可定制应用程序的通信方式。此外，您还能获得了解您特定业务需求的专家提供的 VIP 客户支持。只需几分钟，您的系统就能完全连接起来--无需担心技术问题，也无需反复试验。

集成不是副业，而是关键的软件基础设施。请将它们托付给通过多年经验不断完善的专业人士。
与 Make、Appy Pie 或 Pipedream 等 DIY 集成工具相比，定价如何？
这最终取决于您需要在应用程序之间同步多少数据。DIY 集成工具通常按执行的 "任务 "收费 - 这些费用很快就会增加，尤其是当您的集成需要复杂的逻辑、数据转换（如日期或货币）、缓存和复杂的工作流时。

然而，我们的 API 应用程序具有先进的功能和集成，这些都是这些 DIY 工具无法复制的。

在价格方面，我们的解决方案具有明显优势：在您选定的使用级别下（例如客户数量），我们通常允许您同步无限数量的记录，包括客户数据、销售、交易等。这使我们的 API App 不仅在功能上更优越，而且随着需求的增长更具成本效益。
我是否必须在 ActiveCampaign 中创建属性才能从 Cliniko 接收数据？
您不需要。ActiveCampaign 中的属性创建是在安装时自动进行的。
这是双向同步集成吗？
不，此集成是从 Cliniko 到 ActiveCampaign 的单向同步。我们的大多数客户更喜欢这种方式，因为它可以防止所有 ActiveCampaign 联系人自动成为 Cliniko 中的病人，从而有助于保持 Cliniko 数据库的整洁和有序。
集成包含多少历史数据？
您可以将现有的 Cliniko 患者全部导入 ActiveCampaign。

对于预约，集成会自动捕获近期和即将到来的数据，如下所示：

过去的预约：检查过去7天内的预约，确保最近的更新或变更被包含在内。

未来预约：根据您指定的设置检查提前安排的预约（例如未来 45 天）。

此设置可确保您的 ActiveCampaign 记录始终与最新的相关预约信息保持一致。

最佳做法：

根据您通常提前多长时间预约来配置未来天数。如果您提前很长时间安排预约，那么较高的值（如 45 天）是理想的选择。要调整此设置，请联系 support@apiant.com。
运行 CRMConnect 需要订购哪个 ActiveCampaign？
您可以使用任何可容纳您打算同步的患者人数的 ActiveCampaign 订阅。只需选择与您的患者总数相匹配或超过患者总数的计划，即可确保无缝集成。
是否包括 ActiveCampaign 自动化和活动构建？
CRMConnect仅将数据从Cliniko解释并同步到ActiveCampaign。这些同步数据具有很高的可操作性，但您需要在 ActiveCampaign 中创建自己的自动化、工作流或活动。如果您需要帮助，请告诉我们--我们可以将您介绍给熟悉 CRMConnect 的 ActiveCampaign 专家。
没有电子邮件的 Cliniko 患者会怎样？
Cliniko 中没有电子邮箱的患者无法同步到 ActiveCampaign，因为 ActiveCampaign 要求每个联系人都有电子邮箱。这些患者将在同步过程中被跳过。
