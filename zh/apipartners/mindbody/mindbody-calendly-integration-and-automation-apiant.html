您需要了解的一切

为什么这款 API 应用程序比 Make、Appy Pie 或 Pipedream 等 DIY 工具更好？
该应用程序接口应用程序是一个交钥匙、专业设计的集成解决方案，由在这两个应用程序领域都具有深厚知识的专家构建。

DIY 工具会让您自己构建、调试和管理集成，而我们的集成则与之不同，我们的集成是预先构建的，经过全面测试，并包含复杂的逻辑，可确保数据流准确、可靠、准时。

它是可配置的，因此您无需编码即可定制应用程序的通信方式。此外，您还能获得了解您特定业务需求的专家提供的 VIP 客户支持。只需几分钟，您的系统就能完全连接起来--无需担心技术问题，也无需反复试验。

集成不是副业，而是关键的软件基础设施。请将它们托付给通过多年经验不断完善的专业人士。
与 Make、Appy Pie 或 Pipedream 等 DIY 集成工具相比，定价如何？
这最终取决于您需要在应用程序之间同步多少数据。DIY 集成工具通常按执行的 "任务 "收费 - 这些费用很快就会增加，尤其是当您的集成需要复杂的逻辑、数据转换（如日期或货币）、缓存和复杂的工作流时。

然而，我们的 API 应用程序具有先进的功能和集成，这些都是这些 DIY 工具无法复制的。

在价格方面，我们的解决方案具有明显优势：在您选定的使用级别下（例如客户数量），我们通常允许您同步无限数量的记录，包括客户数据、销售、交易等。这使我们的 API App 不仅在功能上更优越，而且随着需求的增长更具成本效益。
Calendly 和 Mindbody 的同步是如何工作的？
双向同步。当客户打开您的预约页面时，CalendarConnect 会从 Mindbody 读取该执业者的实时可预约时间，并在显示任何时间之前将其直接写入 Calendly。客户预约后，预约信息会立即出现在 Mindbody 中，客户信息已匹配或创建，并已分配正确的员工和服务，客户的咨询回答也会记录在案。
是否为双向同步？
是的。Mindbody 的可用时间会同步到 Calendly，而 Calendly 的预约也会同步到 Mindbody。实际上，这意味着直接在 Mindbody 中预约的时间段会从 Calendly 的预约页面消失，而通过 Calendly 进行的预约则会显示在您的 Mindbody 日程表中。
可用性数据多久同步一次？
它完全没有定时同步，而是按需获取。每次客户打开您的预订页面时，CalendarConnect 都会从 Mindbody 读取最新数据，并在显示任何时间之前更新 Calendly。没有时间间隔，因此您的可用时间不会出现波动。
预订信息多久会发送到 Mindbody？
即时生效。Calendly 会在预订完成后立即通知 CalendarConnect，并立即创建 Mindbody 预约。
我需要谷歌日历吗？
不。以前将 Mindbody 连接到 Calendly 需要通过 Google 日历来设置您的空闲时间，因为这是 Calendly 只能看到外部日程安排的方式。4.0 版本则直接将空闲时间写入 Calendly。您无需使用 Google 日历，也无需使用 Google Workspace，而且不会将任何信息写入您员工的个人日历。
我已经在使用谷歌日历了，需要断开连接吗？
不，CalendarConnect 不会影响它。它只是不再包含在集成中了。您的员工可以继续使用 Google 日历进行任何他们常用的操作。
访客需要点击任何按钮才能查看可用时间吗？
不，页面会自动加载实时空位信息。用户会看到一个短暂的加载动画，然后就会显示可通过 Mindbody 预订的实际时间。如果用户保持页面打开状态，只需轻点一下即可刷新时间，并查看列表的最后更新时间。
需要哪种 Calendly 计划？
CalendarConnect 需要付费的 Calendly 计划，因为将可用性写入 Calendly 使用了 Calendly 免费套餐不包含的功能。
我需要授权每位员工的 Calendly 账户吗？
一个 Calendly 组织连接即可覆盖您的整个团队，包括您之后添加的主持人。
如果 Calendly 客户端不在 Mindbody 中怎么办？
首次预订时，系统会自动创建一个新的 Mindbody 客户档案。CalendarConnect 会首先读取您网站的必填字段规则，因此即使在验证机制严格的 Mindbody 网站上，也能成功创建档案。
我可以运营多个地点吗？
是的。一个 Calendly 组织即可服务您所有的 Mindbody 地点，即使是作为独立 Mindbody 站点运行的地点，包括跨区域和数据共享设置。预订会自动路由到正确的地点、员工和服务，每个地点的可用时间都从其自身的 Mindbody 站点以各自的时区读取。
能否同步多个 Calendly 事件类型？
是的。您可以根据需要配置任意数量的活动类型，每种类型都可以映射到其自身的 Mindbody 服务、员工和地点。
如果预订失败会怎样？
您会立即收到通知。CalendarConnect 会在客户的 Mindbody 记录中标记失败，同时向您的管理员联系人和 Calendly 主机发送电子邮件，每项操作均可独立切换。每次失败的预订都会被完整记录，因此支持人员无需您重新输入任何内容即可重现该预订。
是否需要额外的手动录入？
不，该集成完全自动将预订从 Calendly 输入到 Mindbody。
