DonorPerfect + Keap 集成的核心功能

在 Keap 中自动将 DonorPerfect 数据转化为可操作的洞察力和自动化功能，从而简化您的运营并增强捐赠者关系。

自动同步捐赠者

在 DonorPerfect 和 Keap 之间实时更新捐赠者记录，无需人工干预。每个变更即时同步，确保团队始终使用准确的数据。

详细捐赠信息同步

每当有捐赠或更新时，Keap 都会自动刷新捐赠者记录，包括联系信息、捐赠日期、捐赠金额、年初至今的总额、捐赠历史和主要捐赠者指标。

自动跟进和感谢

根据更新的捐赠者行动和历史记录，自动生成感谢邮件、收据和个性化后续通信。

明确的筹资指标

在 Keap 中直接获取捐赠者趋势、年度累计捐赠、平均捐赠金额等关键指标的可操作洞察。

捐赠者代码和偏好同步

轻松同步捐赠者专属详情，如捐赠者类型、选择加入原因、邮件偏好和沟通方式，保持一致且准确的捐赠者记录。

轻松实现捐赠者分群

根据捐赠者的历史和偏好即时分类，为您的筹款活动实现精准定向沟通。

捐赠者标记作为标签

自动将 DonorPerfect 标记转换为 Keap 标记，简化细分，实现有效定位和个性化捐赠者旅程。

您需要了解的一切

为什么这款 API 应用程序比 Make、Appy Pie 或 Pipedream 等 DIY 工具更好？
该应用程序接口应用程序是一个交钥匙、专业设计的集成解决方案，由在这两个应用程序领域都具有深厚知识的专家构建。

DIY 工具会让您自己构建、调试和管理集成，而我们的集成则与之不同，我们的集成是预先构建的，经过全面测试，并包含复杂的逻辑，可确保数据流准确、可靠、准时。

它是可配置的，因此您无需编码即可定制应用程序的通信方式。此外，您还能获得了解您特定业务需求的专家提供的 VIP 客户支持。只需几分钟，您的系统就能完全连接起来--无需担心技术问题，也无需反复试验。

集成不是副业，而是关键的软件基础设施。请将它们托付给通过多年经验不断完善的专业人士。
与 Make、Appy Pie 或 Pipedream 等 DIY 集成工具相比，定价如何？
这最终取决于您需要在应用程序之间同步多少数据。DIY 集成工具通常按执行的 "任务 "收费 - 这些费用很快就会增加，尤其是当您的集成需要复杂的逻辑、数据转换（如日期或货币）、缓存和复杂的工作流时。

然而，我们的 API 应用程序具有先进的功能和集成，这些都是这些 DIY 工具无法复制的。

在价格方面，我们的解决方案具有明显优势：在您选定的使用级别下（例如客户数量），我们通常允许您同步无限数量的记录，包括客户数据、销售、交易等。这使我们的 API App 不仅在功能上更优越，而且随着需求的增长更具成本效益。
捐赠者同步计数如何计算？
只有活跃的同步捐赠者才会被计算在内。不活跃的捐赠者在更新或进行新的捐赠之前不会被计算在内。
数据多久同步一次？
数据同步每 15 分钟进行一次。
你们是否提供非营利性折扣？
所有连接 DonorPerfect 和 Keap 的 CRMConnect 用户都是非营利组织；因此，我们的定价已经针对非营利组织进行了优化。
包含多少历史捐赠数据？
默认情况下，您的订阅包括一个月的历史捐赠数据。您可以一次性付费同步更多月份的数据。
我需要哪种 Keap 订阅？
CRMConnect 可与任何付费 Keap 订阅无缝连接。
Keap 中是否包括自动化？
CRMConnect 仅管理数据同步；自动化由您直接在 Keap 中创建和管理。如有需要，Keap 专家可提供帮助。
DonorPerfect 中没有电子邮件地址的捐赠者会怎样？
它们将被添加到 Keap 中，但没有电子邮件。
我的捐赠者数量超过了订阅上限。我该怎么办？
只有活跃的捐赠者才计入订阅限额，这样您就可以管理不活跃的捐赠者，而无需立即升级。
我可以选择同步哪些捐赠者信息吗？
所有标准的捐赠者和捐赠字段都会自动同步；特定的自定义字段需要进行可选的定制。
我可以从 DonorPerfect 同步自定义字段吗？
是的，同步自定义字段是可选的附加功能。
我能否跟踪特定筹款活动的成功情况？
是的，Keap 可根据同步捐赠数据清晰显示捐赠者的互动情况和活动效果。
