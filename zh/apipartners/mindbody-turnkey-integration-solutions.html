常见问题

这个系统会同步 Mindbody 的课程预订、预约和会员资格，还是只会同步联系人？

所有信息。Mindbody 的 CRMConnect 产品可同步客户资料，包括即将到来的和已结束的课程预订、预约、报名、会员资格（含到期日和剩余次数）、合同、自动付款状态、购买历史记录和访问记录。具体字段覆盖范围取决于目标 CRM；例如，Mindbody + HubSpot 应用可同步 120 多个自定义属性，并维护 HubSpot 交易中的预约流程和销售流程。

该方案如何处理多地点和加盟经营？

原生集成。客户会在CRM系统中根据其预订、到访或购买的Mindbody门店自动添加标签，并在所有门店保持记录一致。从CRM推送回Mindbody的潜在客户信息可以自动分配到正确的门店。一个CRM账户可以与多个Mindbody门店同步，这也是我们支持加盟店和企业数据共享网络（最多可达232个门店）的方式。

如果多个客户或家庭成员共用一个邮箱地址会发生什么情况？

CRMConnect 使用智能匹配逻辑来检测重复的个人资料，并在 Mindbody 中合并记录时更新正确的联系人，从而确保完整的历史记录保持不变。共享同一电子邮件地址的家庭成员会自动归入 CRM 中的同一公司记录下，这样家长就可以收到孩子账户的提醒和账单通知，而不会出现联系人重复或信息混淆的情况。

我们可以自定义字段映射和业务规则吗？还是说规则是固定的？

可定制。每个 API 应用都预置了合理的默认设置（例如同步哪些字段、自定义对象的建模方式、预订与交易的映射关系等），并在设置层公开配置选项。您可以决定是否同步自定义对象、如何应用位置标签以及哪些自定义 Mindbody 字段会流经应用。企业部署无需修改代码库即可在此基础上添加定制逻辑。

Mindbody可以通过APIANT连接哪些CRM和其他工具？

目前，Mindbody API 应用已支持 HubSpot、ActiveCampaign、Keap、Klaviyo、HighLevel、Zoho CRM、Shopify、Zoom、Calendly 和 Zapier 等 10 款产品，涵盖 CRM、邮件营销、电商、视频会议、日程安排和通用自动化等领域。如果您需要的工具不在列表中，AI Co-Pilot 通常可以在几天内（而非几个月）构建连接器。

这项服务如何定价？按地点、按联系人还是固定费用？

定价取决于具体的API应用程序、Mindbody站点数量以及部署规模。单站点订阅按公布的月费标准起价；多站点和加盟网络则根据站点数量和交易量报价。请联系我们获取您具体方案的准确报价。

如果我们的 Mindbody 实例有自定义字段或特殊的业务规则怎么办？

Mindbody 自定义字段会自动同步为已连接 CRM 中的自定义属性，方便您根据业务特定数据点进行细分和自动化操作。对于特殊的业务逻辑（例如独特的会员结构、特定地点规则、定制化的收入归因），底层 APIANT 平台允许我们在不重建核心集成的情况下添加这些逻辑。请在需求分析电话会议中提出，我们将向您展示其适用性。
