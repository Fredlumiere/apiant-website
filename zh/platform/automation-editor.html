一次构建。部署到数百个站点。让每个客户都能以不同的方式使用它。

产品化集成的秘诀在于将通用性和独特性区分开来。逻辑--数据如何在 API 之间流动、错误如何处理、对象如何映射--对每个人来说都是一样的。而设置--同步哪些字段、启用哪些功能、时区、语言、徽标--则因客户而异。

逻辑 通用

自动化逻辑在所有部署中都是相同的。它定义了数据如何流动、错误如何处理以及系统间对象如何映射。

  • 应用程序接口之间的数据流
  • 错误处理和重试规则
  • 对象映射和转换
  • 基于设置的条件分支
  • 速率限制合规

设置 每位客户

每次部署都有独立的设置层。无需修改逻辑即可按客户自定义配置。设置直接在 FormApp 中呈现，供终端用户配置。

  • 同步哪些字段
  • 启用哪些功能（自定义对象：是/否）
  • 时区和语言
  • 门店专属配置
  • 品牌和用户界面偏好
具体例子 客户关系管理集成有一个设置："自定义对象预约：是/否"。自动化会根据这一选择进行分支。相同的代码库处理两种路径。当一个特许经营店新增五个分店时，这些分店会继承主设置，但也可以单独配置。

数据引擎

无损数据处理

每个自动化都运行在 APIANT 的统一数据引擎上。格式无关的处理。全面使用 XPath。无限扩展。大型 API 响应、复杂的嵌套结构、每次同步数千条记录，引擎都能原生处理。

引擎盖下的发动机

大多数集成平台都会在嵌套 JSON、分页响应或大容量同步时出现问题。APIANT 的数据引擎可将各种格式（JSON、XML、CSV、自定义）规范化为单一模型，并无需手动解析即可进行转换。

XPath 表达式无处不在，让你在每一步都能精确控制数据选择、过滤和转换。
