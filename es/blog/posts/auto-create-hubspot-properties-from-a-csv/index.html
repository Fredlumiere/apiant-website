#HubSpot

Cómo crear automáticamente propiedades de HubSpot (contacto, oportunidad o empresa) utilizando esta automatización de importación gratuita basada en APIANT.

Público objetivo: Administradores de HubSpot

Pasos para crear automáticamente propiedades de HubSpot con un archivo CSV utilizando una cuenta gratuita de APIANT para administradores de HubSpot.

Primero necesitarás una cuenta APIANT…

Soluciones objetivo

Luego, copia y edita esta hoja de cálculo de Google.

Aquí está el Enlace a la hoja de cálculo de Google.

Añade tantas filas como quieras.

Seleccione el objeto de HubSpot para el que desea crear las propiedades:

  • Contacto
  • Trato
  • Empresa

Asígnale un nombre de grupo de propiedades

Siempre puedes listar una propiedad y elegir "No" para crear una propiedad personalizada en HubSpot e ignorarla por ahora.

Elija el nombre para mostrar, nombre de la API

Seleccione el tipo de propiedad en el menú desplegable:

  • selector de fecha
  • Fecha y hora
  • Selección desplegable
  • Texto de varias líneas
  • Selección múltiple
  • Campo numérico
  • Texto de una sola línea
  • Casilla de verificación única de encendido/apagado
  • Nativo de HubSpot

Y por último, introduzca la descripción de su propiedad.

Una vez que haya introducido todas las filas (una por propiedad), descargue la hoja como un archivo CSV:

Instala la automatización de plantillas en tu cuenta de APIANT.

Aquí está el enlace a la plantilla llamada Crear propiedades personalizadas de HubSpot a partir de un archivo CSV

Una vez instalado, conecte un HubSpot Hub desde el menú.

Seleccione la aplicación pública del sistema e inicie sesión en el Hub.

Activar la automatización

Presione el botón de reproducción para la automatización ya que esto es un Formulario de aplicación disparador basado

Haz clic para subir tu archivo CSV.

Tus propiedades se crearán automáticamente y se generará un informe.

Puedes editar la automatización según te convenga (incluso podrías añadir valores a los menús desplegables y a las selecciones múltiples).
