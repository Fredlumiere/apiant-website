เมื่อคลิกปุ่ม "สร้างบัญชี" ลูกค้าตกลงที่จะผูกพันตามข้อตกลงนี้ โดยมีผลบังคับใช้ตั้งแต่วันดังกล่าว ("วันที่มีผลบังคับใช้") การเข้าถึงและการใช้งานแพลตฟอร์มของลูกค้า และภาระผูกพันของ APIANT ที่เกี่ยวข้องนั้น ขึ้นอยู่กับการยอมรับข้อตกลงนี้ของลูกค้าอย่างชัดเจน

ภาคผนวกการประมวลผลข้อมูล: หากคุณประมวลผลข้อมูลส่วนบุคคลผ่านแพลตฟอร์ม APIANT ของเรา ข้อตกลงเพิ่มเติมเกี่ยวกับการประมวลผลข้อมูล (DPA) ข้อกำหนดนี้เป็นส่วนเสริมของข้อกำหนดและเงื่อนไขเหล่านี้ และควบคุมวิธีการที่ APIANT ดำเนินการกับข้อมูลส่วนบุคคลในนามของคุณ

1. เกี่ยวกับแพลตฟอร์ม

แพลตฟอร์มนี้จะทำให้เวิร์กโฟลว์ระหว่างแอปพลิเคชันและบริการของบุคคลที่สามแบบสแตนด์อโลนบางอย่างเป็นไปโดยอัตโนมัติ ไม่ว่าจะเป็นแบบเว็บหรือแบบออฟไลน์ ("แอปพลิเคชันของบุคคลที่สาม") โดยการสั่งให้ดำเนินการคำสั่ง ("งาน") ภายในแอปพลิเคชันของบุคคลที่สามเหล่านั้น เมื่อมีการเปลี่ยนแปลงข้อมูลผู้ใช้ (การรวมกันของงานดังกล่าว เรียกว่า "ระบบอัตโนมัติ") นอกจากงานที่ตั้งโปรแกรมไว้ล่วงหน้าสำหรับแต่ละแอปพลิเคชันของบุคคลที่สามแล้ว แพลตฟอร์มยังมีเครื่องมือแก้ไขแอสเซมบลีสำหรับการรวม API ("ตัวแก้ไขแอสเซมบลี") ซึ่งสามารถใช้ในการพัฒนางานใหม่ๆ ที่ไม่ซ้ำใครได้

1A. โครงสร้างพื้นฐานเซิร์ฟเวอร์ MCP

แพลตฟอร์มนี้รวมถึงความสามารถให้ลูกค้าสามารถติดตั้งเซิร์ฟเวอร์ที่เข้ากันได้กับ Model Context Protocol ("MCP") บนโครงสร้างพื้นฐาน APIANT เฉพาะของลูกค้า ซึ่งรวมถึงเซิร์ฟเวอร์และชื่อโดเมนของลูกค้าเอง (รวมเรียกว่า "โครงสร้างพื้นฐานเซิร์ฟเวอร์ MCP") โครงสร้างพื้นฐานเซิร์ฟเวอร์ MCP เป็นส่วนประกอบหนึ่งของบริการและอยู่ภายใต้ข้อกำหนดของข้อตกลงนี้ ในส่วนที่เกี่ยวกับการใช้งานโครงสร้างพื้นฐานเซิร์ฟเวอร์ MCP ของลูกค้า:

(i) เซิร์ฟเวอร์ MCP ของลูกค้าถูกติดตั้งบนโครงสร้างพื้นฐาน APIANT เฉพาะของลูกค้า ผู้ใช้ปลายทางของเซิร์ฟเวอร์ MCP ของลูกค้าเชื่อมต่อกับเซิร์ฟเวอร์ของลูกค้า ไม่ใช่เชื่อมต่อกับ APIANT โดยตรง

(ii) ลูกค้ามีหน้าที่รับผิดชอบแต่เพียงผู้เดียวในความสัมพันธ์กับผู้ใช้ปลายทางของตน ซึ่งรวมถึงข้อกำหนดในการให้บริการ นโยบายความเป็นส่วนตัว และการเปิดเผยการจัดการข้อมูลใดๆ ที่ใช้บังคับกับผู้ใช้ปลายทางที่เชื่อมต่อกับเซิร์ฟเวอร์ MCP ของลูกค้าผ่านแพลตฟอร์ม AI (แต่ละแพลตฟอร์มเรียกว่า "แพลตฟอร์ม AI")

(iii) ลูกค้ารับทราบว่าข้อมูลที่ส่งระหว่างแพลตฟอร์ม AI และเซิร์ฟเวอร์ MCP ของลูกค้าจะผ่านโครงสร้างพื้นฐานของผู้ให้บริการแพลตฟอร์ม AI และอยู่ภายใต้แนวทางการจัดการข้อมูลของผู้ให้บริการดังกล่าว ซึ่งทั้งลูกค้าและ APIANT ไม่สามารถควบคุมได้

(iv) ลูกค้ามีหน้าที่รับผิดชอบแต่เพียงผู้เดียวในการตรวจสอบให้แน่ใจว่าการใช้งานโครงสร้างพื้นฐานเซิร์ฟเวอร์ MCP และข้อมูลที่ประมวลผลผ่านเซิร์ฟเวอร์ MCP ของลูกค้าเป็นไปตามกฎหมาย กฎระเบียบ และข้อบังคับที่เกี่ยวข้องทั้งหมด รวมถึงกฎหมายว่าด้วยความเป็นส่วนตัว และ

(v) ข้อกำหนดอื่นๆ ทั้งหมดของข้อตกลงนี้ รวมถึงแต่ไม่จำกัดเพียงข้อจำกัดในการใช้งาน (มาตรา 10) กรรมสิทธิ์ในทรัพย์สินทางปัญญา (มาตรา 11 และ 12) ข้อสงวนสิทธิ์ (มาตรา 17) และข้อจำกัดความรับผิด (มาตรา 19) มีผลบังคับใช้โดยสมบูรณ์กับการใช้งานโครงสร้างพื้นฐานเซิร์ฟเวอร์ MCP ของลูกค้า

2. การให้บริการทดลองใช้ของ APIANT อยู่ภายใต้ข้อกำหนดและเงื่อนไขของ APIANT เหล่านี้

ภายใต้ข้อกำหนดและเงื่อนไขของข้อตกลง APIANT ฉบับนี้ ในช่วงระยะเวลาทดลองใช้ APIANT ตกลงที่จะใช้ความพยายามอย่างสมเหตุสมผลในเชิงพาณิชย์เพื่อมอบสิทธิ์การเข้าถึงและการใช้งานแพลตฟอร์มที่จำกัดแก่ลูกค้า ซึ่ง APIANT อาจเสนอให้แก่ผู้ถือบัญชีเป็นครั้งคราว ("บริการทดลองใช้" และรวมกับบริการสมัครสมาชิกแล้ว เรียกว่า "บริการ") ข้อจำกัดในการเข้าถึงและการใช้งานแพลตฟอร์มที่ให้ไว้เกี่ยวกับการบริการทดลองใช้อาจขยายหรือแก้ไขเพิ่มเติมได้ตลอดเวลาโดยไม่ต้องแจ้งให้ทราบล่วงหน้า และอาจรวมถึงข้อจำกัดในการเข้าถึงและการใช้งานแอปพลิเคชันของบุคคลที่สามและ/หรือโปรแกรมแก้ไข Assembly ด้วย

"ช่วงทดลองใช้" จะเริ่มต้นในวันที่มีผลบังคับใช้ และหากไม่ถูกยกเลิกก่อนกำหนดตามข้อกำหนดของ APIANT เหล่านี้ จะมีระยะเวลาเท่ากับช่วงทดลองใช้ฟรีที่เผยแพร่บนเว็บไซต์ ณ วันที่มีผลบังคับใช้

3. ข้อกำหนดและเงื่อนไขเพิ่มเติมมีผลบังคับใช้กับการใช้งานบริการสมัครสมาชิกของลูกค้า และการให้บริการสมัครสมาชิกของ APIANT

การให้บริการสมัครสมาชิกใดๆ ของ APIANT นั้นอยู่ภายใต้ข้อกำหนดและเงื่อนไขเพิ่มเติม ซึ่ง APIANT จะนำเสนอให้ลูกค้าตรวจสอบและยอมรับในขณะที่ลูกค้าสมัครใช้บริการดังกล่าว และข้อกำหนดเพิ่มเติมเหล่านั้น (แต่ละข้อเรียกว่า "ข้อกำหนดเฉพาะบริการ") จะกลายเป็นส่วนหนึ่งของข้อตกลงนี้ หากข้อกำหนดในที่นี้ขัดแย้งกับข้อกำหนดเฉพาะบริการใดๆ ข้อกำหนดเฉพาะบริการนั้นจะมีผลบังคับใช้ในส่วนที่เกี่ยวข้องกับเรื่องที่ระบุไว้ในข้อกำหนดเฉพาะบริการนั้น

4. ลูกค้าต้องสร้างบัญชีผู้ใช้เพื่อเข้าใช้งานแพลตฟอร์ม

ในการเข้าใช้งานแพลตฟอร์ม ลูกค้าต้องระบุข้อมูลประจำตัวในการเข้าสู่ระบบที่เชื่อมโยงกับบัญชี APIANT ของลูกค้า ("บัญชี") การสร้างบัญชีที่ถูกต้องจำเป็นต้องระบุที่อยู่อีเมลที่ถูกต้อง ซึ่งลูกค้ามีสิทธิ์ในการเข้าถึงและใช้งาน และบุคคลที่สร้างบัญชีดังกล่าวต้อง (i) มีอายุอย่างน้อย 18 ปี (ii) ไม่มีชื่ออยู่ในรายชื่อบุคคลหรือหน่วยงานใดๆ ของรัฐบาลสหรัฐฯ ที่ถูกห้ามรับการส่งออก และ (iii) ไม่ใช่ผู้พำนักอาศัยหรือมีภูมิลำเนาอยู่ในประเทศใดๆ ที่ระบุไว้ในรายชื่อประเทศที่สนับสนุนการก่อการร้ายโดยรัฐบาลสหรัฐฯ (ซึ่งปัจจุบันรวมถึงอิหร่าน ซูดาน และซีเรีย)

ลูกค้ารับรองและยืนยันว่า (i) ข้อมูลทั้งหมดที่ลูกค้าให้แก่ APIANT เกี่ยวกับลูกค้าในการสร้างบัญชี ("ข้อมูลบัญชี") นั้นครบถ้วน ถูกต้อง เป็นปัจจุบัน และแม่นยำ (ii) หากมีการเปลี่ยนแปลงเกิดขึ้นจนทำให้ข้อมูลบัญชีไม่ครบถ้วน ไม่ถูกต้อง ไม่เป็นปัจจุบัน หรือแม่นยำอีกต่อไป ลูกค้าจะต้องอัปเดตบัญชีโดยทันทีเพื่อให้สะท้อนถึงการเปลี่ยนแปลงดังกล่าว และ (iii) บุคคลที่สร้างบัญชีและลูกค้ามีอำนาจและสิทธิที่จำเป็นในการเข้าทำข้อตกลงนี้

5. ลูกค้าต้องสมัครใช้บริการแบบรายเดือนเพื่อเข้าใช้งานแพลตฟอร์ม

APIANT อาจเสนอรูปแบบการกำหนดราคาแบบสมัครสมาชิกหนึ่งแบบหรือมากกว่าสำหรับบริการสมัครสมาชิก ("แผนการสมัครสมาชิก") ซึ่งแตกต่างกันที่ราคา ("ค่าธรรมเนียม") และตัวแปรหนึ่งตัวหรือมากกว่า ซึ่งอาจรวมถึงแต่ไม่จำเป็นต้องรวมถึงระยะเวลาการสมัครสมาชิก ข้อจำกัดด้านระบบอัตโนมัติและงาน ความพร้อมใช้งานของแอปพลิเคชันจากบุคคลที่สาม และบริการพัฒนา ยกเว้นในช่วงระยะเวลาทดลองใช้ การเข้าถึงแพลตฟอร์มจำเป็นต้องสมัครสมาชิกแผนการสมัครสมาชิก (การชำระเงินสำหรับการซื้อดังกล่าวจะครบกำหนดและต้องชำระตามข้อกำหนดเฉพาะบริการที่เกี่ยวข้อง)

6. การชำระค่าธรรมเนียมและการปรับเพิ่มค่าธรรมเนียม

ค่าธรรมเนียมทั้งหมดต้องชำระล่วงหน้าและไม่สามารถขอคืนได้ (ยกเว้นตามที่ระบุไว้ในข้อตกลง) ลูกค้าอนุญาตให้ APIANT เรียกเก็บเงินจากบัตรเครดิตหรือวิธีการชำระเงินอิเล็กทรอนิกส์อื่น ๆ ที่เชื่อมโยงกับบัญชีของลูกค้าสำหรับค่าธรรมเนียมทั้งหมดเมื่อเกิดขึ้น APIANT อาจออกใบแจ้งหนี้ค่าธรรมเนียมให้ลูกค้า และลูกค้าตกลงที่จะชำระใบแจ้งหนี้ดังกล่าวภายในสิบห้า (15) วันนับจากวันที่ได้รับ โดยใช้วิธีการโอนเงิน, ACH, เช็ค หรือวิธีการชำระเงินอื่น ๆ ที่ APIANT ยอมรับได้

ค่าธรรมเนียมทั้งหมดต้องชำระเป็นเงินดอลลาร์สหรัฐ และไม่รวมภาษีที่เกี่ยวข้อง เช่น ภาษีขาย ภาษีสรรพสามิต ภาษีการใช้ หรือภาษีอื่นๆ ที่คล้ายคลึงกัน ลูกค้ามีหน้าที่รับผิดชอบในการชำระภาษีที่เกี่ยวข้องทั้งหมด ไม่ว่าจะชำระโดยตรงหรือชำระให้กับ APIANT ตามที่กฎหมายกำหนด

หากชำระเงินล่าช้า จะใช้นโยบายดังต่อไปนี้:

ระดับ 1 (ค้างชำระ 1 สัปดาห์): จะมีการเรียกเก็บค่าปรับล่าช้าในอัตรา 5% ของยอดเงินคงค้างในใบแจ้งหนี้

ระดับ 2 (ค้างชำระ 2 สัปดาห์): จะมีการเรียกเก็บค่าธรรมเนียมล่าช้าเพิ่มเติมอีก 10% ของยอดเงินคงค้างในใบแจ้งหนี้ (รวมเป็น 15%) และการเข้าถึงแพลตฟอร์ม APIANT จะถูกระงับชั่วคราว จนกว่าจะชำระยอดเงินคงค้างทั้งหมด รวมทั้งค่าธรรมเนียมล่าช้าทั้งหมดครบถ้วน

นอกจากนี้ APIANT อาจเพิ่มค่าธรรมเนียมที่เกี่ยวข้องกับข้อกำหนดเฉพาะบริการใดๆ เมื่อมีการต่ออายุ โดยไม่เกินร้อยละห้า (5%) หรือเปอร์เซ็นต์การเปลี่ยนแปลงจริงของดัชนีราคาผู้บริโภคของสหรัฐฯ ในช่วงระยะเวลาก่อนหน้า แล้วแต่ว่าอัตราใดสูงกว่า APIANT จะพยายามอย่างเต็มที่ที่จะแจ้งให้ทราบล่วงหน้าเกี่ยวกับการเพิ่มค่าธรรมเนียมดังกล่าว

7. การใช้งานแพลตฟอร์มของลูกค้าต้องเป็นไปตามข้อตกลงนี้

การใช้งานแพลตฟอร์มและบริการต่างๆ ขึ้นอยู่กับการที่ลูกค้าต้องปฏิบัติตามข้อตกลงและกฎหมาย กฎระเบียบ และข้อบังคับที่เกี่ยวข้องทั้งหมดอย่างครบถ้วน APIANT อาจยุติข้อตกลงและระงับบัญชีของลูกค้าและการเข้าถึงแพลตฟอร์มได้ทุกเมื่อโดยไม่ต้องแจ้งให้ทราบล่วงหน้า โดยไม่จำกัดสิทธิ์ในการแก้ไขปัญหาอื่นๆ ที่มีอยู่ หาก APIANT เชื่อหรือได้รับข้อกล่าวหาว่าลูกค้าละเมิดข้อตกลงในส่วนใดส่วนหนึ่ง รวมถึงแต่ไม่จำกัดเพียงข้อจำกัดในการใช้งานแพลตฟอร์มและเนื้อหาข้อมูลผู้ใช้ที่ระบุไว้ในส่วนที่ 10

8. ผู้ใช้งานที่ได้รับอนุญาตต้องปฏิบัติตามข้อกำหนดการใช้งานที่เกี่ยวข้อง

ลูกค้าอาจอนุญาตให้พนักงานและ/หรือผู้รับเหมาอิสระของลูกค้าจำนวนตามที่ระบุไว้ในข้อกำหนดการสมัครใช้งานที่เกี่ยวข้องใช้แพลตฟอร์ม ("ผู้ใช้ที่ได้รับอนุญาต") อย่างไรก็ตาม ผู้ใช้ที่ได้รับอนุญาตแต่ละรายต้องตกลงที่จะปฏิบัติตามข้อกำหนดการใช้งานสำหรับผู้ใช้ปลายทางของ APIANT ซึ่ง APIANT อาจนำมาใช้เป็นครั้งคราว ลูกค้าต้องแจ้งให้ APIANT ทราบทันทีหากพบการละเมิดข้อกำหนดการใช้งานสำหรับผู้ใช้ปลายทางของ APIANT โดยผู้ใช้ที่ได้รับอนุญาต และจะต้องรับผิดชอบต่อการละเมิดข้อกำหนดการใช้งานสำหรับผู้ใช้ปลายทางของ APIANT โดยผู้ใช้ที่ได้รับอนุญาตใดๆ

9. ลูกค้ามีหน้าที่รับผิดชอบต่อข้อมูลและภาระผูกพันบางประการที่เกี่ยวข้องกับบริการ

ลูกค้ามีหน้าที่รับผิดชอบแต่เพียงผู้เดียวในเรื่อง (i) การใช้งานบัญชีใดๆ ที่ลูกค้าสามารถเข้าถึงได้ ไม่ว่าการใช้งานหรือผู้ใช้ดังกล่าวจะได้รับอนุญาตหรือไม่ และไม่ว่าลูกค้าจะทราบถึงการใช้งานดังกล่าวหรือไม่ก็ตาม (ii) การรักษาความปลอดภัยและการรักษาความลับของบัญชี รหัสผ่าน และไฟล์ของลูกค้า (iii) การจัดหาและการบำรุงรักษาทั้งฟังก์ชันการทำงานและความปลอดภัยของอุปกรณ์และบริการเสริมใดๆ ที่จำเป็นในการเชื่อมต่อ เข้าถึง หรือใช้งานแพลตฟอร์ม รวมถึงฮาร์ดแวร์ ซอฟต์แวร์ ระบบปฏิบัติการ เครือข่าย และอื่นๆ (iv) การดูแลรักษาบัญชีที่เกี่ยวข้องกับผู้ให้บริการแอปพลิเคชันของบุคคลที่สามที่ลูกค้าใช้ในการเชื่อมต่อกับบริการใดๆ และ (v) การสำรองข้อมูลผู้ใช้ในระหว่างระยะเวลาของข้อตกลง และลูกค้ารับทราบว่าตนจะไม่สามารถเข้าถึงข้อมูลผู้ใช้ได้หลังจากข้อตกลงหมดอายุหรือสิ้นสุดลง

10. ลูกค้าถูกห้ามไม่ให้กระทำการบางอย่างและใช้ข้อมูลผู้ใช้ในบางลักษณะ

ลูกค้าไม่อาจกระทำการใดๆ ดังต่อไปนี้ และไม่อาจอนุญาตหรือสนับสนุนให้บุคคลที่สามกระทำการใดๆ ดังต่อไปนี้:

(i) โดยตรงหรือโดยอ้อม (a) ทำการวิศวกรรมย้อนกลับ ถอดรหัส แยกส่วน หรือพยายามค้นหาหรือดึงรหัสต้นฉบับ รหัสวัตถุ หรือโครงสร้างพื้นฐาน แนวคิด ความรู้ หรืออัลกอริทึมที่เกี่ยวข้องกับแพลตฟอร์ม หรือซอฟต์แวร์ เอกสาร หรือข้อมูลใดๆ ที่เกี่ยวข้องกับแพลตฟอร์ม ("ซอฟต์แวร์") (b) แก้ไข แปล หรือสร้างงานดัดแปลงจากแพลตฟอร์มหรือซอฟต์แวร์ใดๆ (c) ใช้แพลตฟอร์มหรือซอฟต์แวร์ใดๆ เพื่อวัตถุประสงค์ในการแบ่งเวลาใช้งานหรือบริการสำนักงาน หรือบริการคอมพิวเตอร์อื่นๆ แก่บุคคลที่สาม (d) แก้ไข ลบ หรือขัดขวางประกาศหรือฉลากกรรมสิทธิ์ใดๆ หรือ (e) ใช้ซอฟต์แวร์หรือแพลตฟอร์มในลักษณะใดๆ เพื่อช่วยเหลือหรือมีส่วนร่วมในการพัฒนา การตลาด หรือการขายผลิตภัณฑ์ที่อาจแข่งขันกับซอฟต์แวร์หรือแพลตฟอร์มใดๆ

(ii) ประมวลผลข้อมูลผู้ใช้ผ่านแพลตฟอร์มที่ (ก) เป็นการหมิ่นประมาท เป็นอันตรายต่อผู้เยาว์ ลามกอนาจาร ไม่เหมาะสม ภาพอนาจาร ใส่ร้าย ข่มขู่ คุกคาม เป็นเท็จ ทำให้เข้าใจผิด หรือไม่ถูกต้อง (ข) มีหรือทำให้มีการวางม้าโทรจัน เวิร์ม ไวรัส หรือโปรแกรมใดๆ ที่มีเจตนาจะแทรกแซง ทำลาย ทำให้เสียหาย แอบดักจับ หรือยึดระบบ ข้อมูล หรือข้อมูลส่วนบุคคลใดๆ บนระบบของ APIANT หรือบุคคลที่สามอื่นๆ (ค) ละเมิดกฎหมาย กฎ หรือข้อบังคับใดๆ ที่เกี่ยวข้องในระดับท้องถิ่น รัฐบาลกลาง หรือต่างประเทศ รวมถึงกฎหมายว่าด้วยความเป็นส่วนตัวและมาตรฐานความเป็นส่วนตัว (ง) ละเมิดกฎหรือนโยบายใดๆ ของแอปพลิเคชันของบุคคลที่สาม (จ) ละเมิดหรือฝ่าฝืนสิทธิ์ของบุคคลที่สามใดๆ หรือ (ฉ) มีข้อมูลสุขภาพหรือทางการแพทย์ของบุคคลใดๆ หรือข้อมูลใดๆ ของบุคคลที่มีอายุต่ำกว่า 13 ปี

(iii) ในกรณีที่ลูกค้าหรือผู้ใช้ที่ได้รับอนุญาตเข้าถึงหรือใช้ Assembly Editor ตามแผนการสมัครสมาชิก ให้ใช้ Assembly Editor เพื่อพัฒนา รัน หรือสร้าง Task ใดๆ ที่ (ก) จะกระทำการหรืออำนวยความสะดวกในการกระทำความผิดทางอาญา หรือการกระทำที่ผิดกฎหมายอื่นๆ (ข) จะปิดใช้งาน แฮ็ก หรือแทรกแซงกลไกการรักษาความปลอดภัย การลงนามดิจิทัล การจัดการสิทธิ์ดิจิทัล การปกป้องเนื้อหา การตรวจสอบ หรือการรับรองความถูกต้องใดๆ ที่ใช้งานในหรือโดยแพลตฟอร์มหรือบริการ Automator หรือโดยซอฟต์แวร์ บริการ หรือเทคโนโลยีอื่นๆ หรือทำให้ผู้อื่นสามารถกระทำเช่นนั้นได้ (ค) มีมัลแวร์ รหัส โปรแกรม หรือส่วนประกอบภายในที่เป็นอันตราย (เช่น ไวรัสคอมพิวเตอร์ ม้าโทรจัน "backdoor") หรือ (ง) ที่อาจสร้างความเสียหาย ทำลาย หรือส่งผลเสียต่อซอฟต์แวร์ เฟิร์มแวร์ ฮาร์ดแวร์ ข้อมูล ระบบ บริการ หรือเครือข่ายของเราหรือของผู้อื่น หรือ

(iv) เมื่อใช้โครงสร้างพื้นฐานเซิร์ฟเวอร์ MCP (a) พยายามใช้เซิร์ฟเวอร์ MCP เพื่อหลีกเลี่ยงการตรวจสอบสิทธิ์ การจำกัดอัตรา หรือการควบคุมการเข้าถึง (b) ใช้เซิร์ฟเวอร์ MCP เพื่อดึงข้อมูล คัดลอก หรือดาวน์โหลดข้อมูลจากแพลตฟอร์มอย่างเป็นระบบเกินกว่าที่จำเป็นเพื่อดำเนินการตามที่ร้องขอ (c) อนุญาตหรืออำนวยความสะดวกในการปลอมแปลงตัวตนหรือการอนุญาตของผู้ใช้ปลายทางใดๆ ที่เชื่อมต่อกับเซิร์ฟเวอร์ MCP ของลูกค้า หรือ (d) อนุญาตหรืออำนวยความสะดวกในการใช้เซิร์ฟเวอร์ MCP ของลูกค้าในลักษณะใดๆ ที่ละเมิดข้อกำหนดหรือนโยบายของผู้ให้บริการแพลตฟอร์ม AI ที่เกี่ยวข้อง

11. ลูกค้าเป็นเจ้าของทรัพย์สินทางปัญญาบางประการที่ APIANT อาจนำไปใช้ได้

ระหว่างลูกค้าและ APIANT ลูกค้าเป็นเจ้าของและสงวนสิทธิ์ทั้งหมดในข้อมูล สารสนเทศ รวมถึงข้อมูลบัญชี และเนื้อหาอื่น ๆ ที่อัปโหลด จัดเก็บ ส่ง หรือประมวลผลโดยหรือในนามของลูกค้าผ่านแพลตฟอร์มหรือเว็บไซต์ หรือที่แพลตฟอร์มอาจเข้าถึงได้ รวมถึงแต่ไม่จำกัดเพียง ข้อมูลที่ถ่ายโอนโดยหรือระหว่าง หรือเข้าถึงจากแอปพลิเคชันของบุคคลที่สาม ที่เกี่ยวข้องกับการใช้งานบริการใด ๆ ของลูกค้า ("ข้อมูลผู้ใช้") ลูกค้ายินยอมให้ APIANT ใช้และแสวงหาประโยชน์จากข้อมูลผู้ใช้โดยไม่จำกัดสิทธิ์ โอนสิทธิ์ได้ อนุญาตให้ใช้สิทธิ์ช่วงได้ ทั่วโลก และไม่มีค่าลิขสิทธิ์ เพื่อให้บริการแก่ลูกค้าภายใต้ข้อตกลงนี้ และตามความจำเป็นหรือเป็นประโยชน์ในการตรวจสอบและปรับปรุงแพลตฟอร์ม ซอฟต์แวร์ หรือบริการ ทั้งในระหว่างและหลังระยะเวลาของข้อตกลงนี้

16. ข้อมูลที่เปิดเผยระหว่างลูกค้าและ APIANT ถือเป็นความลับ

"ข้อมูลลับ" หมายถึง ข้อมูลลับทั้งหมดที่ฝ่ายหนึ่ง ("ฝ่ายเปิดเผยข้อมูล") เปิดเผยให้แก่ฝ่ายอื่น ("ฝ่ายรับข้อมูล") ที่เกี่ยวข้องกับข้อตกลงนี้ ซึ่งควรเข้าใจได้ว่าเป็นความลับตามลักษณะของข้อมูลและสถานการณ์การเปิดเผย รวมถึง ตัวอย่างเช่น ข้อมูลผู้ใช้ อย่างไรก็ตาม ข้อมูลลับไม่รวมถึงข้อมูลใดๆ ที่ (i) เป็นที่รู้จักหรือกลายเป็นที่รู้จักโดยทั่วไปโดยไม่ละเมิดข้อผูกพันใดๆ ที่มีต่อฝ่ายเปิดเผยข้อมูล (ii) เป็นที่รู้จักของฝ่ายรับข้อมูลมาก่อนที่จะได้รับการเปิดเผยจากฝ่ายเปิดเผยข้อมูลโดยไม่ละเมิดข้อผูกพันใดๆ ที่มีต่อฝ่ายเปิดเผยข้อมูล (iii) ได้รับจากบุคคลที่สามโดยไม่ละเมิดข้อผูกพันใดๆ ที่มีต่อฝ่ายเปิดเผยข้อมูล หรือ (iv) ได้รับการพัฒนาขึ้นโดยอิสระโดยฝ่ายรับข้อมูล

ฝ่ายผู้รับข้อมูลจะ (i) ใช้ความระมัดระวังในระดับที่เหมาะสม (แต่ไม่น้อยกว่าความระมัดระวังที่สมเหตุสมผล) เพื่อปกป้องข้อมูลที่เป็นความลับ (ii) จะไม่เปิดเผยหรือใช้ข้อมูลที่เป็นความลับเพื่อวัตถุประสงค์ใดๆ นอกเหนือขอบเขตของข้อตกลงนี้ และ (iii) จะจำกัดการเข้าถึงข้อมูลที่เป็นความลับเฉพาะพนักงาน ผู้รับจ้าง และตัวแทนของตนที่จำเป็นต้องเข้าถึงข้อมูลดังกล่าวเพื่อวัตถุประสงค์ที่สอดคล้องกับข้อตกลงนี้ และผู้ที่ผูกพันด้วยข้อจำกัดด้านการรักษาความลับที่ไม่เข้มงวดน้อยกว่าที่ระบุไว้ในที่นี้ อย่างไรก็ตาม APIANT อาจเปิดเผยข้อมูลที่เป็นความลับของลูกค้าในขอบเขตที่ตนเชื่อว่าจำเป็นอย่างสมเหตุสมผลเพื่อปฏิบัติตามคำสั่งศาลหรือกฎหมายใดๆ

ภายในสามสิบ (30) วันนับจากวันที่สัญญาหมดอายุหรือสิ้นสุดก่อนกำหนด APIANT จะต้องทำลายหรือลบข้อมูลที่เป็นความลับของลูกค้าที่ประกอบด้วยข้อมูลผู้ใช้ออกจากระบบของ APIANT ในกรณีที่ APIANT ครอบครองหรือควบคุมข้อมูลดังกล่าว

19. บริษัท APIANT ไม่รับผิดชอบต่อความเสียหายและความรับผิดบางประการ และมีขีดจำกัดความรับผิดสูงสุดตามที่ระบุไว้ในที่นี้

แม้จะมีข้อความใดๆ ที่ขัดแย้งกับข้อตกลงนี้ก็ตาม ในกรณีใดๆ ก็ตาม (I) ความรับผิดของ APIANT ที่เกิดขึ้นจากหรือเกี่ยวข้องกับข้อตกลงนี้ ไม่ว่าจะในสัญญา การละเมิด หรือภายใต้ทฤษฎีความรับผิดอื่นๆ จะไม่เกินจำนวนเงินรวมทั้งหมดที่ลูกค้าได้ชำระหรือค้างชำระภายใต้ข้อตกลงนี้ในช่วงเดือนปฏิทินก่อนหน้าวันที่เกิดเหตุการณ์ที่ก่อให้เกิดการเรียกร้อง (จำนวนเงินดังกล่าวมีเจตนาให้เป็นวงเงินสูงสุดสะสม ไม่ใช่ต่อเหตุการณ์) และ (II) APIANT จะไม่มีความรับผิดใดๆ ต่อลูกค้าสำหรับกำไรหรือรายได้ที่สูญเสียไป หรือสำหรับความเสียหายทางอ้อม ความเสียหายที่เกิดขึ้นโดยบังเอิญ ความเสียหายที่ตามมา หรือการชดเชยใดๆ ค่าเสียหายพิเศษ ค่าเสียหายเชิงลงโทษ หรือค่าเสียหายเชิงตัวอย่าง ไม่ว่าจะเกิดจากสาเหตุใด ไม่ว่าจะในสัญญา การละเมิด หรือภายใต้ทฤษฎีความรับผิดอื่นใด และไม่ว่า APIANT จะได้รับแจ้งถึงความเป็นไปได้ของค่าเสียหายดังกล่าวหรือไม่ก็ตาม ข้อจำกัดและการปฏิเสธความรับผิดข้างต้นจะไม่ใช้บังคับในส่วนที่กฎหมายที่เกี่ยวข้องห้ามไว้

20. ระยะเวลาและการสิ้นสุดสัญญา

เว้นแต่จะมีการบอกเลิกก่อนกำหนดตามที่ระบุไว้ในที่นี้ ข้อตกลงนี้จะมีผลบังคับใช้ตั้งแต่วันที่มีผลบังคับใช้ และจะมีผลต่อไปตลอดระยะเวลาของแผนการสมัครสมาชิกที่ซื้อไว้ ตามข้อกำหนดเฉพาะบริการที่เกี่ยวข้อง

นอกเหนือจากมาตรการแก้ไขอื่นใดที่ APIANT อาจมีแล้ว APIANT อาจบอกเลิกข้อตกลงนี้ได้ทันทีโดยการแจ้งเป็นลายลักษณ์อักษร หากลูกค้าไม่ชำระค่าธรรมเนียมหรือจำนวนเงินอื่นใดตามกำหนด หรือละเมิดข้อตกลงอย่างร้ายแรง

เมื่อสัญญาถูกยกเลิก ลูกค้าต้องยุติการใช้งานและการเข้าถึงแพลตฟอร์มทั้งหมดโดยทันที ข้อกำหนดในมาตรา 11, 12, 16-27 ของข้อกำหนด APIANT เหล่านี้จะมีผลบังคับใช้ต่อไปแม้ว่าสัญญาจะถูกยกเลิกหรือหมดอายุลงก็ตาม สิทธิและภาระผูกพันอื่นๆ ทั้งหมดจะไม่มีผลบังคับใช้อีกต่อไป

21. ข้อตกลงนี้อยู่ภายใต้บังคับของกฎหมายแห่งเครือรัฐเพนซิลเวเนีย

ข้อตกลงนี้อยู่ภายใต้บังคับของกฎหมายแห่งเครือรัฐเพนซิลเวเนียในทุกประการ โดยไม่คำนึงถึงกฎเกณฑ์ที่เกี่ยวข้องกับความขัดแย้งทางกฎหมาย ทั้งการนำพระราชบัญญัติธุรกรรมข้อมูลคอมพิวเตอร์แบบเดียวกัน (Uniform Computer Information Transactions Act) และอนุสัญญาสหประชาชาติว่าด้วยการขายสินค้าระหว่างประเทศ (U.N. Convention on the International Sale of Goods) มาใช้ ไม่ได้มีผลบังคับใช้กับข้อตกลงนี้ หรือกับสิทธิและหน้าที่ของคู่สัญญาภายใต้ข้อตกลงนี้

22. ข้อพิพาทใดๆ ที่เกี่ยวข้องกับข้อตกลงนี้จะได้รับการแก้ไขโดยวิธีการอนุญาโตตุลาการที่มีผลผูกพัน

ข้อพิพาทใดๆ ที่เกิดขึ้นจากหรือเกี่ยวข้องกับข้อตกลงนี้ หรือเนื้อหาของข้อตกลงนี้ จะได้รับการแก้ไขโดยการอนุญาโตตุลาการที่มีผลผูกพันแต่เพียงผู้เดียว ภายใต้กฎการอนุญาโตตุลาการทางการค้าของสมาคมอนุญาโตตุลาการแห่งอเมริกา (“AAA”) การอนุญาโตตุลาการจะดำเนินการในเมืองฟิลาเดลเฟีย รัฐเพนซิลเวเนีย โดยอนุญาโตตุลาการเพียงคนเดียวที่มีความรู้ความเชี่ยวชาญในเรื่องการทำสัญญากับภาครัฐ และด้านเชิงพาณิชย์ของข้อตกลง “ซอฟต์แวร์เป็นบริการ” หรือ “แพลตฟอร์มเป็นบริการ” และทรัพย์สินทางปัญญา อนุญาโตตุลาการจะให้คำอธิบายเป็นลายลักษณ์อักษรโดยละเอียดแก่คู่กรณีเพื่อสนับสนุนคำตัดสินของตน และไม่ว่าผลลัพธ์จะเป็นอย่างไร คู่กรณีแต่ละฝ่ายจะต้องรับผิดชอบค่าใช้จ่ายและค่าธรรมเนียมของตนเอง (รวมถึงค่าทนายความ) ที่เกี่ยวข้องกับกระบวนการอนุญาโตตุลาการ และร้อยละห้าสิบ (50%) ของค่าธรรมเนียมของอนุญาโตตุลาการและ AAA คำตัดสินของอนุญาโตตุลาการจะเป็นที่สิ้นสุดและมีผลผูกพัน และสามารถบังคับใช้ได้ในศาลใดๆ ที่มีอำนาจพิจารณาคดี

24. ข้อกำหนดบางประการที่เกี่ยวข้องกับผู้ใช้งานภาครัฐ

ซอฟต์แวร์และแพลตฟอร์มเป็น "สินค้าเชิงพาณิชย์" ตามความหมายที่กำหนดไว้ใน 48 C.F.R. §2.101 ซึ่งประกอบด้วย "ซอฟต์แวร์คอมพิวเตอร์เชิงพาณิชย์" และ "เอกสารประกอบซอฟต์แวร์คอมพิวเตอร์เชิงพาณิชย์" ตามความหมายที่ใช้ใน 48 C.F.R. §12.212 หรือ 48 C.F.R. §227.7202 แล้วแต่กรณี ในกรณีที่ซอฟต์แวร์หรือแพลตฟอร์มถือว่าได้รับอนุญาตให้แก่ลูกค้าภายใต้ข้อตกลงนี้ สอดคล้องกับ 48 C.F.R. §12.212 หรือ 48 C.F.R. §227.7202-1 ถึง 227.7202-4 แล้วแต่กรณี ซอฟต์แวร์คอมพิวเตอร์เชิงพาณิชย์และเอกสารประกอบซอฟต์แวร์คอมพิวเตอร์เชิงพาณิชย์จะได้รับอนุญาตให้แก่ผู้ใช้ปลายทางของรัฐบาลสหรัฐฯ (ก) เฉพาะในฐานะสินค้าเชิงพาณิชย์ และ (ข) ด้วยสิทธิ์เฉพาะที่มอบให้แก่ผู้ใช้ปลายทางรายอื่นทั้งหมดตามข้อกำหนดและเงื่อนไขในที่นี้ ลิขสิทธิ์ยังไม่ได้รับการเผยแพร่ สงวนสิทธิ์ภายใต้กฎหมายลิขสิทธิ์ของสหรัฐอเมริกา

25. ข้อกำหนดและข้อจำกัดบางประการที่เกี่ยวข้องกับกฎหมายการส่งออก

ลูกค้ารับทราบว่าซอฟต์แวร์และแพลตฟอร์มอยู่ภายใต้ข้อบังคับการบริหารการส่งออกของสหรัฐอเมริกาและกฎหมาย ข้อจำกัด และข้อบังคับการส่งออกอื่นๆ (รวมเรียกว่า "กฎหมายการส่งออก") และโดยไม่จำกัดภาระผูกพันอื่นใดของลูกค้าภายใต้ข้อตกลงนี้ ลูกค้าจะปฏิบัติตามกฎหมายการส่งออก ลูกค้าจะไม่จัดส่ง โอน ส่งออก หรือส่งออกซ้ำซอฟต์แวร์หรือแพลตฟอร์มโดยตรงหรือโดยอ้อมไปยัง: (i) ประเทศใดๆ ที่อยู่ภายใต้ข้อจำกัดการส่งออกของสหรัฐอเมริกา; (ii) ผู้ใช้ปลายทางใดๆ ที่ลูกค้ารู้หรือมีเหตุผลให้รู้ว่าจะนำไปใช้ในการออกแบบ พัฒนา หรือผลิตอาวุธนิวเคลียร์ เคมี หรือชีวภาพ หรือระบบจรวด ยานปล่อยอวกาศ และจรวดสำรวจ หรือระบบยานอากาศไร้คนขับ (แต่ละรายการเรียกว่า "การใช้งานต้องห้าม"); หรือ (iii) ผู้ใช้ปลายทางใดๆ ที่ถูกห้ามไม่ให้เข้าร่วมในธุรกรรมการส่งออกของสหรัฐอเมริกาโดยหน่วยงานรัฐบาลกลางใดๆ ของรัฐบาลสหรัฐอเมริกา ลูกค้ารับรองและยืนยันว่าลูกค้าจะไม่ใช้ซอฟต์แวร์เพื่อการใช้งานต้องห้าม
