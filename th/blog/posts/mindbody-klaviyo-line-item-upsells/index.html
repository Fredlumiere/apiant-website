การซิงค์ข้อมูลการซื้อสินค้าแต่ละรายการจาก Mindbody ไปยัง Klaviyo สำหรับการขายเสริมสินค้าที่มีราคาสูง

Fred Lumiere 20 พฤศจิกายน 2024 ใช้เวลาอ่าน 5 นาที
#ฟิตเนสและสุขภาพ#จิตใจและร่างกาย#คลาวิโย#CRMConnect#เครื่องมือข้อมูล

เหตุใดช่องข้อมูลการขายเพียงช่องเดียวจึงทำลายตรรกะการขายเพิ่ม

แพ็กเกจสุขภาพราคาสูงไม่ได้มีแค่สินค้าเดียว แพ็กเกจพักผ่อน 12 สัปดาห์ราคา 6,200 ดอลลาร์ มักจะรวมที่พักพื้นฐาน แผนอาหาร จำนวนคลาสเรียนรายวัน แพ็กเกจการฝึกส่วนตัว และบริการเสริมเพิ่มเติม (เช่น การบำบัดด้วยเสียง เครดิตการนวด การฝึกแบบตัวต่อตัวกับโค้ช) ทุกรายการในใบแจ้งหนี้ล้วนเป็นโอกาสในการเพิ่มยอดขาย ขายสินค้าที่เกี่ยวข้อง และต่ออายุสมาชิก

ปัญหาเริ่มต้นเมื่อ CRM ของคุณเห็นเพียงยอดรวมของคำสั่งซื้อเท่านั้น สมมติว่า: Silver Fern Wellness Retreat (ตัวอย่าง) ขายแพ็กเกจราคา 4,000 ถึง 8,000 ดอลลาร์สหรัฐฯ ในรูปแบบโปรแกรม 12 สัปดาห์ต่อเนื่องกัน Klaviyo ที่ยังไม่ได้แก้ไข จะเห็นเพียงว่าลูกค้าจ่ายเงิน 5,800 ดอลลาร์สหรัฐฯ เมื่อวันอังคารที่ผ่านมา แต่ Klaviyo ไม่สามารถเห็นได้ว่าแพ็กเกจนั้นรวมเครดิตการนวด 3 ครั้ง และไม่มีเซสชั่นการฝึกสอนส่วนตัวเลย ดังนั้นขั้นตอนหลังการซื้อจึงอาจแสดงคำแนะนำการขายเพิ่มเติมแบบทั่วไป (ซึ่งจะทำให้ผู้ซื้อครึ่งหนึ่งที่ซื้อสินค้าที่ถูกเสนอขายเพิ่มเติมไปแล้วรู้สึกไม่พอใจ) หรืออาจไม่แสดงคำแนะนำใดๆ เลย

สิ่งที่เครื่องมือสำเร็จรูปทั่วไปขาดไป

ข้อมูลที่ Mindbody ป้อนสำหรับการขายนั้นประกอบด้วยรายการสินค้า แต่เครื่องมือเชื่อมต่อทั่วไปส่วนใหญ่จะยุบการขายให้เหลือเพียงแถวเดียว ก่อนที่จะส่งไปยัง Klaviyo เหตุผลส่วนใหญ่มักเกี่ยวข้องกับการสร้างแบบจำลองข้อมูล: เหตุการณ์ "Placed Order" ของ Klaviyo คาดหวังอาร์เรย์ของรายการสินค้า และการเชื่อมต่อข้อมูลการขายแบบซ้อนกันของ Mindbody เข้ากับอาร์เรย์นั้นอย่างถูกต้อง (ด้วย SKU ราคา และแท็กหมวดหมู่ที่เหมาะสม) เป็นงานที่ถูกตัดออกไปใน "Zap ที่รวดเร็ว" ผลลัพธ์ที่ได้คือคำสั่งซื้อแบบบรรทัดเดียวใน Klaviyo โดยไม่มีรายการสินค้า ไม่มีรายละเอียดเพิ่มเติม และไม่มีการคำนวณการขายเพิ่ม

แนวทาง APIANT

CRMConnect Mindbody ไปยัง Klaviyo ประกอบด้วย การซิงค์รายการซื้อและรายการขาย นับเป็นคุณสมบัติชั้นเยี่ยม ข้อมูลการขายจะไหลจาก Mindbody เข้าสู่ Klaviyo โดยแต่ละรายการสินค้าจะยังคงอยู่ครบถ้วน ดังนั้นโปรไฟล์และข้อมูลเหตุการณ์ของ Klaviyo จึงคงโครงสร้างไว้สำหรับการแบ่งกลุ่มและตรรกะการไหลของข้อมูล

กลไกการประมวลผลข้อมูลแบบรวมศูนย์ภายใน APIANT นั้นไม่ขึ้นกับรูปแบบข้อมูล ข้อมูลการขายของ Mindbody จะถูกแปลงผ่าน XPath (มาตรฐานเปิดของ W3C) ไปยัง Schema เหตุการณ์ของ Klaviyo โดยไม่สูญเสียการจัดลำดับชั้น แต่ละรายการสินค้าจะมี SKU ราคา หมวดหมู่ และปริมาณของตัวเอง ซึ่งเป็นส่วนที่ทำให้ตรรกะการขายเพิ่มเป็นไปได้

สามฟีเจอร์หลักจากแอป API คือหัวใจสำคัญของฟีเจอร์นี้:

  • การซิงค์รายการซื้อและรายการขาย สำหรับรายการที่มีโครงสร้าง
  • การซิงค์ข้อมูลโปรไฟล์ลูกค้าแบบเรียลไทม์ ดังนั้นข้อมูลโปรไฟล์ผู้ซื้อจึงเป็นปัจจุบันและสามารถแบ่งกลุ่มได้
  • การติดตามการเข้าชม ดังนั้น การดูแลลูกค้าหลังการขายจึงสามารถแตกแขนงออกไปได้ตามว่าลูกค้าได้เริ่มใช้สินค้าที่ซื้อไปจริงหรือไม่

ลักษณะการซิงค์รายการสินค้าใน Klaviyo เป็นอย่างไร

การซื้อแพ็กเกจการพักผ่อนจะถูกจัดวางใน Klaviyo ในรูปแบบของกิจกรรมที่มีโครงสร้าง โดยมีรูปแบบคร่าวๆ ดังนี้:

{
  "event": "Placed Order",
  "customer_properties": {
    "$email": "client@example.com",
    "mindbody_client_id": "MB-44918"
  },
  "properties": {
    "OrderId": "MB-INV-71204",
    "Total": 5800.00,
    "Currency": "USD",
    "Items": [
      { "SKU": "RETREAT-12W-DLX", "Name": "12-Week Deluxe Package", "Price": 4200, "Category": "Retreat Base" },
      { "SKU": "MEAL-VEG-12W", "Name": "Vegetarian Meal Plan", "Price": 800, "Category": "Meal Plan" },
      { "SKU": "MASSAGE-CR-3", "Name": "Massage Credits x3", "Price": 450, "Category": "Add-On" },
      { "SKU": "SOUND-BATH-1", "Name": "Sound Bath Session", "Price": 350, "Category": "Add-On" }
    ]
  }
}

ตอนนี้ Klaviyo สามารถแบ่งกลุ่มลูกค้าได้ตาม “ซื้อแพ็กเกจ 12 สัปดาห์โดยไม่รวมการฝึกสอนส่วนตัว” หรือ “ซื้อแผนอาหารแต่ไม่รวมส่วนเสริม” หรือ “ใช้จ่ายมากกว่า 5,000 ดอลลาร์ แต่ไม่ได้ใช้เครดิตการนวดเลย”

การออกแบบสินค้าเสริมเพื่อการขายเพิ่มเติมสำหรับแพ็กเกจราคาสูง

กระบวนการขายเพิ่มมีตัวกระตุ้นสามอย่าง แต่ละอย่างเชื่อมโยงกับสิ่งที่เป็นอยู่ หายไป จากรายการสินค้า:

  1. ไม่ได้ซื้อบริการฝึกสอนส่วนตัว หลังจากเริ่มการอบรมไปได้สามวัน ให้ส่งอีเมลเสนอส่วนลดสำหรับการแนะนำตัวแบบตัวต่อตัวกับโค้ชอาวุโส และอย่าส่งอีเมลไปยังผู้ที่มีรายการสินค้าที่ระบุรหัสสินค้า (SKU) สำหรับการฝึกสอนอยู่แล้ว
  2. ซื้อแพ็คเกจอาหารแล้ว ไม่มีส่วนเสริมเพิ่มเติม หลังจากผ่านไปเจ็ดวัน ให้ส่งอีเมล "คุณรู้หรือไม่" เกี่ยวกับเครดิตสำหรับการบำบัดด้วยเสียงและการนวด พร้อมราคาแพ็กเกจ
  3. ซื้อส่วนเสริมแล้ว แต่ไม่มีการจองคลาสเรียนในอีก 14 วันข้างหน้า สร้างอีเมลเพื่อกระตุ้นการมีส่วนร่วมอีกครั้งด้วยตารางเวลาที่วางแผนไว้ล่วงหน้า

แต่ละสาขาจะอ่านข้อมูลจากรายการสินค้าที่มีอยู่แล้วในโปรไฟล์ ไม่มีใครถูกเสนอขายสินค้าที่ซื้อไปแล้ว แค่นี้ก็เพียงพอแล้วที่จะป้องกันไม่ให้ลูกค้าที่ซื้อสินค้าราคาสูงยกเลิกการสมัครรับข้อมูลของคุณ

การเพิ่มสิทธิประโยชน์สะสมแต้มสำหรับการซื้อซ้ำ

กระบวนการที่สองใช้ข้อมูลชุดเดียวกัน แต่ใช้ช่วงเวลาที่ยาวกว่า ใช้รายการต่างๆ ในการคำนวณมูลค่าตลอดอายุการใช้งานแยกตามหมวดหมู่:

  • เมื่อใช้บริการนวดตลอดชีพครบ 1,500 ดอลลาร์ขึ้นไป จะได้รับเชิญเข้าร่วมกลุ่ม "ผู้ก่อตั้ง" พร้อมสิทธิ์ในการจองก่อนใคร
  • เข้าพักในรีทรีทเต็มรูปแบบสองครั้งภายในสิบสองเดือน: ยกเว้นค่าอาหารในรีทรีทครั้งที่สาม
  • แพ็กเกจพักผ่อน 1 ที่ พร้อมบริการเสริมอีก 4 อย่าง: เปิดใช้งานการขอคำแนะนำด้วยรหัสส่วนตัว

การคำนวณทางคณิตศาสตร์ดำเนินการใน Klaviyo โดยใช้ Items อาร์เรย์ในแต่ละเหตุการณ์ "สั่งซื้อสำเร็จ" การผสานรวมนี้ช่วยรักษาความถูกต้องของอาร์เรย์เท่านั้น

ตัวแทน AOV Lift ราคาแพ็คเกจ 4,000-8,000 ดอลลาร์

ภาพประกอบใช้เพื่อเป็นตัวอย่าง ไม่ใช่ลูกค้าจริง:

  • อัตราการแนบส่วนเสริม (อีเมลหลังการซื้อทั่วไป): ประมาณ 8 ถึง 12 เปอร์เซ็นต์
  • อัตราการขายสินค้าเสริมที่มีรายละเอียดแต่ละรายการเพิ่มขึ้นเป็น 20 ถึง 28 เปอร์เซ็นต์ ส่วนใหญ่เป็นเพราะข้อเสนอที่เหมาะสมเข้าถึงผู้ซื้อที่เหมาะสม
  • มูลค่าการสั่งซื้อเฉลี่ยต่อการลงทะเบียนเข้าร่วมกิจกรรม: เพิ่มขึ้น 6 ถึง 11 เปอร์เซ็นต์ในกลุ่มตัวอย่าง
  • อัตราการยกเลิกการสมัครรับข้อมูลหลังการซื้อ: ต่ำกว่า เนื่องจากกลไกการระงับช่วยป้องกันปัญหา "เรากำลังพยายามขายสินค้าเพิ่มเติมให้คุณ ทั้งๆ ที่คุณซื้อไปแล้ว"

สิ่งเหล่านี้ทำงานด้วยกลไก ไม่ใช่เวทมนตร์ รายการต่างๆ ทำให้การกำหนดเป้าหมายมีความแม่นยำ การกำหนดเป้าหมายที่แม่นยำเป็นตัวขับเคลื่อนการยก

ผู้สร้างบ้าน

  • ยืนยันให้มีการซิงค์ข้อมูลรายละเอียดแต่ละรายการระหว่าง Mindbody และ Klaviyo ยอดรวมคำสั่งซื้อทั้งหมดเป็นทางตันทางการตลาดเมื่อราคาสินค้าสูง
  • สร้างตรรกะการขายเพิ่มของคุณบนพื้นฐานของสิ่งที่เป็นอยู่ ไม่มา จากอาร์เรย์ของรายการ นั่นคือตำแหน่งที่ขั้นตอนต่อไปที่สามารถซื้อได้อยู่
  • ใช้ยอดใช้จ่ายตลอดช่วงชีวิตในหมวดหมู่ต่างๆ (นวด, การฝึกสอน, อาหาร) สำหรับระดับความภักดี รายได้รวมนั้นไม่ชัดเจนพอสำหรับธุรกิจแพ็กเกจการพักผ่อน
