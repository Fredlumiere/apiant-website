เราเก็บรวบรวมข้อมูลส่วนบุคคลที่คุณให้เราโดยสมัครใจเมื่อคุณลงทะเบียนใช้บริการ แสดงความสนใจในการรับข้อมูลเกี่ยวกับเราหรือผลิตภัณฑ์และบริการของเรา เมื่อคุณเข้าร่วมกิจกรรมบนบริการ หรือเมื่อคุณติดต่อเราด้วยวิธีอื่นใด

ข้อมูลที่เราเก็บรวบรวมประกอบด้วย:

  • ข้อมูลบันทึกและการใช้งาน ข้อมูลบันทึกและการใช้งานคือข้อมูลที่เกี่ยวข้องกับบริการ การวินิจฉัย การใช้งาน และประสิทธิภาพ ซึ่งเซิร์ฟเวอร์ของเราจะรวบรวมโดยอัตโนมัติเมื่อคุณเข้าถึงหรือใช้บริการของเรา และเราจะบันทึกไว้ในไฟล์บันทึก ขึ้นอยู่กับวิธีการที่คุณโต้ตอบกับเรา ข้อมูลบันทึกนี้อาจรวมถึงที่อยู่ IP ของคุณ ข้อมูลอุปกรณ์ ประเภทเบราว์เซอร์ และการตั้งค่า ตลอดจนข้อมูลเกี่ยวกับกิจกรรมของคุณในบริการ (เช่น วันที่/เวลาที่เกี่ยวข้องกับการใช้งานของคุณ หน้าและไฟล์ที่ดู การค้นหา และการกระทำอื่นๆ ที่คุณทำ เช่น คุณสมบัติใดที่คุณใช้) ข้อมูลเหตุการณ์ของอุปกรณ์ (เช่น กิจกรรมของระบบ รายงานข้อผิดพลาด (บางครั้งเรียกว่า "crash dump") และการตั้งค่าฮาร์ดแวร์)
  • ข้อมูลอุปกรณ์ เราเก็บรวบรวมข้อมูลอุปกรณ์ เช่น ข้อมูลเกี่ยวกับคอมพิวเตอร์ โทรศัพท์ แท็บเล็ต หรืออุปกรณ์อื่นๆ ที่คุณใช้ในการเข้าถึงบริการ ทั้งนี้ ขึ้นอยู่กับอุปกรณ์ที่ใช้ ข้อมูลอุปกรณ์นี้อาจรวมถึงข้อมูลต่างๆ เช่น ที่อยู่ IP ของคุณ (หรือพร็อกซีเซิร์ฟเวอร์) หมายเลขประจำตัวอุปกรณ์และแอปพลิเคชัน ตำแหน่งที่ตั้ง ประเภทเบราว์เซอร์ รุ่นฮาร์ดแวร์ ผู้ให้บริการอินเทอร์เน็ตและ/หรือผู้ให้บริการเครือข่ายมือถือ ระบบปฏิบัติการ และข้อมูลการกำหนดค่าระบบ
  • ข้อมูลตำแหน่งที่ตั้ง เราเก็บรวบรวมข้อมูลตำแหน่งที่ตั้ง เช่น ข้อมูลเกี่ยวกับตำแหน่งที่ตั้งของอุปกรณ์ของคุณ ซึ่งอาจเป็นข้อมูลที่แม่นยำหรือไม่แม่นยำก็ได้ ปริมาณข้อมูลที่เราเก็บรวบรวมนั้นขึ้นอยู่กับประเภทและการตั้งค่าของอุปกรณ์ที่คุณใช้ในการเข้าถึงบริการ ตัวอย่างเช่น เราอาจใช้ GPS และเทคโนโลยีอื่นๆ เพื่อเก็บรวบรวมข้อมูลตำแหน่งทางภูมิศาสตร์ที่บอกเราถึงตำแหน่งปัจจุบันของคุณ (โดยอิงจากที่อยู่ IP ของคุณ) คุณสามารถเลือกที่จะไม่ให้เราเก็บรวบรวมข้อมูลนี้ได้โดยการปฏิเสธการเข้าถึงข้อมูลหรือโดยการปิดใช้งานการตั้งค่าตำแหน่งที่ตั้งบนอุปกรณ์ของคุณ อย่างไรก็ตาม หากคุณเลือกที่จะไม่ให้เราเก็บรวบรวมข้อมูล คุณอาจไม่สามารถใช้บริการบางส่วนได้

2. เราประมวลผลข้อมูลของคุณอย่างไร?

โดยสรุป: เราประมวลผลข้อมูลของคุณเพื่อให้บริการ ปรับปรุง และบริหารจัดการบริการของเรา ติดต่อสื่อสารกับคุณ เพื่อความปลอดภัยและการป้องกันการฉ้อโกง และเพื่อให้เป็นไปตามกฎหมาย นอกจากนี้เราอาจประมวลผลข้อมูลของคุณเพื่อวัตถุประสงค์อื่น ๆ โดยได้รับความยินยอมจากคุณ

เราประมวลผลข้อมูลส่วนบุคคลของคุณด้วยเหตุผลหลายประการ ขึ้นอยู่กับวิธีการที่คุณใช้งานบริการของเรา ซึ่งรวมถึง:

  • เพื่ออำนวยความสะดวกในการสร้างบัญชีและการตรวจสอบสิทธิ์ รวมถึงการจัดการบัญชีผู้ใช้ในด้านอื่นๆ เราอาจประมวลผลข้อมูลของคุณเพื่อให้คุณสามารถสร้างและเข้าสู่ระบบบัญชีของคุณได้ รวมถึงเพื่อให้บัญชีของคุณใช้งานได้อย่างปกติ
  • เพื่อส่งมอบและอำนวยความสะดวกในการส่งมอบบริการแก่ผู้ใช้ เราอาจประมวลผลข้อมูลของคุณเพื่อให้บริการที่คุณร้องขอ
  • เพื่อตอบข้อซักถามของผู้ใช้/ให้การสนับสนุนแก่ผู้ใช้ เราอาจประมวลผลข้อมูลของคุณเพื่อตอบข้อซักถามของคุณและแก้ไขปัญหาใดๆ ที่คุณอาจมีเกี่ยวกับบริการที่ร้องขอ
  • เพื่อส่งข้อมูลด้านการบริหารจัดการให้คุณ เราอาจประมวลผลข้อมูลของคุณเพื่อส่งรายละเอียดเกี่ยวกับผลิตภัณฑ์และบริการของเรา การเปลี่ยนแปลงข้อกำหนดและนโยบายของเรา และข้อมูลอื่น ๆ ที่คล้ายคลึงกัน
  • เพื่อดำเนินการและจัดการคำสั่งซื้อของคุณ เราอาจประมวลผลข้อมูลของคุณเพื่อดำเนินการและจัดการคำสั่งซื้อ การชำระเงิน การคืนสินค้า และการแลกเปลี่ยนสินค้าที่คุณทำผ่านบริการนี้
  • เพื่อขอรับคำติชม เราอาจประมวลผลข้อมูลของคุณเมื่อจำเป็นเพื่อขอความคิดเห็นและติดต่อคุณเกี่ยวกับการใช้บริการของเรา
  • เพื่อส่งข้อมูลการตลาดและโปรโมชั่นให้คุณ เราอาจประมวลผลข้อมูลส่วนบุคคลที่คุณส่งมาให้เราเพื่อวัตถุประสงค์ทางการตลาด หากเป็นไปตามความต้องการด้านการตลาดของคุณ คุณสามารถยกเลิกการรับอีเมลทางการตลาดจากเราได้ตลอดเวลา สำหรับข้อมูลเพิ่มเติม โปรดดูที่ "คุณมีสิทธิ์ในความเป็นส่วนตัวอะไรบ้าง?" ด้านล่าง.
  • เพื่อนำเสนอโฆษณาที่ตรงเป้าหมายให้กับคุณ เราอาจประมวลผลข้อมูลของคุณเพื่อพัฒนาและแสดงเนื้อหาและโฆษณาที่ปรับให้เหมาะสมกับความสนใจ สถานที่ตั้ง และอื่นๆ ของคุณ
  • เพื่อปกป้องบริการของเรา เราอาจประมวลผลข้อมูลของคุณเพื่อเป็นส่วนหนึ่งของความพยายามในการรักษาความปลอดภัยของบริการของเรา รวมถึงการตรวจสอบและป้องกันการฉ้อโกง
  • เพื่อระบุแนวโน้มการใช้งาน เราอาจประมวลผลข้อมูลเกี่ยวกับการใช้งานบริการของเรา เพื่อให้เข้าใจการใช้งานบริการได้ดียิ่งขึ้นและเพื่อปรับปรุงบริการให้ดียิ่งขึ้น
  • เพื่อประเมินประสิทธิภาพของแคมเปญการตลาดและการส่งเสริมการขายของเรา เราอาจประมวลผลข้อมูลของคุณเพื่อทำความเข้าใจวิธีการนำเสนอแคมเปญการตลาดและโปรโมชั่นที่เหมาะสมกับคุณมากที่สุด
  • เพื่อรักษาหรือปกป้องผลประโยชน์ที่สำคัญยิ่งของบุคคล เราอาจประมวลผลข้อมูลของคุณเมื่อจำเป็นเพื่อรักษาหรือปกป้องผลประโยชน์ที่สำคัญของบุคคล เช่น เพื่อป้องกันอันตราย

3. โครงสร้างพื้นฐานเซิร์ฟเวอร์ MCP

โดยสรุป: APIANT ให้บริการโครงสร้างพื้นฐานเซิร์ฟเวอร์ MCP (Model Context Protocol) ที่ลูกค้าของเราสามารถนำไปใช้งานบนเซิร์ฟเวอร์เฉพาะและโดเมนของตนเองได้ เมื่อข้อมูลของคุณถูกประมวลผลผ่านเซิร์ฟเวอร์ MCP ที่ใช้ APIANT ของลูกค้า เราจะประมวลผลเฉพาะข้อมูลที่จำเป็นต่อการดำเนินการตามคำขอเท่านั้น เราจะไม่ใช้ข้อมูลการโต้ตอบของ MCP เพื่อฝึกฝนโมเดล AI แสดงโฆษณา หรือสร้างโปรไฟล์ผู้ใช้

เซิร์ฟเวอร์ APIANT MCP ทำงานอย่างไร

APIANT ช่วยให้ลูกค้า ("ผู้สร้าง") สามารถติดตั้งเซิร์ฟเวอร์ที่เข้ากันได้กับ MCP บนโครงสร้างพื้นฐานและโดเมนเฉพาะของตนเองได้ เซิร์ฟเวอร์ MCP เหล่านี้ช่วยให้ผู้ใช้ปลายทางของผู้สร้างสามารถโต้ตอบกับการผสานรวมและระบบอัตโนมัติของผู้สร้างผ่านแพลตฟอร์ม AI (เช่น Claude โดย Anthropic) โดยใช้ภาษาธรรมชาติ เมื่อผู้ใช้ปลายทางเชื่อมต่อกับเซิร์ฟเวอร์ MCP ของผู้สร้าง แพลตฟอร์ม AI จะส่งคำขอเรียกใช้เครื่องมือไปยังเซิร์ฟเวอร์ที่ขับเคลื่อนด้วย APIANT ของผู้สร้าง APIANT ให้บริการโครงสร้างพื้นฐานของแพลตฟอร์ม ผู้ใช้ปลายทางเชื่อมต่อกับเซิร์ฟเวอร์ของผู้สร้าง ไม่ได้เชื่อมต่อกับ APIANT โดยตรง

ข้อมูลใดบ้างที่ถูกประมวลผลผ่านเซิร์ฟเวอร์ MCP

เมื่อมีการประมวลผลข้อมูลผ่านเซิร์ฟเวอร์ MCP ที่ใช้ APIANT ข้อมูลประเภทต่อไปนี้อาจเกี่ยวข้องด้วย:

  • ข้อมูลประจำตัวสำหรับการตรวจสอบสิทธิ์: โทเค็น OAuth 2.0 หรือข้อมูลประจำตัวอื่นๆ ที่ใช้ในการตรวจสอบตัวตนและอนุญาตการเข้าถึงเซิร์ฟเวอร์ของผู้สร้าง
  • พารามิเตอร์การเรียกใช้เครื่องมือ: ข้อมูลป้อนเข้าเฉพาะที่จำเป็นสำหรับการดำเนินการแต่ละอย่างที่ร้องขอ (ตัวอย่างเช่น ชื่อแอปพลิเคชัน การกำหนดค่าเวิร์กโฟลว์ หรือคำค้นหา)
  • การตอบสนองการเรียกใช้เครื่องมือ: ผลลัพธ์ที่ได้รับจากเซิร์ฟเวอร์ของผู้สร้างเว็บไซต์เพื่อตอบสนองต่อคำขอต่างๆ จะถูกส่งต่อไปยังแพลตฟอร์ม AI เพื่อแสดงผลให้ผู้ใช้ปลายทางเห็น

APIANT ทำ ไม่ รับข้อความสนทนาทั้งหมดระหว่างผู้ใช้ปลายทางและแพลตฟอร์ม AI เฉพาะข้อมูลการเรียกใช้เครื่องมือที่มีโครงสร้างซึ่งจำเป็นต่อการดำเนินการเฉพาะเท่านั้นที่จะถูกประมวลผลบนเซิร์ฟเวอร์ที่ขับเคลื่อนด้วย APIANT ของผู้สร้าง

เราใช้ข้อมูล MCP อย่างไร

APIANT ในฐานะผู้ให้บริการโครงสร้างพื้นฐานของแพลตฟอร์ม ใช้ข้อมูลที่ประมวลผลผ่านเซิร์ฟเวอร์ MCP เพื่อวัตถุประสงค์ดังต่อไปนี้เท่านั้น:

  • จัดหาและดำเนินการโครงสร้างพื้นฐานของแพลตฟอร์มในนามของผู้สร้าง
  • ตรวจสอบประสิทธิภาพเซิร์ฟเวอร์ เวลาการทำงาน และอัตราข้อผิดพลาด
  • แก้ไขปัญหาและปรับปรุงความน่าเชื่อถือของโครงสร้างพื้นฐานเซิร์ฟเวอร์ MCP
  • ปฏิบัติตามข้อผูกพันทางกฎหมายที่เกี่ยวข้อง

วิธีการจัดเก็บและรักษาข้อมูล MCP ของเรา

  • โทเค็นการตรวจสอบสิทธิ์ ข้อมูลจะถูกเก็บไว้ในหน่วยความจำตลอดระยะเวลาของเซสชัน และจะไม่คงอยู่หลังจากตัดการเชื่อมต่อ
  • บันทึกการเรียกใช้เครื่องมือ (พารามิเตอร์และผลตอบสนอง) อาจถูกเก็บรักษาไว้เป็นระยะเวลาจำกัดเพื่อวัตถุประสงค์ในการแก้ไขข้อผิดพลาดและการดำเนินงาน บันทึกเหล่านี้จะถูกลบภายใน 90 วัน เว้นแต่กฎหมายจะกำหนดให้เก็บรักษาไว้นานกว่านั้น
  • ไม่มีโปรไฟล์ผู้ใช้ สร้างขึ้นจากข้อมูลการโต้ตอบของ MCP

สิ่งที่เราไม่ทำกับข้อมูล MCP

  • เราทำ ไม่ ใช้ข้อมูลการโต้ตอบของ MCP เพื่อฝึกฝนโมเดล AI หรือแมชชีนเลิร์นนิงใดๆ ก็ได้
  • เราทำ ไม่ ขายข้อมูลการโต้ตอบ MCP ให้แก่บุคคลที่สาม
  • เราทำ ไม่ ใช้ข้อมูลการโต้ตอบของ MCP เพื่อวัตถุประสงค์ในการโฆษณา การวิเคราะห์ข้อมูลส่วนบุคคล หรือการตลาด
  • เราทำ ไม่ เราจะไม่เปิดเผยข้อมูลการโต้ตอบของ MCP ให้กับบุคคลที่สาม เว้นแต่จำเป็นต่อการให้บริการ หรือตามที่กฎหมายกำหนด

4. เราอาศัยหลักการทางกฎหมายใดในการประมวลผลข้อมูลส่วนบุคคลของคุณ?

โดยสรุป: เราจะประมวลผลข้อมูลส่วนบุคคลของคุณก็ต่อเมื่อเราเชื่อว่าจำเป็นและมีเหตุผลทางกฎหมายที่ถูกต้อง (เช่น พื้นฐานทางกฎหมาย) ในการดำเนินการดังกล่าวภายใต้กฎหมายที่บังคับใช้ เช่น การได้รับความยินยอมจากคุณ เพื่อปฏิบัติตามกฎหมาย เพื่อให้บริการแก่คุณ เพื่อเข้าทำหรือปฏิบัติตามข้อผูกพันตามสัญญา เพื่อปกป้องสิทธิ์ของคุณ หรือเพื่อประโยชน์ทางธุรกิจที่ชอบด้วยกฎหมายของเรา

หากคุณอยู่ในสหภาพยุโรปหรือสหราชอาณาจักร ส่วนนี้จะเกี่ยวข้องกับคุณ

ระเบียบการคุ้มครองข้อมูลทั่วไป (GDPR) และ GDPR ของสหราชอาณาจักร กำหนดให้เราต้องอธิบายถึงหลักการทางกฎหมายที่ถูกต้องที่เราใช้ในการประมวลผลข้อมูลส่วนบุคคลของคุณ ดังนั้น เราอาจใช้หลักการทางกฎหมายต่อไปนี้ในการประมวลผลข้อมูลส่วนบุคคลของคุณ:

  • ยินยอม. เราอาจประมวลผลข้อมูลของคุณหากคุณได้ให้ความยินยอม (เช่น การอนุญาต) ในการใช้ข้อมูลส่วนบุคคลของคุณเพื่อวัตถุประสงค์เฉพาะ คุณสามารถเพิกถอนความยินยอมได้ตลอดเวลา เรียนรู้เพิ่มเติมเกี่ยวกับ การถอนความยินยอมของคุณ.
  • การปฏิบัติตามสัญญา เราอาจประมวลผลข้อมูลส่วนบุคคลของคุณเมื่อเราเชื่อว่าจำเป็นต่อการปฏิบัติตามข้อผูกพันตามสัญญาที่เรามีต่อคุณ รวมถึงการให้บริการของเรา หรือตามคำขอของคุณก่อนที่จะทำสัญญากับคุณ
  • ผลประโยชน์ที่ชอบด้วยกฎหมาย เราอาจประมวลผลข้อมูลของคุณเมื่อเราเชื่อว่ามีความจำเป็นอย่างสมเหตุสมผลเพื่อบรรลุผลประโยชน์ทางธุรกิจที่ชอบด้วยกฎหมายของเรา และผลประโยชน์เหล่านั้นไม่ได้มีน้ำหนักมากกว่าผลประโยชน์ สิทธิ และเสรีภาพขั้นพื้นฐานของคุณ ตัวอย่างเช่น เราอาจประมวลผลข้อมูลส่วนบุคคลของคุณเพื่อวัตถุประสงค์บางประการดังที่ได้อธิบายไว้ เพื่อ:
    • ส่งข้อมูลเกี่ยวกับข้อเสนอพิเศษและส่วนลดสำหรับผลิตภัณฑ์และบริการของเราให้แก่ผู้ใช้
    • พัฒนาและแสดงเนื้อหาโฆษณาที่ปรับแต่งให้เหมาะสมและตรงกับความต้องการของผู้ใช้ของเรา
    • วิเคราะห์วิธีการใช้งานบริการของเรา เพื่อที่เราจะได้ปรับปรุงบริการให้ดียิ่งขึ้น ดึงดูดและรักษาฐานผู้ใช้ไว้
    • สนับสนุนกิจกรรมทางการตลาดของเรา
    • วินิจฉัยปัญหาและ/หรือป้องกันกิจกรรมฉ้อโกง
    • ทำความเข้าใจว่าผู้ใช้ของเราใช้ผลิตภัณฑ์และบริการของเราอย่างไร เพื่อที่เราจะได้ปรับปรุงประสบการณ์การใช้งานของผู้ใช้ให้ดียิ่งขึ้น
  • ข้อผูกพันทางกฎหมาย เราอาจประมวลผลข้อมูลของคุณในกรณีที่เราเชื่อว่าจำเป็นต่อการปฏิบัติตามข้อผูกพันทางกฎหมายของเรา เช่น เพื่อให้ความร่วมมือกับหน่วยงานบังคับใช้กฎหมายหรือหน่วยงานกำกับดูแล การใช้สิทธิหรือปกป้องสิทธิทางกฎหมายของเรา หรือการเปิดเผยข้อมูลของคุณเป็นหลักฐานในการดำเนินคดีที่เรามีส่วนเกี่ยวข้อง
  • ผลประโยชน์ที่สำคัญยิ่ง เราอาจประมวลผลข้อมูลของคุณในกรณีที่เราเชื่อว่าจำเป็นเพื่อปกป้องผลประโยชน์ที่สำคัญของคุณหรือผลประโยชน์ที่สำคัญของบุคคลที่สาม เช่น สถานการณ์ที่เกี่ยวข้องกับภัยคุกคามที่อาจเกิดขึ้นต่อความปลอดภัยของบุคคลใดๆ

5. เราจะเปิดเผยข้อมูลส่วนบุคคลของคุณเมื่อใดและกับใครบ้าง?

โดยสรุป: เราอาจเปิดเผยข้อมูลในสถานการณ์เฉพาะที่ระบุไว้ในส่วนนี้ และ/หรือกับบุคคลที่สามดังต่อไปนี้

ผู้ขาย ที่ปรึกษา และผู้ให้บริการบุคคลที่สามอื่นๆ เราอาจแบ่งปันข้อมูลของคุณกับผู้ขาย ผู้ให้บริการ ผู้รับเหมา หรือตัวแทนบุคคลที่สาม ("บุคคลที่สาม") ซึ่งให้บริการแก่เราหรือในนามของเรา และจำเป็นต้องเข้าถึงข้อมูลดังกล่าวเพื่อดำเนินการนั้น เรามีสัญญาที่ทำไว้กับบุคคลที่สามของเรา ซึ่งออกแบบมาเพื่อช่วยปกป้องข้อมูลส่วนบุคคลของคุณ นั่นหมายความว่าพวกเขาไม่สามารถดำเนินการใดๆ กับข้อมูลส่วนบุคคลของคุณได้ เว้นแต่เราจะสั่งให้พวกเขาทำเช่นนั้น พวกเขาจะไม่แบ่งปันข้อมูลส่วนบุคคลของคุณกับองค์กรใดๆ นอกเหนือจากเรา นอกจากนี้ พวกเขายังให้คำมั่นที่จะปกป้องข้อมูลที่พวกเขาถือครองในนามของเรา และเก็บรักษาไว้ตามระยะเวลาที่เรากำหนด

บุคคลที่สามที่เราอาจแบ่งปันข้อมูลส่วนบุคคลด้วยมีดังต่อไปนี้:

  • บริการคลาวด์คอมพิวติ้ง: บริการเว็บอเมซอน (AWS)
  • ใบแจ้งหนี้และการเรียกเก็บเงิน: หยิก
  • การวิเคราะห์เว็บไซต์และแอปพลิเคชันบนมือถือ: Google Analytics, Smartlook
  • การโฆษณา การตลาดทางตรง และการสร้างฐานลูกค้าเป้าหมาย: เลมลิสต์, ฮับสปอต CRM
  • สื่อสารและสนทนากับผู้ใช้: อีเมล HubSpot
  • การสำรองข้อมูลและความปลอดภัย: การสำรองข้อมูล Google Drive, Amazon Glacier
  • การเพิ่มประสิทธิภาพการทำงานและโครงสร้างพื้นฐาน: Amazon Web Services, Splunk
  • การตรวจสอบประสิทธิภาพเว็บไซต์: สปลันค์ มินต์ เอ็กซ์เพรส

นอกจากนี้ เราอาจจำเป็นต้องเปิดเผยข้อมูลส่วนบุคคลของคุณในสถานการณ์ต่อไปนี้:

  • การโอนกิจการ เราอาจเปิดเผยหรือโอนข้อมูลของคุณให้แก่บริษัทอื่นในกรณีที่มีการควบรวมกิจการ การขายสินทรัพย์ของบริษัท การจัดหาเงินทุน หรือการเข้าซื้อกิจการทั้งหมดหรือบางส่วนของธุรกิจของเราให้แก่บริษัทอื่น หรือในระหว่างการเจรจาต่อรองในเรื่องดังกล่าว
  • พันธมิตรทางธุรกิจ เราอาจแบ่งปันข้อมูลของคุณกับพันธมิตรทางธุรกิจของเราเพื่อนำเสนอผลิตภัณฑ์ บริการ หรือโปรโมชั่นบางอย่างแก่คุณ
  • โครงสร้างพื้นฐานเซิร์ฟเวอร์ MCP เมื่อมีการประมวลผลข้อมูลผ่านเซิร์ฟเวอร์ MCP ที่ใช้ APIANT ของลูกค้า ข้อมูลดังกล่าวอาจถูกส่งไปและกลับจากแพลตฟอร์ม AI ของบุคคลที่สาม และแอปพลิเคชันของบุคคลที่สามใดๆ ที่ลูกค้าเชื่อมต่อผ่าน APIANT ดูรายละเอียดเพิ่มเติมได้ที่นี่ ส่วนที่ 3 สำหรับรายละเอียดเพิ่มเติม

6. เราใช้คุกกี้และเทคโนโลยีการติดตามอื่นๆ หรือไม่?

โดยสรุป: เราอาจใช้คุกกี้และเทคโนโลยีการติดตามอื่นๆ เพื่อรวบรวมและจัดเก็บข้อมูลของคุณ

เราอาจใช้คุกกี้และเทคโนโลยีการติดตามที่คล้ายกัน (เช่น เว็บบีคอนและพิกเซล) เพื่อรวบรวมข้อมูลเมื่อคุณใช้งานบริการของเรา เทคโนโลยีการติดตามออนไลน์บางอย่างช่วยให้เรารักษาความปลอดภัยของบริการและบัญชีของคุณ ป้องกันการทำงานผิดพลาด แก้ไขข้อผิดพลาด บันทึกการตั้งค่าของคุณ และช่วยในการทำงานพื้นฐานของเว็บไซต์

นอกจากนี้ เรายังอนุญาตให้บุคคลที่สามและผู้ให้บริการใช้เทคโนโลยีการติดตามออนไลน์บนบริการของเราเพื่อการวิเคราะห์และการโฆษณา รวมถึงเพื่อช่วยจัดการและแสดงโฆษณา ปรับแต่งโฆษณาให้ตรงกับความสนใจของคุณ หรือส่งการแจ้งเตือนเกี่ยวกับตะกร้าสินค้าที่ถูกทิ้งไว้ (ขึ้นอยู่กับการตั้งค่าการสื่อสารของคุณ) บุคคลที่สามและผู้ให้บริการใช้เทคโนโลยีของตนเพื่อแสดงโฆษณาเกี่ยวกับผลิตภัณฑ์และบริการที่ปรับให้เหมาะสมกับความสนใจของคุณ ซึ่งอาจปรากฏบนบริการของเราหรือบนเว็บไซต์อื่นๆ

ในกรณีที่เทคโนโลยีการติดตามออนไลน์เหล่านี้ถือเป็นการ "ขาย" / "แบ่งปัน" (ซึ่งรวมถึงการโฆษณาแบบกำหนดเป้าหมาย ตามที่กำหนดไว้ในกฎหมายที่เกี่ยวข้อง) ภายใต้กฎหมายของรัฐต่างๆ ในสหรัฐอเมริกา คุณสามารถเลือกที่จะไม่ใช้เทคโนโลยีการติดตามออนไลน์เหล่านี้ได้โดยการส่งคำขอตามที่อธิบายไว้ด้านล่างในส่วน "พลเมืองสหรัฐอเมริกามีสิทธิความเป็นส่วนตัวเฉพาะเจาะจงหรือไม่?"

ข้อมูลเฉพาะเกี่ยวกับวิธีที่เราใช้เทคโนโลยีดังกล่าว และวิธีที่คุณสามารถปฏิเสธคุกกี้บางประเภทได้นั้น ระบุไว้ในนโยบายความเป็นส่วนตัวของเรา ประกาศเกี่ยวกับคุกกี้.

7. เราจะเก็บรักษาข้อมูลของคุณไว้นานแค่ไหน?

โดยสรุป: เราจะเก็บรักษาข้อมูลของคุณไว้ตราบเท่าที่จำเป็นเพื่อให้บรรลุวัตถุประสงค์ที่ระบุไว้ในนโยบายความเป็นส่วนตัวนี้ เว้นแต่กฎหมายจะกำหนดไว้เป็นอย่างอื่น

เราจะเก็บรักษาข้อมูลส่วนบุคคลของคุณไว้ตราบเท่าที่จำเป็นสำหรับวัตถุประสงค์ที่ระบุไว้ในนโยบายความเป็นส่วนตัวนี้เท่านั้น เว้นแต่กฎหมายจะกำหนดหรืออนุญาตให้เก็บรักษาไว้นานกว่านั้น (เช่น ข้อกำหนดด้านภาษี บัญชี หรือข้อกำหนดทางกฎหมายอื่นๆ) ไม่มีวัตถุประสงค์ใดในนโยบายนี้ที่จะกำหนดให้เราเก็บรักษาข้อมูลส่วนบุคคลของคุณนานกว่าระยะเวลาที่ผู้ใช้มีบัญชีกับเรา

เมื่อเราไม่มีความจำเป็นทางธุรกิจที่ถูกต้องตามกฎหมายในการประมวลผลข้อมูลส่วนบุคคลของคุณอีกต่อไป เราจะลบหรือทำให้ข้อมูลดังกล่าวเป็นนิรนาม หรือหากไม่สามารถทำได้ (เช่น เนื่องจากข้อมูลส่วนบุคคลของคุณถูกจัดเก็บไว้ในไฟล์สำรอง) เราจะจัดเก็บข้อมูลส่วนบุคคลของคุณอย่างปลอดภัยและแยกออกจากกระบวนการประมวลผลใดๆ เพิ่มเติม จนกว่าจะสามารถลบได้

8. เราจะรักษาข้อมูลของคุณให้ปลอดภัยได้อย่างไร?

โดยสรุป: เรามุ่งมั่นที่จะปกป้องข้อมูลส่วนบุคคลของคุณผ่านระบบมาตรการรักษาความปลอดภัยทั้งด้านองค์กรและด้านเทคนิค

เราได้นำมาตรการรักษาความปลอดภัยทางเทคนิคและองค์กรที่เหมาะสมและสมเหตุสมผลมาใช้เพื่อปกป้องความปลอดภัยของข้อมูลส่วนบุคคลที่เราประมวลผล อย่างไรก็ตาม แม้ว่าเราจะมีมาตรการป้องกันและความพยายามในการรักษาความปลอดภัยข้อมูลของคุณ แต่การส่งข้อมูลทางอิเล็กทรอนิกส์ผ่านอินเทอร์เน็ตหรือเทคโนโลยีการจัดเก็บข้อมูลใดๆ ก็ไม่สามารถรับประกันได้ว่าจะปลอดภัย 100% ดังนั้นเราจึงไม่สามารถสัญญาหรือรับประกันได้ว่าแฮกเกอร์ อาชญากรไซเบอร์ หรือบุคคลที่สามที่ไม่ได้รับอนุญาตจะไม่สามารถเจาะระบบรักษาความปลอดภัยของเราและรวบรวม เข้าถึง ขโมย หรือแก้ไขข้อมูลของคุณอย่างไม่เหมาะสมได้ แม้ว่าเราจะพยายามอย่างเต็มที่เพื่อปกป้องข้อมูลส่วนบุคคลของคุณ การส่งข้อมูลส่วนบุคคลไปยังและจากบริการของเรานั้นเป็นความเสี่ยงของคุณเอง คุณควรเข้าถึงบริการภายในสภาพแวดล้อมที่ปลอดภัยเท่านั้น

การสื่อสารทั้งหมดของเซิร์ฟเวอร์ MCP จะส่งผ่านการเชื่อมต่อที่เข้ารหัส HTTPS/TLS

9. เราเก็บรวบรวมข้อมูลจากผู้เยาว์หรือไม่?

เราไม่ได้เก็บรวบรวม ขอข้อมูล หรือทำการตลาดกับเด็กที่มีอายุต่ำกว่า 18 ปีโดยเจตนา และเราไม่ได้ขายข้อมูลส่วนบุคคลดังกล่าวโดยเจตนา การใช้บริการนี้แสดงว่าคุณมีอายุอย่างน้อย 18 ปี หรือคุณเป็นผู้ปกครองของเด็กที่ยังไม่บรรลุนิติภาวะและยินยอมให้เด็กนั้นใช้บริการ หากเราทราบว่ามีการเก็บรวบรวมข้อมูลส่วนบุคคลจากผู้ใช้ที่มีอายุต่ำกว่า 18 ปี เราจะปิดใช้งานบัญชีและใช้มาตรการที่เหมาะสมเพื่อลบข้อมูลดังกล่าวออกจากบันทึกของเราโดยเร็วที่สุด หากคุณทราบว่าเราอาจเก็บรวบรวมข้อมูลใดๆ จากเด็กที่มีอายุต่ำกว่า 18 ปี โปรดติดต่อเราได้ที่ privacy@apiant.com.

10. คุณมีสิทธิ์ในความเป็นส่วนตัวอะไรบ้าง?

โดยสรุป: ขึ้นอยู่กับรัฐที่คุณอาศัยอยู่ในสหรัฐอเมริกา หรือในบางภูมิภาค เช่น เขตเศรษฐกิจยุโรป (EEA) และสหราชอาณาจักร คุณมีสิทธิ์ที่ช่วยให้คุณเข้าถึงและควบคุมข้อมูลส่วนบุคคลของคุณได้มากขึ้น คุณสามารถตรวจสอบ เปลี่ยนแปลง หรือยกเลิกบัญชีของคุณได้ตลอดเวลา ขึ้นอยู่กับประเทศ จังหวัด หรือรัฐที่คุณอาศัยอยู่

ในบางภูมิภาค (เช่น EEA และสหราชอาณาจักร) คุณมีสิทธิ์บางประการภายใต้กฎหมายคุ้มครองข้อมูลที่เกี่ยวข้อง ซึ่งอาจรวมถึงสิทธิ์ (i) ในการขอเข้าถึงและรับสำเนาข้อมูลส่วนบุคคลของคุณ (ii) ในการขอแก้ไขหรือลบข้อมูล (iii) ในการจำกัดการประมวลผลข้อมูลส่วนบุคคลของคุณ (iv) หากมีผลบังคับใช้ ในการโอนย้ายข้อมูล และ (v) ในการไม่ถูกตัดสินใจโดยอัตโนมัติ ในบางกรณี คุณอาจมีสิทธิ์คัดค้านการประมวลผลข้อมูลส่วนบุคคลของคุณ คุณสามารถยื่นคำร้องดังกล่าวได้โดยติดต่อเราโดยใช้รายละเอียดการติดต่อที่ระบุไว้ในส่วน "คุณสามารถติดต่อเราเกี่ยวกับประกาศนี้ได้อย่างไร?" ด้านล่าง.

เราจะพิจารณาและดำเนินการตามคำขอใด ๆ โดยสอดคล้องกับกฎหมายคุ้มครองข้อมูลส่วนบุคคลที่เกี่ยวข้อง

หากคุณอยู่ในเขตเศรษฐกิจยุโรป (EEA) หรือสหราชอาณาจักร และเชื่อว่าเรากำลังประมวลผลข้อมูลส่วนบุคคลของคุณโดยไม่ชอบด้วยกฎหมาย คุณยังมีสิทธิ์ร้องเรียนต่อหน่วยงานคุ้มครองข้อมูลของประเทศสมาชิกหรือหน่วยงานคุ้มครองข้อมูลของสหราชอาณาจักรได้อีกด้วย

หากคุณอยู่ในประเทศสวิตเซอร์แลนด์ คุณสามารถติดต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลและสารสนเทศแห่งสหพันธรัฐได้

การเพิกถอนความยินยอมของคุณ: หากเราอาศัยความยินยอมของคุณในการประมวลผลข้อมูลส่วนบุคคลของคุณ ซึ่งอาจเป็นความยินยอมโดยชัดแจ้งและ/หรือโดยปริยาย ขึ้นอยู่กับกฎหมายที่เกี่ยวข้อง คุณมีสิทธิ์ที่จะเพิกถอนความยินยอมของคุณได้ตลอดเวลา คุณสามารถเพิกถอนความยินยอมได้ตลอดเวลาโดยติดต่อเราโดยใช้รายละเอียดการติดต่อที่ระบุไว้ในส่วน "คุณสามารถติดต่อเราเกี่ยวกับประกาศนี้ได้อย่างไร?"ด้านล่างหรืออัปเดตการตั้งค่าของคุณ"

อย่างไรก็ตาม โปรดทราบว่าการดำเนินการนี้จะไม่ส่งผลกระทบต่อความชอบด้วยกฎหมายของการประมวลผลข้อมูลก่อนการถอนความยินยอม และในกรณีที่กฎหมายที่เกี่ยวข้องอนุญาต ก็จะไม่ส่งผลกระทบต่อการประมวลผลข้อมูลส่วนบุคคลของคุณที่ดำเนินการโดยอาศัยเหตุผลชอบด้วยกฎหมายอื่นนอกเหนือจากความยินยอม

การยกเลิกการรับข่าวสารด้านการตลาดและการส่งเสริมการขาย: คุณสามารถยกเลิกการรับข่าวสารด้านการตลาดและโปรโมชั่นจากเราได้ตลอดเวลา โดยคลิกที่ลิงก์ยกเลิกการสมัครรับข้อมูลในอีเมลที่เราส่งไป หรือติดต่อเราโดยใช้รายละเอียดที่ระบุไว้ในส่วน "คุณสามารถติดต่อเราเกี่ยวกับประกาศนี้ได้อย่างไร?"ด้านล่าง" จากนั้นคุณจะถูกลบออกจากรายชื่อผู้รับข่าวสารทางการตลาด อย่างไรก็ตาม เราอาจยังคงติดต่อคุณอยู่ เช่น เพื่อส่งข้อความที่เกี่ยวข้องกับบริการซึ่งจำเป็นสำหรับการจัดการและการใช้งานบัญชีของคุณ เพื่อตอบคำขอรับบริการ หรือเพื่อวัตถุประสงค์อื่นที่ไม่ใช่การตลาด

หากคุณต้องการตรวจสอบหรือเปลี่ยนแปลงข้อมูลในบัญชีของคุณ หรือต้องการยกเลิกบัญชีของคุณ คุณสามารถทำได้ดังนี้:

  • เข้าสู่การตั้งค่าบัญชีของคุณและอัปเดตบัญชีผู้ใช้ของคุณ

เมื่อคุณร้องขอให้ยกเลิกบัญชีของคุณ เราจะปิดใช้งานหรือลบข้อมูลบัญชีของคุณออกจากฐานข้อมูลของเรา อย่างไรก็ตาม เราอาจเก็บรักษาข้อมูลบางส่วนไว้ในไฟล์ของเราเพื่อป้องกันการฉ้อโกง แก้ไขปัญหา ช่วยเหลือในการสอบสวนใดๆ บังคับใช้ข้อกำหนดทางกฎหมายของเรา และ/หรือปฏิบัติตามข้อกำหนดทางกฎหมายที่เกี่ยวข้อง

11. การควบคุมคุณสมบัติห้ามติดตาม

เว็บเบราว์เซอร์ส่วนใหญ่ และระบบปฏิบัติการมือถือและแอปพลิเคชันมือถือบางแอป มีฟีเจอร์หรือการตั้งค่า "ห้ามติดตาม" ("DNT") ที่คุณสามารถเปิดใช้งานเพื่อแสดงความต้องการด้านความเป็นส่วนตัวของคุณว่าไม่ต้องการให้มีการตรวจสอบและรวบรวมข้อมูลเกี่ยวกับกิจกรรมการท่องเว็บออนไลน์ของคุณ ในขณะนี้ ยังไม่มีมาตรฐานเทคโนโลยีที่เป็นเอกภาพสำหรับการรับรู้และใช้งานสัญญาณ DNT ที่ได้รับการสรุปอย่างเป็นทางการ ดังนั้น เราจึงไม่ตอบสนองต่อสัญญาณ DNT จากเบราว์เซอร์หรือกลไกอื่นใดที่สื่อสารโดยอัตโนมัติถึงการเลือกของคุณที่จะไม่ถูกติดตามทางออนไลน์ หากมีการนำมาตรฐานสำหรับการติดตามออนไลน์มาใช้ที่เราต้องปฏิบัติตามในอนาคต เราจะแจ้งให้คุณทราบเกี่ยวกับแนวปฏิบัติดังกล่าวในเวอร์ชันแก้ไขของประกาศความเป็นส่วนตัวนี้

กฎหมายของรัฐแคลิฟอร์เนียกำหนดให้เราต้องแจ้งให้คุณทราบถึงวิธีการที่เราตอบสนองต่อสัญญาณ DNT จากเว็บเบราว์เซอร์ เนื่องจากในปัจจุบันยังไม่มีมาตรฐานทางอุตสาหกรรมหรือทางกฎหมายสำหรับการรับรู้หรือการปฏิบัติตามสัญญาณ DNT ดังนั้นเราจึงไม่ตอบสนองต่อสัญญาณเหล่านั้นในขณะนี้

แหล่งที่มาของข้อมูลส่วนบุคคล

เรียนรู้เพิ่มเติมเกี่ยวกับแหล่งที่มาของข้อมูลส่วนบุคคลที่เราเก็บรวบรวมได้ใน "เราเก็บรวบรวมข้อมูลอะไรบ้าง?"

วิธีการที่เราใช้และแบ่งปันข้อมูลส่วนบุคคล

เรียนรู้เพิ่มเติมเกี่ยวกับวิธีที่เราใช้ข้อมูลส่วนบุคคลของคุณได้ในส่วน "เราประมวลผลข้อมูลของคุณอย่างไร?"

เราเก็บรวบรวมและแบ่งปันข้อมูลส่วนบุคคลของคุณผ่านช่องทางต่างๆ ดังนี้:

  • คุกกี้กำหนดเป้าหมาย/คุกกี้การตลาด
  • คุกกี้โซเชียลมีเดีย
  • บีคอน/พิกเซล/แท็ก

ข้อมูลของคุณจะถูกเปิดเผยให้บุคคลอื่นทราบหรือไม่?

เราอาจเปิดเผยข้อมูลส่วนบุคคลของคุณแก่ผู้ให้บริการของเราตามสัญญาเป็นลายลักษณ์อักษรระหว่างเรากับผู้ให้บริการแต่ละราย เรียนรู้เพิ่มเติมเกี่ยวกับวิธีที่เราเปิดเผยข้อมูลส่วนบุคคลได้ในส่วน "เราเปิดเผยข้อมูลส่วนบุคคลของคุณเมื่อใดและกับใครบ้าง?"

เราอาจใช้ข้อมูลส่วนบุคคลของคุณเพื่อวัตถุประสงค์ทางธุรกิจของเราเอง เช่น การดำเนินการวิจัยภายในเพื่อการพัฒนาและสาธิตเทคโนโลยี ซึ่งไม่ถือว่าเป็นการ "ขาย" ข้อมูลส่วนบุคคลของคุณ

เราไม่ได้ขายหรือแบ่งปันข้อมูลส่วนบุคคลใดๆ ให้กับบุคคลที่สามเพื่อวัตถุประสงค์ทางธุรกิจหรือเชิงพาณิชย์ในช่วงสิบสอง (12) เดือนที่ผ่านมา

สิทธิ์ของคุณ

คุณมีสิทธิ์ภายใต้กฎหมายคุ้มครองข้อมูลของบางรัฐในสหรัฐอเมริกา อย่างไรก็ตาม สิทธิ์เหล่านี้ไม่ใช่สิทธิ์เด็ดขาด และในบางกรณี เราอาจปฏิเสธคำขอของคุณตามที่กฎหมายอนุญาต สิทธิ์เหล่านี้ได้แก่:

  • สิทธิในการทราบว่าเรากำลังประมวลผลข้อมูลส่วนบุคคลของคุณหรือไม่
  • สิทธิ์ในการเข้าถึงข้อมูลส่วนบุคคลของคุณ
  • สิทธิ์ในการแก้ไขข้อมูลส่วนบุคคลที่ไม่ถูกต้อง
  • สิทธิ์ในการขอให้ลบข้อมูลส่วนบุคคลของคุณ
  • สิทธิ์ในการขอรับสำเนาข้อมูลส่วนบุคคลที่คุณเคยเปิดเผยให้เราทราบ
  • สิทธิในการไม่ได้รับเลือกปฏิบัติในการใช้สิทธิของคุณ
  • สิทธิ์ในการปฏิเสธการประมวลผลข้อมูลส่วนบุคคลของคุณ หากข้อมูลดังกล่าวถูกนำไปใช้เพื่อการโฆษณาแบบกำหนดเป้าหมาย (หรือการแบ่งปันตามที่กำหนดไว้ในกฎหมายคุ้มครองความเป็นส่วนตัวของรัฐแคลิฟอร์เนีย) การขายข้อมูลส่วนบุคคล หรือการสร้างโปรไฟล์เพื่อสนับสนุนการตัดสินใจที่ก่อให้เกิดผลทางกฎหมายหรือผลที่มีนัยสำคัญในทำนองเดียวกัน ("การสร้างโปรไฟล์")

ขึ้นอยู่กับรัฐที่คุณอาศัยอยู่ คุณอาจมีสิทธิ์ดังต่อไปนี้:

  • สิทธิในการขอรับรายชื่อประเภทของบุคคลที่สามที่เราได้เปิดเผยข้อมูลส่วนบุคคลให้ (ตามที่กฎหมายที่เกี่ยวข้องอนุญาต รวมถึงกฎหมายคุ้มครองความเป็นส่วนตัวของรัฐแคลิฟอร์เนีย)
  • สิทธิในการจำกัดการใช้และการเปิดเผยข้อมูลส่วนบุคคลที่ละเอียดอ่อน (ตามที่กฎหมายที่เกี่ยวข้องอนุญาต รวมถึงกฎหมายคุ้มครองความเป็นส่วนตัวของรัฐแคลิฟอร์เนีย)

เมื่อได้รับคำขอของคุณ เราจำเป็นต้องตรวจสอบตัวตนของคุณเพื่อยืนยันว่าคุณเป็นบุคคลเดียวกับที่เรามีข้อมูลอยู่ในระบบของเรา เราจะใช้ข้อมูลส่วนบุคคลที่คุณให้ไว้ในคำขอเพื่อตรวจสอบตัวตนหรืออำนาจในการยื่นคำขอของคุณเท่านั้น อย่างไรก็ตาม หากเราไม่สามารถตรวจสอบตัวตนของคุณจากข้อมูลที่เรามีอยู่ เราอาจขอให้คุณให้ข้อมูลเพิ่มเติมเพื่อวัตถุประสงค์ในการตรวจสอบตัวตนของคุณ และเพื่อวัตถุประสงค์ด้านความปลอดภัยหรือการป้องกันการฉ้อโกง

หากคุณส่งคำขอผ่านตัวแทนที่ได้รับอนุญาต เราอาจจำเป็นต้องรวบรวมข้อมูลเพิ่มเติมเพื่อตรวจสอบตัวตนของคุณก่อนดำเนินการตามคำขอ และตัวแทนจะต้องมีหนังสืออนุญาตเป็นลายลักษณ์อักษรและลงนามโดยคุณเพื่อส่งคำขอในนามของคุณ
