## Current state (verified)
- Qualification popup `#contact-form` (33 English pages) collects Work-Email, Mobile,
  Company (readonly), Company-Domain (readonly), IntegrationNeeds. NO name fields.
  `contact_name` in lead_sessions is built from first/last which are currently empty.
- Lead relay `buildRelayParams` does NOT send FirstName/LastName.
- Contact Us `#contact-us-form` (17 product pages) already collects FirstName/LastName
  and connect `#stc-contact-form` likewise. submit-apiapps currently requires first OR last.
- submit-lead reads first_name/last_name optionally (for contact_name), does not require.

## Target
- Popup collects First Name + Last Name (required); handler validates; payload carries them.
- submit-lead REQUIRES first_name + last_name; maps to relay FirstName/LastName (lead URL).
- submit-apiapps REQUIRES BOTH first_name + last_name (was OR); already maps to apiapps URL.
- Downstream URLs preserved via APIANT_LEAD_WEBHOOK_URL / APIANT_APIAPPS_WEBHOOK_URL.
