Почему одно-единственное поле для продажи убивает логику дополнительных продаж

Дорогостоящие оздоровительные пакеты — это не один товарный пункт. Пакет на двенадцать недель стоимостью 6200 долларов обычно включает в себя проживание, питание, ежедневное количество занятий, пакет индивидуальных сессий и дополнительные опции (звуковая терапия, массаж, индивидуальная консультация с тренером). Каждая строка в этом счете — это возможность для дополнительных продаж, перекрестных продаж и продления договора.

Проблемы начинаются, когда ваша CRM-система видит только общую сумму заказа. Гипотетический пример: оздоровительный центр Silver Fern Wellness Retreat (иллюстративный пример) продает пакеты услуг стоимостью от 4000 до 8000 долларов в рамках двенадцатинедельных циклов. Klaviyo, не подвергаясь никаким манипуляциям, видит, что клиент заплатил 5800 долларов в прошлый вторник. Klaviyo не видит, что пакет включал три сеанса массажа и ни одного индивидуального коучинга. Таким образом, процесс после покупки либо запускает общие предложения дополнительных услуг (разочаровывая половину покупателей, которые уже приобрели предлагаемый пакет), либо не запускается вообще.

Чего не хватает стандартным инструментам

В Mindbody данные о продаже включают позиции товара, но большинство стандартных инструментов для объединения данных сворачивают продажу в одну строку еще до того, как она попадает в Klaviyo. Причина обычно кроется в моделировании данных: событие «Размещенный заказ» в Klaviyo ожидает массив товаров, и правильная интеграция данных о продаже из Mindbody в этот массив (с соответствующими артикулами, ценами и тегами категорий) — это работа, которую можно выполнить в «быстром Zap-запросе». В результате в Klaviyo отображается заказ в одну строку, без позиций товара, без отображения дополнительных товаров и без расчетов по апселлингу.

Подход APIANT

CRMConnect Mindbody to Klaviyo включает в себя Синхронизация покупок и позиций продаж Это первоклассная функция. Данные о продажах передаются из Mindbody в Klaviyo с сохранением каждой позиции в неизменном виде, поэтому профиль Klaviyo и полезная нагрузка событий сохраняют структуру в неизменном виде для сегментации и логики потока.

Единый механизм обработки данных внутри APIANT не зависит от формата. Данные о продажах Mindbody преобразуются с помощью XPath (открытый стандарт W3C) в схему событий Klaviyo без потери вложенности. Каждая позиция содержит свой артикул, цену, категорию и количество. Именно это обеспечивает возможность реализации логики дополнительных продаж.

В данном случае решающее значение имеют три функции приложения API:

  • Синхронизация покупок и позиций продаж для структурированного списка элементов.
  • В реальном времени Client Profile Sync Таким образом, профиль покупателя актуален и может быть сегментирован.
  • Отслеживание визитов Таким образом, работа с клиентами после покупки может основываться на том, начал ли клиент фактически использовать приобретенный товар.

Как выглядит синхронизация позиций в Klaviyo

Приобретенный пакет услуг для ретрита предоставляется в Клавийо в виде структурированного мероприятия. Его форма примерно такова:

{
  "event": "Placed Order",
  "customer_properties": {
    "$email": "client@example.com",
    "mindbody_client_id": "MB-44918"
  },
  "properties": {
    "OrderId": "MB-INV-71204",
    "Total": 5800.00,
    "Currency": "USD",
    "Items": [
      { "SKU": "RETREAT-12W-DLX", "Name": "12-Week Deluxe Package", "Price": 4200, "Category": "Retreat Base" },
      { "SKU": "MEAL-VEG-12W", "Name": "Vegetarian Meal Plan", "Price": 800, "Category": "Meal Plan" },
      { "SKU": "MASSAGE-CR-3", "Name": "Massage Credits x3", "Price": 450, "Category": "Add-On" },
      { "SKU": "SOUND-BATH-1", "Name": "Sound Bath Session", "Price": 350, "Category": "Add-On" }
    ]
  }
}

Теперь Klaviyo может сегментировать пользователей по таким критериям, как «приобрели 12-недельный пакет без индивидуальных консультаций», «приобрели план питания, но без дополнительных услуг» или «потратили более 5000 долларов, но не использовали ни одного кредита на массаж».

Разработка дополнительных предложений для дорогостоящих пакетов услуг.

Процесс дополнительных продаж включает три триггера, каждый из которых связан с тем, что уже было предложено. отсутствующий из списка статей расходов:

  1. Индивидуальные тренировки не оплачивались. Через три дня после начала ретрита отправьте электронное письмо с предложением ознакомительной встречи один на один со старшим коучем со скидкой. Исключите из списка рассылки тех, в чьих тарифных планах уже есть услуги коучинга.
  2. План питания приобретен, без дополнительных опций. Через семь дней отправьте электронное письмо с интересной информацией о программе звуковой терапии и массажа, а также о пакетной цене.
  3. Дополнительные услуги приобретены, но в ближайшие 14 дней нет запланированных занятий. Запустите рассылку писем для повторного вовлечения аудитории, используя тщательно подобранный график.

Каждая ветка считывает информацию из позиций, уже указанных в профиле. Никому не навязывают то, что он уже купил. Одного этого достаточно, чтобы ваши покупатели, приобретающие товары по высоким ценам, не отписывались от рассылки.

Накопление бонусов за лояльность при повторных покупках

Второй процесс выполняется на тех же данных, но в более длинном временном интервале. Используйте позиции заказа для расчета пожизненной ценности клиента по категориям:

  • При пожизненных расходах на массаж свыше 1500 долларов: приглашение в «стартовый» уровень с приоритетным бронированием.
  • Два полноценных ретрита за двенадцать месяцев: компенсировать стоимость питания на третьем ретрите.
  • Один ретрит плюс четыре дополнительных услуги: инициируйте запрос на реферальную ссылку с помощью персонализированного кода.

Математические вычисления выполняются в Klaviyo с использованием Items Массив обрабатывается при каждом событии «Размещен заказ». Интеграция просто обеспечивает точность массива.

Репрезентативный рост среднего чека при пакетах услуг стоимостью от 4 до 8 тысяч долларов.

Иллюстративные изображения, а не реальный клиент:

  • Базовый показатель количества прикрепленных писем (типовые письма после покупки): примерно от 8 до 12 процентов.
  • Доля дополнительных предложений, учитывающих отдельные позиции в описании товара, выросла до 20-28 процентов, в основном потому, что правильное предложение доходит до правильного покупателя.
  • Средний чек на одного участника ретрита: увеличение на 6–11 процентов в репрезентативных группах.
  • Уровень отписки после покупки: ниже, поскольку логика подавления предотвращает проблему «мы предлагаем вам то, что вы уже купили».

Это результат работы механизмов, а не магии. Составляющие статьи расходов позволяют осуществлять точное нацеливание. Точное нацеливание обеспечивает рост.

Выводы для строителей

  • Настаивайте на синхронизации данных по каждой позиции заказа между Mindbody и Klaviyo. Совокупная сумма заказа — это тупиковый маркетинговый подход при высоких ценах.
  • Основывайте свою логику дополнительных продаж на том, что уже есть. отсутствующий из массива items. Именно там находится следующий шаг, позволяющий совершить покупку.
  • Используйте общие расходы по категориям услуг (массаж, коучинг, питание) для определения уровней лояльности. Общий доход слишком очевиден для бизнеса, предлагающего пакетные ретритные программы.

Попробуйте это в своем уединенном месте отдыха.
