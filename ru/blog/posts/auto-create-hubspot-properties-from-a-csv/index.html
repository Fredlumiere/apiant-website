Целевые решения

Затем скопируйте и отредактируйте эту таблицу Google.

Вот оно ссылка на таблицу Google.

Добавьте столько строк, сколько хотите.

Выберите объект HubSpot, для которого вы хотите создать свойства:

  • Контакт
  • Иметь дело
  • Компания

Присвойте ему имя группы свойств.

Вы всегда можете указать свойство и выбрать «Нет», чтобы создать пользовательское свойство в HubSpot и пока игнорировать его.

Выберите отображаемое имя и имя API.

Выберите тип недвижимости из выпадающего списка:

  • Выбор даты
  • Дата и время
  • Выпадающий список
  • Многострочный текст
  • Множественный выбор
  • Числовое поле
  • Текст в одну строку
  • Флажок «Вкл/Выкл» (один флажок)
  • HubSpot native

И наконец, введите описание вашего объекта недвижимости.

После того, как вы введете все строки (по одной на каждый объект недвижимости), скачайте таблицу в формате CSV:

Установите автоматизацию шаблонов в своем аккаунте APIANT.

Вот оно связь к шаблону под названием Создание пользовательских свойств HubSpot из CSV-файла.

После установки подключите HubSpot Hub из меню.

Выберите общедоступное приложение системы и войдите в Центр управления.

Включите автоматизацию

Нажмите кнопку воспроизведения для автоматизации, так как это Форма приложения триггер на основе

Нажмите, чтобы загрузить ваш CSV-файл.

Ваши объекты недвижимости будут созданы автоматически, и будет сгенерирован отчет.

Вы можете свободно редактировать автоматизацию по своему усмотрению (например, добавлять значения в выпадающие списки и поля для множественного выбора).
