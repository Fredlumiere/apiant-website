Составление отчетов по каждому филиалу в Keap для сети из 4 бутиковых фитнес-центров.

Fred Lumiere 18 декабря 2024 г. 6 минут чтения
#Фитнес и здоровье#РазумТело#Keap#CRMConnect#Для предприятий

На практике маркетинговая команда из 3 человек в сети из 4 фитнес-центров, состоящая из нескольких человек, после учета управления рекламой, создания контента и еженедельных собраний, сокращается до 1,5 человек. Оставшееся время должно уходить на подготовку отчетов по каждому филиалу для четырех разных генеральных менеджеров, каждый из которых хочет знать, как работает его сайт на этой неделе и как это соотносится с показателями прошлого месяца.

Без надлежащих данных по каждому местоположению в Keap работа по составлению отчетов выглядит следующим образом: экспорт четырех CSV-файлов из Mindbody (по одному на каждое местоположение), открытие четырех отчетов в Keap, сопоставление данных в таблице Google Sheets, создание четырех мини-панелей мониторинга, отправка четырех электронных писем, повторение на следующей неделе. Каждый цикл отнимает от 4 до 6 часов рабочего времени маркетолога. За год это составляет от 200 до 300 часов чистого времени на составление отчетов без каких-либо результатов в творческой работе.

Гипотетический пример: Сеть фитнес-центров Ember Athletic (иллюстративный пример), состоящая из 4 филиалов и насчитывающая 2100 членов, с центральной маркетинговой командой из 3 человек, столкнулась именно с такой ситуацией. Маркетологи выгорали. Генеральные менеджеры жаловались, что данные по их филиалам кажутся второстепенными. Владелец постоянно слышал: «Нам нужен специалист по бизнес-аналитике», но сопротивлялся, потому что это зарплата в 90 000 долларов.

Правильный ответ — не специалист по бизнес-аналитике. Правильный ответ — это правильная интеграция данных уровня сайта в Keap, чтобы создание отчетов стало проблемой сохранения результатов поиска, а не проблемой ручного экспорта.

Отметка контактов сайтом Mindbody в Keap

CRMConnect Mindbody to Keap поддерживает Синхронизация данных из нескольких филиалов Mindbody в единую учетную запись Keap.В разделе часто задаваемых вопросов на странице приложения четко указано: «Можно ли синхронизировать несколько местоположений с одной учетной записью Keap? Да, вы можете легко управлять несколькими местоположениями Mindbody в одной учетной записи Keap».

В Keap идентификация сайта осуществляется посредством сочетания следующих элементов:

  • A primary_location поле у каждого контакта (их домашний сайт)
  • A locations_visited Поле с несколькими значениями, содержащее список всех сайтов, которые они посетили или на которых совершили покупку.
  • Теги, специфичные для сайта (site-ember-downtown, site-ember-eastside, site-ember-north, site-ember-westgate)
  • Все стандартные поля Mindbody (последнее посещение, последняя покупка и т. д.), содержащие контекст сайта.

Функция маркировки приобретенных услуг также кодирует место покупки в метке, поэтому, если комплект материалов для занятий куплен в Eastside, он будет иметь соответствующую маркировку. purchased-10pack-eastside Действует маркировка, если вы приобрели тот же набор в магазине Downtown. purchased-10pack-downtownЭто основа для формирования отчетов по каждому местоположению в Keap без дублирования контактов.

У участника, который присоединился к группе в центре города и начал посещать Истсайд три месяца спустя, есть один контакт в Keap, который выглядит следующим образом:

{
  "email": "member@example.com",
  "firstname": "Andre",
  "primary_location": "Ember Downtown",
  "locations_visited": ["Ember Downtown", "Ember Eastside"],
  "tags": [
    "site-ember-downtown",
    "site-ember-eastside",
    "purchased-unlimited-downtown",
    "year-1-member"
  ],
  "last_visit_location": "Ember Eastside",
  "last_visit_date": "2026-05-15",
  "last_visit_service": "Strength Class",
  "last_visit_staff": "Yusra",
  "membership_status": "Active"
}

Создание конвейеров обработки данных для каждого местоположения без дублирования записей.

Возникает соблазн создать для каждого филиала отдельный аккаунт Keap. Не делайте этого. Вы потеряете возможность просмотра данных о членах разных филиалов (а это одна из немногих функций Keap, которая действительно хороша), вам придётся платить в 4 раза больше за лицензирование, и вам придётся вручную сверять данные о членстве в разных филиалах.

Правильный подход — это один аккаунт Keap с сохраненными поисковыми запросами, помеченными местоположением, и последовательностями кампаний для каждого местоположения.

Просмотр данных об участниках, прекративших членство, по каждому местоположению: фильтр tags contains site-ember-eastside AND last_visit_date crossed 14 days AND membership_status = ActiveЭто список пользователей Eastside GM, доступный только её участникам. Каждому GM присваивается своя собственная закладка.

Приветствие новых участников в каждом филиале: Четыре версии одной и той же последовательности кампаний, каждая из которых ограничена тегом сайта. Приветствие в центре города содержит информацию об инструкторах и расписании занятий, специфичных для этого района. Приветствие в восточной части города содержит подробную информацию о восточной части города. Та же схема автоматизации, контент с учетом местоположения.

Отчеты по удержанию клиентов по каждому филиалу: Сохраняйте сохраненные поисковые запросы, сгруппированные по primary_locationОтфильтровано по пороговым значениям статуса членства. Маркетинговая команда создает их один раз, и они обновляются автоматически.

Для стратегических кампаний, охватывающих несколько регионов, locations_visited Многозначное поле — это объединение. Для рассылки рекламной кампании «Попробуйте наше новое заведение в Истсайде», предназначенной только для членов сообщества, проживающих в центре города, но никогда не посещавших Истсайд, используется один фильтр для определения: primary_location = Ember Downtown AND locations_visited does not contain Ember Eastside.

Выявление низкой производительности на уровне объекта на ранней стадии

Вопрос удержания клиентов, волнующий каждого владельца сети из нескольких филиалов: «Отток клиентов из одного из моих филиалов происходит быстрее, чем из других?» Без маркировки каждого филиала ответ на этот вопрос занимает неделю, и обычно это происходит слишком поздно.

Сохраненные поисковые запросы Keap, основанные на тегах сайта, позволяют получить ответ примерно за 90 секунд: подсчитать количество контактов с помощью tags contains site-ember-westgate AND last_visit_date crossed 21 days AND membership_status = Activeразделить на общую сумму site-ember-westgate Если у вас есть активные участники, то вы можете оценить темпы снижения посещаемости на всех четырех сайтах. Сравните показатели на Westgate: 12% ежемесячного снижения, а на остальных трех — от 6 до 7%, то вам следует заняться проблемой уже в этом месяце, а не через три месяца.

Двусторонняя синхронизация профилей клиентов (с передачей изменений из Keap в Mindbody каждые 15 минут) позволяет маркетинговой команде исправлять ошибки в тегах сайта, не нарушая работу Mindbody. Если основное местоположение пользователя было указано неправильно, исправление в Keap автоматически отобразится в Mindbody при следующей синхронизации.

Сэкономленное время благодаря участию 2100 человек.

В типичной ситуации внедрения в сетях такого масштаба объем работы по составлению отчетов по каждому подразделению обычно сокращается с 4–6 часов в неделю на одного маркетолога до менее чем 30 минут (в основном это время уходит на просмотр сохраненных поисковых запросов и написание комментариев для генерального менеджера). Для маркетинговой команды Ember из 3 человек это примерно 12–16 часов в неделю, или 600–800 часов в год, что составляет примерно треть от полной штатной численности персонала.

Качественный успех имеет большее значение. Генеральные менеджеры перестают чувствовать себя второстепенными, потому что их данные автоматически и своевременно поступают в их почтовый ящик. Маркетинг перестает быть узким местом для обсуждений на уровне подразделений. Разговор на еженедельном совещании руководства смещается с «маркетинг еще не отправил отчеты» на «темп отката Westgate увеличился, давайте обсудим это».

В частности, в случае с Ember, после того как были сняты все заботы по отчетности, маркетинговая команда смогла запускать по два новых тестовых рекламных ролика в месяц, причем оба теста откладывались на предыдущие шесть месяцев. Результаты этих тестов покрыли затраты на интеграцию в первом квартале.

Эти цифры носят иллюстративный характер; объем работы по составлению отчетов по каждому подразделению в значительной степени зависит от того, как часто генеральные менеджеры фактически используют запрашиваемые ими отчеты.

Выводы для строителей

  • Что скопировать: Используйте одну учетную запись Keap с привязкой к местоположению. Не разделяйте учетные записи на несколько учетных записей Keap, если у вас нет веской юридической причины (действительно независимое владение франшизой без пункта о совместном использовании данных).
  • На что обратить внимание: Использование тегов для сайтов работает только в том случае, если названия сайтов в Mindbody согласованы и понятны. Перед запуском проверьте названия ваших сайтов в Mindbody; «Downtown», «Ember Downtown» и «downtown-1» — три разных идентификатора сайта в Mindbody — приведут к появлению трех разных тегов в Keap, означающих одно и то же. Кроме того, синхронизация Mindbody и Keap для встреч и продаж осуществляется в одностороннем порядке; двусторонняя синхронизация происходит только для профилей клиентов (мгновенно из Mindbody в Keap, каждые 15 минут из Keap в Mindbody).
  • Когда этот шаблон не подходит: В сетях, где каждое подразделение предлагает принципиально разные услуги или цены (например, сеть фитнес-студий, которая также владеет медицинским спа-салоном под управлением той же материнской компании), вероятно, потребуются отдельные экземпляры Keap, поскольку логика кампаний в любом случае не будет переносимой между подразделениями.
