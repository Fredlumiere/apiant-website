Автоматизированные пользовательские поля Keap от Mindbody: сокращение времени настройки с дней до минут.

Fred Lumiere 10 февраля 2025 г. 6 минут чтения
#Фитнес и здоровье#РазумТело#Keap#CRMConnect#Движок обработки данных

Спросите любого персонального тренера, который за последние два года сменил CRM-систему, как прошел первый месяц. Он расскажет вам о таблицах, импорте данных и медленной, изнурительной работе по ручному созданию каждого пользовательского поля Mindbody в Keap.

В студии персональных тренировок каждый тренер отслеживает от 8 до 15 индивидуальных показателей для каждого клиента: цели, состав тела, история травм, предпочтения в тренировках, диетические ограничения, даты достижения целей, предпочтения в отношении оборудования дома, ограничения по расписанию. В Mindbody эти данные хранятся в виде индексов клиентов или пользовательских полей. В Keap по умолчанию таких полей нет. Вам нужно создавать каждое поле по отдельности, определять его тип, писать метку, а затем писать логику сопоставления, которая будет заполнять его данными из Mindbody.

Добросовестный тренер может создать, возможно, 4 пользовательских поля в час, учитывая создание полей, сопоставление данных с Mindbody и импорт результатов тестов. Умножьте это на 15 полей, умножьте на количество тренеров, желающих видеть разные варианты отображения, и одна только работа по настройке займет несколько дней. Большинство студий сдаются на полпути и в итоге получают наполовину заполненную базу данных Keap, которой никто не доверяет.

Гипотетический пример: Granite Bay Personal Training (иллюстративный пример), студия с одним офисом, 5 тренерами и 140 клиентами, дважды попыталась сделать это вручную. Обе попытки провалились на этапе создания полей. Тренеры буквально две недели тратили свои обеденные перерывы на создание пользовательских полей Keap, им это не понравилось, и они вернулись к использованию Mindbody для всего, а также к дополнительной электронной таблице для отслеживания целей.

Какие поля создает CRMConnect в первый же день?

CRMConnect Mindbody to Keap поставляется с автоматическое создание пользовательских полейНа странице приложения указано: «CRMConnect автоматически создает необходимые поля данных Mindbody в Keap во время настройки, обеспечивая точное отслеживание данных о клиентах с первого дня, без необходимости ручной настройки».

С первого дня интеграция создает в Keap все необходимые компоненты для велнес-бизнеса:

  • Поля профиля: mindbody_client_id, pricing_option_name, membership_status, total_visits, last_visit_date, last_visit_service, last_visit_staff, next_scheduled_appointment
  • Поля для информации о членстве и договорах: membership_expiration_date, remaining_sessions, contract_id, auto_pay_status
  • Поля для покупки и ввода: intro_offer_purchased, intro_offer_purchase_date, last_purchase_item, last_purchase_amount, last_purchase_date
  • Поля взаимодействия: first_visit_date, total_visits, lifetime_revenue

Помимо стандартного набора, CRMConnect отображает Индексы клиентов Mindbody и пользовательские поля клиентов в соответствующие пользовательские поля Keap автоматически. Таким образом, студия персональных тренировок, которая использует пользовательское поле Mindbody уже некоторое время... client_goals (Структурированный набор: снижение веса, подвижность, сила, специфичный для вида спорта, после травмы) позволяет получить именно это поле в Keap без необходимости ручного ввода значений в выпадающий список Keap.

В первый день работы тренера его клиентская база выглядит следующим образом:

{
  "email": "client@example.com",
  "firstname": "Riya",
  "mindbody_client_id": "MBO-2025-00451",
  "primary_trainer": "Sam",
  "client_goals": ["strength", "post-injury"],
  "injury_notes": "Right shoulder, post-surgical 2024",
  "preferred_session_day": "Tuesday/Thursday morning",
  "pricing_option_name": "12-Pack Personal Training",
  "remaining_sessions": 9,

  "last_visit_date": "2026-05-14",
  "last_visit_staff": "Sam",
  "next_scheduled_appointment": "2026-05-19T07:00:00"
}

Как синхронизация данных о продажах сохраняет полезность полей с течением времени

Первый день — это легко. Сложности начнутся через 12 месяцев, когда клиенты будут покупать новые пакеты услуг, достигать определенных этапов, менять цели и обновлять свои предпочтения. Статическое поле бесполезно; постоянно обновляемое поле способствует автоматизации.

Синхронизация данных о продажах в CRMConnect происходит мгновенно. Профили, встречи и продажи синхронизируются в течение нескольких минут (синхронизация Mindbody с Keap происходит мгновенно; синхронизация Keap с Mindbody выполняется каждые 15 минут). Теги приобретенных услуг поддерживают актуальные теги Keap по мере совершения покупок: «Автоматически управляйте тегами Keap на основе покупок клиентов, что позволяет проводить точную сегментацию для кампаний по увеличению продаж, напоминаний о продлении и персонализированной коммуникации».

Таким образом, клиент, купивший новую упаковку из 12 штук, запускает автоматические обновления. pricing_option_name, remaining_sessions, last_purchase_item, last_purchase_amount и last_purchase_dateплюс соответствующая бирка для покупки (purchased-12pack-pt-2026q2 или аналогичные). Любая автоматизация Keap, построенная на основе этих полей, видит изменения в течение нескольких секунд. Запускаются кампании по продлению подписки. Запускаются поздравления с достижением этапов. Запускаются уведомления о задачах для тренеров.

Пользовательские поля остаются полезными, потому что они актуальны, а не потому, что кто-то обновляет их вручную.

Создание пользовательских интерфейсов для тренеров без написания кода.

Благодаря наличию необходимых полей каждый тренер может создавать собственные представления сохраненных поисковых запросов Keap без необходимости написания пользовательского кода.

Мнение Сэма: фильтр для primary_trainer = Sam AND membership_status = Active. Сортировать по next_scheduled_appointmentЭто ежедневный рабочий список Сэма. Новые клиенты появляются автоматически. Старые клиенты исчезают по истечении срока действия их членства.

Вид обновления упаковки: фильтр для remaining_sessions <= 3 AND membership_status = Activeсгруппировано по primary_trainerКаждый тренер видит свой собственный поток продления контрактов.

Обзор этапов: фильтр для total_visits >= 100 AND milestone_100_celebrated is empty. Обеспечивает автоматическую отправку поздравлений по достижении определенных этапов и подарочных карт (ритуал удержания клиентов в студии).

Обзор ситуации с травмами: фильтр для injury_notes is known AND last_visit_date in last 7 daysЭто позволяет главному тренеру выявлять клиентов с активными травмами, которые недавно тренировались, для последующих бесед с целью проверки техники выполнения упражнений.

Ничего из этого не требует написания собственного кода. Ничего из этого не требует от тренеров ведения электронных таблиц. Поля заполняются сами собой; представления обновляются сами собой.

Сокращённая продолжительность настройки системы для 140 клиентов.

В типичном случае внедрения в студиях такого масштаба ручная настройка, обычно требуемая при самостоятельном подходе (от 4 до 6 часов на одного тренера, умноженных на 5 тренеров, плюс от 8 до 12 часов работы по созданию административных полей), сокращается примерно до часа настройки с помощью предварительно созданного набора полей CRMConnect. Это примерно 30-40 часов времени тренера и администратора, которые можно сразу же сэкономить на настройке.

Помимо первоначальной настройки, экономия времени достигается за счет того, что студии не нужно добавлять новые поля задним числом при внедрении новой программы. В Mindbody запускается новый мастер-класс «Мобильность по понедельникам»; данные о посещении мастер-класса автоматически поступают в Keap в виде тега покупки, без необходимости вмешательства в менеджер полей Keap.

Для Granite Bay качественным преимуществом стало то, что тренеры впервые смогли использовать Keap. После двух неудачных попыток ручной настройки, третья попытка с автоматизированными полями увенчалась успехом, поскольку тренерам не пришлось выполнять никакой работы по настройке самостоятельно. Клиенты, которых они отслеживали в дополнительных таблицах, получили доступ к системе с сохраненными целями и записями о травмах, потому что Mindbody заполнил эти поля, а CRMConnect автоматически их сопоставил.

Эти цифры носят иллюстративный характер; экономия времени на настройку во многом зависит от количества заполненных вами пользовательских полей Mindbody и от того, насколько систематизировано именование существующих полей.

Выводы для строителей

  • Что скопировать: Полагайтесь на автоматическое создание полей, а не пытайтесь проявить смекалку. Возникает соблазн разработать «лучшие» поля Keap, чем те, что есть в Mindbody. Не поддавайтесь искушению; пусть готовый набор полей интеграции поможет вам в течение первых 60 дней, а затем добавляйте поля только там, где они необходимы для конкретной автоматизации.
  • На что обратить внимание: Автоматическое создание полей обрабатывает стандартные данные о здоровье; действительно пользовательские индексы Mindbody по-прежнему необходимо сопоставлять на этапе настройки CRMConnect. Кроме того, синхронизация Mindbody с Keap для записей о встречах и продажах осуществляется в одностороннем порядке; двусторонняя синхронизация происходит только для профилей клиентов. Не пытайтесь вносить изменения в поля Mindbody из Keap.
  • Когда этот шаблон не подходит: Очень маленькие студии с минимальным объемом данных о клиентах (например, только клиенты, приходящие без записи, без отслеживания целей) получают меньше пользы от обширного набора данных; стандартного подмножества вполне достаточно. И наоборот, студиям с крайне специфическими моделями данных Mindbody может потребоваться консультация для правильного сопоставления их нестандартных индексов.
