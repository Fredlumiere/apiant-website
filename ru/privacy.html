3. Серверная инфраструктура MCP

Вкратце: APIANT предоставляет серверную инфраструктуру MCP (Model Context Protocol), которую наши клиенты развертывают на своих собственных выделенных серверах и доменах. Когда ваши данные обрабатываются через сервер MCP, работающий на базе APIANT, мы обрабатываем только те данные, которые необходимы для выполнения запрошенных действий. Мы не используем данные о взаимодействии с MCP для обучения моделей ИИ, показа рекламы или создания профилей пользователей.

Как работают серверы APIANT MCP

APIANT позволяет своим клиентам («разработчикам») развертывать MCP-совместимые серверы на собственной выделенной инфраструктуре и в собственных доменах. Эти MCP-серверы позволяют конечным пользователям разработчика взаимодействовать с интеграциями и автоматизацией разработчика через платформы искусственного интеллекта (такие как Claude от Anthropic) с использованием естественного языка. Когда конечный пользователь подключается к MCP-серверу разработчика, платформа ИИ отправляет запросы на вызов инструментов на сервер разработчика, работающий на базе APIANT. APIANT предоставляет базовую инфраструктуру платформы; конечные пользователи подключаются к серверу разработчика, а не напрямую к APIANT.

Какие данные обрабатываются через серверы MCP?

При обработке данных на сервере MCP, работающем на базе APIANT, могут быть задействованы следующие категории данных:

  • Учетные данные для аутентификации: Токены OAuth 2.0 или другие учетные данные, используемые для проверки личности и авторизации доступа к серверу разработчика.
  • Параметры вызова инструмента: Конкретные входные данные, необходимые для выполнения каждого запрошенного действия (например, названия приложений, конфигурации рабочих процессов или поисковые запросы).
  • Ответы на запросы инструментов: Результаты, возвращаемые сервером застройщика в ответ на запросы, передаются обратно на платформу искусственного интеллекта для отображения конечному пользователю.

APIANT делает нет Получает полный текст диалогов между конечными пользователями и платформами ИИ. На сервере разработчика, работающем на базе APIANT, обрабатываются только структурированные данные о вызовах инструментов, необходимые для выполнения конкретных действий.

Как мы используем данные MCP

Компания APIANT, как поставщик платформенной инфраструктуры, использует данные, обрабатываемые через серверы MCP, исключительно для следующих целей:

  • Предоставление и эксплуатация инфраструктуры платформы от имени застройщика.
  • Отслеживайте производительность серверов, время их бесперебойной работы и частоту ошибок.
  • Устранение неполадок и повышение надежности серверной инфраструктуры MCP.
  • Соблюдайте действующие правовые обязательства.

Большинство веб-браузеров, а также некоторые мобильные операционные системы и мобильные приложения включают функцию или настройку «Не отслеживать» («DNT»), которую вы можете активировать, чтобы сообщить о своем предпочтении в отношении конфиденциальности и не допускать мониторинга и сбора данных о вашей активности в интернете.
