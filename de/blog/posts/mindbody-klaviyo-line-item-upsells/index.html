Synchronisierung von Einzelpostenkäufen von Mindbody zu Klaviyo für hochpreisige Upselling-Angebote

Warum ein einzelnes Verkaufsfeld die Upselling-Logik zunichtemacht

Hochwertige Wellness-Pakete sind keine Einheitsware. Ein zwölfwöchiges Retreat-Paket für 6.200 US-Dollar beinhaltet üblicherweise eine Unterkunft, Verpflegung, ein tägliches Kontingent an Kursen, ein Paket mit privaten Sitzungen und optionale Zusatzleistungen (z. B. Klangbad, Massagegutscheine, Einzelcoaching). Jede Position auf der Rechnung bietet die Möglichkeit für Zusatzverkäufe, Cross-Selling und Vertragsverlängerungen.

Das Problem beginnt, wenn Ihr CRM nur den Gesamtbetrag der Bestellung sieht. Beispiel: Silver Fern Wellness Retreat (beispielhaft) bietet Pakete zwischen 4.000 und 8.000 US-Dollar in zwölfwöchigen Kursen an. Klaviyo, das nicht in die Transaktion eingebunden ist, sieht, dass ein Kunde letzten Dienstag 5.800 US-Dollar bezahlt hat. Klaviyo sieht jedoch nicht, dass das Paket drei Massagegutscheine und keine Einzelcoaching-Sitzungen beinhaltet. Daher werden nach dem Kauf entweder generische Zusatzangebote ausgelöst (was die Hälfte der Käufer verärgert, die das angebotene Produkt bereits gekauft haben) oder es werden gar keine Zusatzangebote angezeigt.

Was Standardwerkzeuge übersehen

Mindbody verarbeitet Verkaufsdaten mit Positionen, doch die meisten gängigen Tools reduzieren diese Daten auf eine einzige Zeile, bevor sie Klaviyo erreichen. Der Grund dafür liegt meist in der Datenmodellierung: Das Klaviyo-Ereignis „Bestellung aufgegeben“ erwartet ein Artikel-Array. Die korrekte Integration der verschachtelten Verkaufsdaten von Mindbody in dieses Array (mit korrekten SKUs, Preisen und Kategorien) wird oft bei einem „schnellen Zap“ vernachlässigt. Das Ergebnis ist eine einzeilige Bestellung in Klaviyo ohne Positionen, ohne Anzeige von Zusatzprodukten und ohne Upselling-Berechnungen.

Der APIANT-Ansatz

CRMConnect Mindbody zu Klaviyo beinhaltet Synchronisierung von Einkaufs- und Verkaufspositionen Als erstklassiges Feature fließen die Verkaufsdaten von Mindbody mit jeder einzelnen Position in Klaviyo, sodass das Klaviyo-Profil und die Ereignisnutzlast die Struktur für Segmentierung und Ablauflogik beibehalten.

Die in APIANT integrierte, einheitliche Datenverarbeitungs-Engine ist formatunabhängig. Die Verkaufsdaten von Mindbody werden mittels XPath (einem offenen W3C-Standard) in das Ereignisschema von Klaviyo abgebildet, ohne dass Verschachtelungen verloren gehen. Jeder Artikel hat seine eigene Artikelnummer (SKU), seinen Preis, seine Kategorie und seine Menge. Dadurch wird die Upselling-Logik ermöglicht.

Drei Funktionen der API-App sind hier ausschlaggebend:

  • Synchronisierung von Einkaufs- und Verkaufspositionen für die strukturierte Artikelliste.
  • Client-Profil-Synchronisation in Echtzeit Das Käuferprofil ist somit aktuell und segmentierbar.
  • Tracking besuchen Die Nachbetreuung nach dem Kauf kann also davon abhängen, ob der Kunde das Gekaufte tatsächlich schon benutzt hat.

So sieht die Zeilen- und Artikelsynchronisierung in Klaviyo aus

Ein gebuchtes Retreat-Paket landet in Klaviyo als strukturierte Veranstaltung. Der Ablauf ist in etwa wie folgt:

{
  "event": "Placed Order",
  "customer_properties": {
    "$email": "client@example.com",
    "mindbody_client_id": "MB-44918"
  },
  "properties": {
    "OrderId": "MB-INV-71204",
    "Total": 5800.00,
    "Currency": "USD",
    "Items": [
      { "SKU": "RETREAT-12W-DLX", "Name": "12-Week Deluxe Package", "Price": 4200, "Category": "Retreat Base" },
      { "SKU": "MEAL-VEG-12W", "Name": "Vegetarian Meal Plan", "Price": 800, "Category": "Meal Plan" },
      { "SKU": "MASSAGE-CR-3", "Name": "Massage Credits x3", "Price": 450, "Category": "Add-On" },
      { "SKU": "SOUND-BATH-1", "Name": "Sound Bath Session", "Price": 350, "Category": "Add-On" }
    ]
  }
}

Klaviyo kann nun segmentieren nach „12-Wochen-Paket ohne privates Coaching gekauft“, oder „Ernährungsplan gekauft, aber keine Zusatzleistungen“, oder „über 5.000 Dollar ausgegeben, aber keine Massageguthaben genutzt“.

Entwicklung von Zusatzangeboten für hochpreisige Pakete

Der Upselling-Prozess hat drei Auslöser, die jeweils damit verknüpft sind, was fehlen aus den Einzelposten:

  1. Es wurde kein privates Coaching in Anspruch genommen. Am dritten Tag des Retreats senden Sie eine E-Mail mit dem Angebot eines vergünstigten 1:1-Einführungsgesprächs mit einem erfahrenen Coach. Ignorieren Sie alle E-Mails, deren Buchungsübersicht bereits ein Coaching-Angebot enthält.
  2. Verpflegungspaket gekauft, keine Zusatzleistungen. Nach sieben Tagen senden Sie eine E-Mail mit dem Betreff „Wussten Sie schon?“, in der Sie auf die Gutscheine für Klangbad und Massage sowie den Paketpreis hinweisen.
  3. Zusatzleistungen wurden gekauft, aber es ist in den nächsten 14 Tagen kein Kurs gebucht. Lösen Sie eine Reaktivierungs-E-Mail mit einem abgestimmten Zeitplan aus.

Jede Filiale liest die bereits im Profil vorhandenen Artikel aus. Niemandem wird etwas zusätzlich angeboten, was er bereits gekauft hat. Allein das reicht aus, um Ihre zahlungskräftigen Kunden vom Abmelden abzuhalten.

Kombination von Treueprämien bei wiederholten Einkäufen

Der zweite Ablauf verarbeitet dieselben Daten, jedoch über einen längeren Zeitraum. Verwenden Sie die einzelnen Positionen, um den Kundenwert nach Kategorie zu berechnen:

  • Bei einem lebenslangen Massage-Ausgabenvolumen von über 1.500 US-Dollar: Einladung in den „Gründer“-Status mit bevorzugter Buchung.
  • Zwei vollständige Retreats innerhalb von zwölf Monaten: Die Verpflegung beim dritten Retreat ist inklusive.
  • Ein Retreat plus vier Zusatzleistungen: Führe eine Empfehlungsanfrage mit einem personalisierten Code aus.

Die mathematischen Berechnungen werden in Klaviyo unter Verwendung der folgenden Methode ausgeführt: Items Bei jedem „Bestellung aufgegeben“-Ereignis wird ein Array erstellt. Die Integration sorgt dafür, dass das Array korrekt bleibt.

Repräsentativer durchschnittlicher Verkaufswert (AOV) bei Paketen zwischen 4.000 und 8.000 US

Illustrative Collagen, kein echter Kunde:

  • Basisrate für das Hinzufügen von Zusatzinhalten (generische E-Mail nach dem Kauf): etwa 8 bis 12 Prozent.
  • Die Quote der Zusatzverkäufe bei positionsbezogenen Upselling-Angeboten stieg auf 20 bis 28 Prozent, vor allem weil das richtige Angebot den richtigen Käufer erreicht.
  • Durchschnittlicher Bestellwert pro Retreat-Teilnehmer: eine Steigerung von 6 bis 11 Prozent bei repräsentativen Kohorten.
  • Die Abmelderate nach dem Kauf ist niedriger, da die Unterdrückungslogik das Problem „Wir versuchen, Ihnen etwas zu verkaufen, was Sie bereits gekauft haben“ verhindert.

Das sind Mechanismen, keine Zauberei. Die einzelnen Positionen ermöglichen eine präzise Zielgruppenansprache. Präzise Zielgruppenansprache steigert den Umsatz.

Fazit für Bauherren

  • Bestehen Sie auf einer Synchronisierung der einzelnen Positionen zwischen Mindbody und Klaviyo. Die aggregierte Bestellsumme ist bei hohen Preisen eine Sackgasse im Marketing.
  • Bauen Sie Ihre Upselling-Logik auf dem auf, was abwesend aus dem Artikel-Array. Dort befindet sich der nächste kaufbare Schritt.
  • Nutzen Sie die Gesamtausgaben in den einzelnen Kategorien (Massage, Coaching, Mahlzeiten) für die Treuestufen. Der Gesamtumsatz ist für ein Unternehmen, das Pauschalreisen anbietet, zu ungenau.
