Konto-Netzwerke

Ein Master. Hunderte von Kinderkonten.

Ein Hauptkonto mit 228 Unterkonten, die jeweils einen Standort repräsentieren. Neue Standorte werden dem Netzwerk hinzugefügt und erben sofort die gemeinsamen Verbindungen und Einstellungen. Auf diese Weise verwaltet The Exercise Coach die MindBody-Integrationen im gesamten Franchise-Unternehmen - von einer einzigen Steuerungsebene aus.

Skalieren ohne Komplexität

Jedes untergeordnete Konto arbeitet unabhängig mit einer eigenen Quellsystemverbindung (z. B. einer eigenen MindBody-Website), nutzt aber zentral verwaltete Ressourcen wie CRM-Verbindungen und Automatisierungscodebasen gemeinsam.

Wenn ein Franchise-Unternehmen fünf neue Standorte hinzufügt, werden diese Standorte dem Kontonetzwerk hinzugefügt und übernehmen sofort die gemeinsamen Verbindungen, Einstellungen und Automatisierungen. Keine manuelle Einrichtung pro Standort.
  Konto-Netzwerk
Gemeinsame Nutzung von Verbindungen

Eine Verbindung. Jeder Standort.

Die Option "Freigabe mit untergeordnetem Konto" bedeutet eine gemeinsame CRM-Verbindung für alle Standorte. Sie benötigen keine 228 separaten CRM-Anmeldedaten. Jedes untergeordnete Konto hat seine eigene Quellsystemverbindung (z. B. seine eigene MindBody-Site), teilt aber das CRM.

Geteilt, wo es darauf ankommt. Isoliert, wo es sein muss.

Einige Verbindungen müssen gemeinsam genutzt werden - Ihr CRM, Ihre Überwachungstools, Ihre Benachrichtigungssysteme. Andere müssen isoliert werden - die Anmeldedaten für das Quellsystem eines jeden Standorts bleiben dem jeweiligen untergeordneten Konto vorbehalten.

Über die Verwaltungskonsole können Sie festlegen, was freigegeben wird und was nicht. Kein Code. Keine Konfigurationsdateien. Nur ein Schalter.

Ratenbegrenzung

Ratenbegrenzung auf Plattformebene. Kein Code erforderlich.

Legen Sie "185 API-Aufrufe pro 10 Sekunden" direkt in der Verwaltungskonsole fest. Die Plattform erzwingt dies automatisch für alle 228 Standorte - kein Code, keine externen Tools zur Ratenbegrenzung, keine Konfiguration pro Standort.

Einmal konfiguriert. Überall durchgesetzt.

Ratenbegrenzungen werden pro Verbindung auf der Plattformebene konfiguriert. Jede Automatisierung, über jedes Konto im Netzwerk, respektiert die Grenze automatisch. Wenn ein API-Partner Ihnen sagt "185 Anrufe pro 10 Sekunden", geben Sie diese Zahl einmal ein und die Plattform erledigt den Rest.

Die Plattform stellt die Anfragen in eine Warteschlange, verteilt sie gleichmäßig über das Zeitfenster und zieht sich bei Erreichen von Grenzwerten zurück. Keine 429-Fehler, die Ihre Kunden erreichen. Kein benutzerdefinierter Drosselungscode in Ihren Automatisierungen.

Weiterleitung

Master-Konto-Routing

Wenn Daten aus dem CRM-System kommen und an das richtige Quellsystem zurückgegeben werden müssen, sendet das Hauptkonto an das richtige untergeordnete Konto. Die Plattform handhabt das Routing automatisch - keine manuelle Zuordnung, keine Nachschlagetabellen, kein Raten, zu welchem Ort ein Datensatz gehört.

"Ein Kontakt-Update kommt in HubSpot an. Das Master-Konto empfängt den Webhook, identifiziert anhand des Standortfelds, zu welcher MindBody-Site der Kontakt gehört, und leitet das Update an das richtige Unterkonto weiter. Das Unterkonto verarbeitet es mit seiner eigenen Automatisierung und seinen eigenen MindBody-Zugangsdaten. Der Kontakt erfährt nie, dass 228 Standorte dahinterstehen."

Einsatz

Bereitstellen und aktualisieren. Alles auf einmal.

Ein-Klick-Bereitstellung für alle verknüpften Konten

Wählen Sie die Codebase-Gruppe aus und verteilen Sie Upgrades gleichzeitig an alle verknüpften Konten. Keine manuellen Rollouts. Keine Versionsabweichung. Keine verpassten Standorte.

Wenn Sie einen Fehler beheben oder eine neue Funktion hinzufügen, erhalten alle Kunden diese zur gleichen Zeit. Der Bereitstellungs-Workflow ist in die Plattform integriert - und nicht nachträglich hinzugefügt worden.

Die Verteilung erfolgt atomar. Entweder bekommen alle Konten das Update, oder keines. Das Rollback ist nur einen Klick entfernt. Sie können die Bereitstellung auch für eine Untergruppe von Konten vornehmen, bevor Sie das gesamte Netzwerk aktualisieren.

Benutzerverwaltung und Zugangskontrolle

Kontrollieren Sie, wer auf was in Ihrem gesamten APIANT-Server zugreifen kann. Weisen Sie Rollen zu, verwalten Sie Berechtigungen und sorgen Sie für Sicherheit in Ihrem gesamten Account-Netzwerk. Jedes Teammitglied sieht nur das, was es sehen muss.

Rollenbasierter Zugriff

Weisen Sie den Teammitgliedern Rollen zu - Administratoren, Ersteller, Betrachter. Jede Rolle definiert, welche Aktionen ein Benutzer durchführen kann und auf welche Konten er im Netzwerk zugreifen kann.

Berechtigungen auf Kontoebene

Gewährung des Zugriffs auf bestimmte untergeordnete Konten, ohne das gesamte Netzwerk freizugeben. Ein Regionalleiter sieht seine 30 Standorte. Der Hauptadministrator sieht alle 228.

Überwachung

Wenn Standort 150 meldet, dass etwas nicht in Ordnung ist, antworten Sie in Sekundenschnelle

Die Unterstützung von Integrationen in großem Umfang bedeutet, dass Fragen schnell beantwortet werden müssen. APIANT bietet Ihnen einen vollständigen Einblick in jede Automatisierung, jeden Datenfluss und jeden API-Aufruf. Durchsuchen Sie beliebige Daten - eine Kunden-ID, eine E-Mail, eine Datensatznummer - und sehen Sie sofort jeden Schritt, den sie durchlaufen haben, jede Transformation, jede API-Antwort. Kein Log-Diving. Kein Rätselraten.

Integration der Unternehmensüberwachung

Bei Unternehmensimplementierungen können Sie eine Verbindung zu Splunk, Datadog oder einem anderen Überwachungstool herstellen, um Dashboards in Echtzeit zu erstellen, die den API-Durchsatz, die Fehlerraten und die Einhaltung von Grenzwerten anzeigen.

Sehen Sie genau, wie viele API-Aufrufe pro Sekunde durch jede Verbindung fließen, welche Automatisierungen ausgeführt werden und ob sie sich den Ratengrenzen nähern - und das alles mit den Überwachungstools, die Ihr Betriebsteam bereits verwendet.
