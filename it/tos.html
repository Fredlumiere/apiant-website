Benvenuti in APIANT. APIANT è la nostra piattaforma proprietaria di integrazione cloud (la "Piattaforma") che consente a individui e aziende di fare di più e lavorare di meno collegando le proprie applicazioni e automatizzando il proprio carico di lavoro. APIANT, Inc. ("APIANT") offre ai clienti, direttamente e tramite il sito web e i domini associati di https://www.apiant.com (il "Sito"), i prodotti e i servizi relativi alla Piattaforma elencati su https://apiant.com (poiché tale elenco può essere aggiornato, modificato o altrimenti cambiato di volta in volta, i "Servizi in abbonamento").

Le presenti Condizioni di servizio di APIANT (le "Condizioni APIANT"), unitamente a eventuali Condizioni specifiche del Servizio applicabili (collettivamente, il "Contratto"), illustrano gli obblighi dell'Utente nei confronti di APIANT, per conto proprio o della propria organizzazione (di seguito, il "Cliente"), e gli obblighi di APIANT nei confronti del Cliente in relazione alla fornitura da parte di APIANT e all'utilizzo da parte del Cliente della Piattaforma e dei Servizi. Il Contratto è un accordo legalmente vincolante tra il Cliente e APIANT; si prega di leggerlo attentamente e di conservarne una copia per i propri archivi.

Cliccando sul pulsante "Crea account", il Cliente accetta, a partire da tale data (la "Data di efficacia"), di essere vincolato dal Contratto. 1. Informazioni sulla piattaforma

La Piattaforma automatizza il flusso di lavoro tra determinate applicazioni e servizi di terze parti indipendenti, sia basati sul web che offline ("Applicazioni di terze parti"), facendo sì che l'esecuzione di comandi ("Attività") all'interno di tali Applicazioni di terze parti venga attivata dalla modifica dei Dati dell'Utente (qualsiasi combinazione di tali Attività, un'"Automazione"). Oltre alle Attività pre-programmate per ciascuna Applicazione di terze parti, la Piattaforma contiene uno strumento di editing di assembly per l'integrazione API (l'"Editor di assembly") che può essere utilizzato per sviluppare Attività nuove e personalizzate.

1A. Infrastruttura del server MCP

La Piattaforma include la possibilità per il Cliente di implementare server compatibili con il Model Context Protocol ("MCP") sull'infrastruttura APIANT dedicata del Cliente, inclusi i server e i nomi di dominio del Cliente (collettivamente, "Infrastruttura Server MCP"). L'Infrastruttura Server MCP è una componente dei Servizi ed è soggetta ai termini del presente Contratto. Per quanto riguarda l'utilizzo dell'Infrastruttura Server MCP da parte del Cliente:

(i) Il server MCP del Cliente è distribuito sull'infrastruttura APIANT dedicata del Cliente. Gli utenti finali del server MCP del Cliente si connettono al server del Cliente, non direttamente ad APIANT;

(ii) Il Cliente è l'unico responsabile del rapporto con i suoi utenti finali, comprese le condizioni di servizio, le politiche sulla privacy e le informative sulla gestione dei dati applicabili agli utenti finali che si connettono al server MCP del Cliente tramite piattaforme di intelligenza artificiale (ciascuna, una "Piattaforma di intelligenza artificiale");

(iii) Il Cliente riconosce che i dati trasmessi tra una Piattaforma AI e il server MCP del Cliente attraversano l'infrastruttura del fornitore della Piattaforma AI e sono soggetti alle pratiche di gestione dei dati di tale fornitore, sulle quali né il Cliente né APIANT hanno alcun controllo;

(iv) Il Cliente è l'unico responsabile di garantire che il suo utilizzo dell'infrastruttura del server MCP e i dati elaborati tramite il server MCP del Cliente siano conformi a tutte le leggi, norme e regolamenti applicabili, comprese le leggi sulla privacy; e

(v) Tutti gli altri termini del presente Contratto, inclusi, a titolo esemplificativo ma non esaustivo, le restrizioni d'uso (Sezione 10), la proprietà intellettuale (Sezioni 11 e 12), le esclusioni di responsabilità (Sezione 17) e le limitazioni di responsabilità (Sezione 19), si applicano integralmente all'utilizzo da parte del Cliente dell'infrastruttura server MCP.

Tutti i corrispettivi devono essere pagati in dollari statunitensi e sono al netto di imposte applicabili quali imposte sulle vendite, accise, imposte sull'utilizzo o imposte simili. Il cliente è responsabile del pagamento di tutte le imposte applicabili, direttamente o ad APIANT, come previsto dalla legge.

In caso di ritardo nel pagamento, si applica la seguente politica:

Livello 1 (ritardo di 1 settimana): Verrà applicata una penale per ritardato pagamento pari al 5% dell'importo della fattura non pagata.

Livello 2 (ritardo di 2 settimane): Verrà applicata una penale di mora pari al 10% dell'importo della fattura non pagata (per un totale cumulativo del 15%) e l'accesso alla piattaforma APIANT verrà temporaneamente sospeso fino al completo pagamento del saldo dovuto, incluse tutte le penali di mora.

Inoltre, APIANT può aumentare le tariffe associate a qualsiasi termine specifico del servizio al momento del rinnovo di non più del cinque percento (5%) o della variazione percentuale effettiva dell'indice dei prezzi al consumo statunitense durante il periodo precedente, a seconda di quale dei due valori sia maggiore. APIANT farà il possibile per fornire un preavviso ragionevole di tali aumenti delle tariffe.
