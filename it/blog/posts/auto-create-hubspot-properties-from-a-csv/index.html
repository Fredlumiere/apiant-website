Creazione automatica di proprietà HubSpot da un file CSV con Claude Code

Fred Lumiere 18 settembre 2024 3 minuti di lettura
#HubSpot

Come creare automaticamente proprietà HubSpot (contatto, trattativa o azienda) utilizzando questo strumento gratuito di automazione dell'importazione basato su APIANT.

Pubblico di destinazione: amministratori di HubSpot

Procedura per creare automaticamente proprietà HubSpot da un file CSV con un account APIANT gratuito per amministratori HubSpot.

Per prima cosa avrai bisogno di un account APIANT…

Sei un amministratore HubSpot e desideri un account APIANT gratuito per amministratori HubSpot? In tal caso, puoi inviare la tua richiesta qui sotto:

Nome di battesimo*

Cognome*

Titolo professionale*

E-mail*

Numero di cellulare*

Nome dell'azienda*

Soluzioni mirate

Quindi copia e modifica questo foglio Google

Ecco il link al foglio Google.

Aggiungi tutte le righe che desideri.

Seleziona l'oggetto HubSpot per il quale desideri creare le proprietà:

  • Contatto
  • Affare
  • Azienda

Assegna un nome al gruppo di proprietà

Puoi sempre elencare una proprietà e scegliere "No" per ignorarla temporaneamente quando crei una proprietà personalizzata in HubSpot.

Scegli il nome visualizzato, il nome API

Seleziona la tipologia di immobile dal menu a tendina:

  • Selettore di date
  • Data e ora
  • Selezione a discesa
  • Testo su più righe
  • Selezione multipla
  • Campo di pianificazione
  • Testo su una sola riga
  • Casella di controllo singola on/off
  • HubSpot nativo

Infine, inserisci la descrizione della tua proprietà.

Una volta inserite tutte le righe (una per ogni proprietà), scarica il foglio in formato CSV:

Installa l'automazione del modello nel tuo account APIANT

Ecco il collegamento al modello chiamato Crea proprietà personalizzate di HubSpot da un file CSV

Una volta installato, collega un HubSpot Hub dal menu

Scegli l'app pubblica del sistema e accedi all'Hub

Attiva l'automazione

Premi il pulsante play per l'automazione poiché questo è un Applicazione per moduli grilletto basato

Fai clic per caricare il tuo file CSV

Le tue proprietà verranno create automaticamente e verrà generato un report.

Sentitevi liberi di modificare l'automazione a vostro piacimento (potreste anche aggiungere valori ai menu a tendina e alle selezioni multiple).
