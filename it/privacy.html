INFORMATIVA SULLA PRIVACY

Ultimo aggiornamento: 9 aprile 2026

La presente Informativa sulla privacy di Apiant, Inc. ("noi", "ci" o "nostro") descrive come e perché potremmo accedere, raccogliere, archiviare, utilizzare e/o condividere ("elaborare") le tue informazioni personali quando utilizzi i nostri servizi ("Servizi"), incluso quando:

  • Visita il nostro sito web all'indirizzo https://apiant.como qualsiasi nostro sito web che rimandi alla presente Informativa sulla privacy

  • Implementa server MCP (Model Context Protocol) basati sulla piattaforma APIANT sulla tua infrastruttura dedicata.
  • Interagisci con noi in altri modi correlati, inclusi vendite, marketing o eventi.

Domande o dubbi? La lettura di questa Informativa sulla privacy ti aiuterà a comprendere i tuoi diritti e le tue scelte in materia di privacy. Siamo responsabili delle decisioni relative al trattamento dei tuoi dati personali. Se non accetti le nostre politiche e pratiche, ti preghiamo di non utilizzare i nostri Servizi. Se hai ancora domande o dubbi, contattaci all'indirizzo privacy@apiant.com.

3. INFRASTRUTTURA DEL SERVER MCP

In breve: APIANT fornisce un'infrastruttura server MCP (Model Context Protocol) che i nostri clienti implementano sui propri server e domini dedicati. Quando i vostri dati vengono elaborati tramite il server MCP di un cliente basato su APIANT, elaboriamo solo i dati necessari per eseguire le azioni richieste. Non utilizziamo i dati di interazione MCP per addestrare modelli di intelligenza artificiale, pubblicare annunci pubblicitari o creare profili utente.

Come funzionano i server APIANT MCP

APIANT consente ai suoi clienti ("sviluppatori") di implementare server compatibili con MCP sulla propria infrastruttura e sui propri domini dedicati. Questi server MCP permettono agli utenti finali dello sviluppatore di interagire con le integrazioni e le automazioni dello sviluppatore tramite piattaforme di intelligenza artificiale (come Claude di Anthropic) utilizzando il linguaggio naturale. Quando un utente finale si connette al server MCP di uno sviluppatore, la piattaforma di intelligenza artificiale invia richieste di chiamata degli strumenti al server dello sviluppatore basato su APIANT. APIANT fornisce l'infrastruttura di piattaforma sottostante; gli utenti finali si connettono al server dello sviluppatore, non direttamente ad APIANT.

Quali dati vengono elaborati tramite i server MCP?

Quando i dati vengono elaborati tramite un server MCP basato su APIANT, possono essere coinvolte le seguenti categorie di dati:

  • Credenziali di autenticazione: Token OAuth 2.0 o altre credenziali utilizzate per verificare l'identità e autorizzare l'accesso al server del costruttore.
  • Parametri di chiamata dello strumento: Gli input specifici necessari per eseguire ciascuna azione richiesta (ad esempio, nomi di applicazioni, configurazioni di flussi di lavoro o query di ricerca).
  • Risposte alle chiamate agli strumenti: I risultati restituiti dal server del costruttore in risposta alle richieste vengono ritrasmessi alla piattaforma di intelligenza artificiale per essere visualizzati all'utente finale.

APIANT lo fa non Ricevi il testo completo delle conversazioni tra gli utenti finali e le piattaforme di intelligenza artificiale. Solo i dati strutturati relativi alle chiamate agli strumenti, necessari per eseguire azioni specifiche, vengono elaborati sul server del creatore basato su APIANT.

Come utilizziamo i dati MCP

APIANT, in qualità di fornitore dell'infrastruttura della piattaforma, utilizza i dati elaborati tramite i server MCP esclusivamente per:

  • Fornire e gestire l'infrastruttura della piattaforma per conto del costruttore
  • Monitorare le prestazioni del server, il tempo di attività e i tassi di errore.
  • Risolvere i problemi e migliorare l'affidabilità dell'infrastruttura del server MCP.
  • Rispettare gli obblighi di legge applicabili

Come memorizziamo e conserviamo i dati MCP

  • Token di autenticazione vengono mantenuti in memoria per la durata della sessione e non vengono conservati dopo la disconnessione.
  • Registri delle chiamate degli strumenti I parametri e le risposte possono essere conservati per un periodo limitato a fini di debug e operativi. Questi registri vengono eliminati entro 90 giorni, a meno che la legge non preveda un periodo di conservazione più lungo.
  • Nessun profilo utente sono costruiti a partire dai dati di interazione MCP.

Cosa NON facciamo con i dati MCP

  • Noi lo facciamo non Utilizza i dati di interazione MCP per addestrare qualsiasi modello di intelligenza artificiale o di apprendimento automatico.
  • Noi lo facciamo non vendere i dati di interazione con MCP a terze parti.
  • Noi lo facciamo non Utilizzare i dati di interazione con MCP per scopi pubblicitari, di profilazione o di marketing.
  • Noi lo facciamo non Condividere i dati di interazione con MCP con terze parti, salvo quanto necessario per fornire i Servizi o come richiesto dalla legge.

I tuoi diritti relativi ai dati MCP

Se sei un utente finale di un server MCP di un costruttore basato su APIANT, contatta direttamente il costruttore in merito ai tuoi diritti sui dati. Se sei un cliente APIANT (costruttore), puoi richiedere l'accesso, la correzione o la cancellazione di qualsiasi dato personale elaborato tramite la tua infrastruttura server MCP contattandoci all'indirizzo privacy@apiant.com. Vedere "QUALI SONO I TUOI DIRITTI IN MATERIA DI PRIVACY?" di seguito per ulteriori dettagli.

4. SU QUALI BASI GIURIDICHE CI BASIAMO PER IL TRATTAMENTO DEI VOSTRI DATI PERSONALI?

In sintesi: trattiamo i tuoi dati personali solo quando riteniamo che sia necessario e abbiamo una valida base giuridica per farlo, come ad esempio con il tuo consenso, per ottemperare alle leggi, per fornirti i servizi richiesti, per stipulare o adempiere ai nostri obblighi contrattuali, per tutelare i tuoi diritti o per perseguire i nostri legittimi interessi commerciali.

Se risiedi nell'UE o nel Regno Unito, questa sezione ti riguarda.

Il Regolamento generale sulla protezione dei dati (GDPR) e il GDPR del Regno Unito ci impongono di spiegare le basi giuridiche valide su cui ci basiamo per il trattamento dei vostri dati personali. Pertanto, potremmo basarci sulle seguenti basi giuridiche per il trattamento dei vostri dati personali:

  • Consenso. Potremmo trattare le tue informazioni se ci hai dato il permesso (ovvero il consenso) di utilizzare i tuoi dati personali per uno scopo specifico. Puoi revocare il tuo consenso in qualsiasi momento. Scopri di più revoca del consenso.
  • Esecuzione di un contratto. Potremmo trattare i vostri dati personali quando riteniamo che sia necessario per adempiere ai nostri obblighi contrattuali nei vostri confronti, inclusa la fornitura dei nostri Servizi, oppure su vostra richiesta prima della stipula di un contratto con voi.
  • Interessi legittimi. Potremmo trattare le tue informazioni quando riteniamo che sia ragionevolmente necessario per perseguire i nostri legittimi interessi commerciali e tali interessi non prevalgano sui tuoi interessi, diritti e libertà fondamentali. Ad esempio, potremmo trattare i tuoi dati personali per alcune delle finalità descritte al fine di:
    • Inviare agli utenti informazioni su offerte speciali e sconti sui nostri prodotti e servizi
    • Sviluppiamo e visualizziamo contenuti pubblicitari personalizzati e pertinenti per i nostri utenti.
    • Analizzare come vengono utilizzati i nostri Servizi per poterli migliorare e coinvolgere e fidelizzare gli utenti.
    • Sostieni le nostre attività di marketing
    • Diagnosticare problemi e/o prevenire attività fraudolente
    • Comprendere come i nostri utenti utilizzano i nostri prodotti e servizi ci permette di migliorare l'esperienza utente.
  • Obblighi legali. Potremmo trattare i vostri dati laddove riteniamo sia necessario per adempiere ai nostri obblighi legali, ad esempio per collaborare con le forze dell'ordine o con un'agenzia di regolamentazione, per esercitare o difendere i nostri diritti legali o per divulgare i vostri dati come prova in controversie legali in cui siamo coinvolti.
  • Eventi vitali. Potremmo trattare i vostri dati laddove riteniamo sia necessario per proteggere i vostri interessi vitali o gli interessi vitali di terzi, ad esempio in situazioni che comportano potenziali minacce alla sicurezza di qualsiasi persona.

5. QUANDO E CON CHI CONDIVIDIAMO LE VOSTRE INFORMAZIONI PERSONALI?

In sintesi: potremmo condividere le informazioni in situazioni specifiche descritte in questa sezione e/o con le seguenti terze parti.

Fornitori, consulenti e altri fornitori di servizi terzi. Potremmo condividere i vostri dati con fornitori, prestatori di servizi, appaltatori o agenti terzi ("terze parti") che svolgono servizi per nostro conto e necessitano di accedere a tali informazioni per svolgere il proprio lavoro. Abbiamo stipulato contratti con le nostre terze parti, progettati per contribuire a proteggere le vostre informazioni personali. Ciò significa che non possono fare nulla con le vostre informazioni personali se non abbiamo dato loro istruzioni in tal senso. Inoltre, non condivideranno le vostre informazioni personali con alcuna organizzazione al di fuori della nostra. Si impegnano inoltre a proteggere i dati che detengono per nostro conto e a conservarli per il periodo da noi indicato.

Le terze parti con cui potremmo condividere le informazioni personali sono le seguenti:

  • Servizi di cloud computing: Amazon Web Services (AWS)
  • Fatturazione e pagamenti: Ricorrentemente
  • Analisi web e mobile: Google Analytics, Smartlook
  • Pubblicità, marketing diretto e generazione di lead: Lemlist, HubSpot CRM
  • Comunica e chatta con gli utenti: Email di HubSpot
  • Backup e sicurezza dei dati: Backup su Google Drive, Amazon Glacier
  • Ottimizzazione delle funzionalità e delle infrastrutture: Amazon Web Services, Splunk
  • Monitoraggio delle prestazioni del sito web: Splunk MINT Express

Potremmo inoltre dover condividere le tue informazioni personali nelle seguenti situazioni:

  • Trasferimenti aziendali. Potremmo condividere o trasferire le tue informazioni in relazione a, o durante le negoziazioni di, qualsiasi fusione, vendita di beni aziendali, finanziamento o acquisizione di tutta o parte della nostra attività da parte di un'altra società.
  • Partner commerciali. Potremmo condividere le tue informazioni con i nostri partner commerciali per offrirti determinati prodotti, servizi o promozioni.
  • Infrastruttura del server MCP. Quando i dati vengono elaborati tramite il server MCP di un cliente basato su APIANT, tali dati possono essere trasmessi da e verso piattaforme di intelligenza artificiale di terze parti e qualsiasi applicazione di terze parti a cui il cliente si è connesso tramite APIANT. Vedi Sezione 3 per maggiori dettagli.

6. UTILIZZIAMO COOKIE E ALTRE TECNOLOGIE DI TRACCIAMENTO?

In breve: potremmo utilizzare cookie e altre tecnologie di tracciamento per raccogliere e memorizzare le tue informazioni.

Potremmo utilizzare cookie e tecnologie di tracciamento simili (come web beacon e pixel) per raccogliere informazioni quando interagisci con i nostri Servizi. Alcune tecnologie di tracciamento online ci aiutano a mantenere la sicurezza dei nostri Servizi e del tuo account, a prevenire arresti anomali, a correggere bug, a salvare le tue preferenze e a supportare le funzioni di base del sito.

Consentiamo inoltre a terze parti e fornitori di servizi di utilizzare tecnologie di tracciamento online sui nostri Servizi per analisi e pubblicità, tra cui la gestione e la visualizzazione di annunci pubblicitari, la personalizzazione degli annunci in base ai tuoi interessi o l'invio di promemoria per i carrelli abbandonati (a seconda delle tue preferenze di comunicazione). Le terze parti e i fornitori di servizi utilizzano la loro tecnologia per fornire pubblicità su prodotti e servizi personalizzati in base ai tuoi interessi, che possono apparire sia sui nostri Servizi che su altri siti web.

Nella misura in cui queste tecnologie di tracciamento online sono considerate una "vendita"/"condivisione" (che include la pubblicità mirata, come definita dalle leggi applicabili) ai sensi delle leggi statali statunitensi applicabili, è possibile rinunciare a queste tecnologie di tracciamento online inviando una richiesta come descritto di seguito nella sezione "I residenti negli Stati Uniti godono di specifici diritti in materia di privacy?"

Informazioni specifiche su come utilizziamo tali tecnologie e su come puoi rifiutare determinati cookie sono riportate nella nostra Avviso sui cookie.

7. PER QUANTO TEMPO CONSERVIAMO LE VOSTRE INFORMAZIONI?

In breve: conserviamo le tue informazioni per il tempo necessario a raggiungere gli scopi indicati nella presente Informativa sulla privacy, salvo diversamente previsto dalla legge.

Conserveremo i vostri dati personali solo per il tempo necessario al raggiungimento delle finalità indicate nella presente Informativa sulla privacy, a meno che un periodo di conservazione più lungo non sia richiesto o consentito dalla legge (ad esempio, per motivi fiscali, contabili o altri obblighi di legge). Nessuna finalità indicata nella presente informativa richiederà la conservazione dei vostri dati personali per un periodo superiore a quello in cui gli utenti mantengono un account presso di noi.

Quando non avremo più una legittima necessità aziendale di trattare i vostri dati personali, provvederemo a cancellarli o ad anonimizzarli, oppure, se ciò non fosse possibile (ad esempio, perché i vostri dati personali sono stati archiviati in backup), li conserveremo in modo sicuro e li isoleremo da qualsiasi ulteriore trattamento fino a quando non sarà possibile cancellarli.

8. COME PROTEGGIAMO LE VOSTRE INFORMAZIONI?

11. CONTROLLI PER LE FUNZIONI "NON TRACCIARE"

La maggior parte dei browser web e alcuni sistemi operativi e applicazioni mobili includono una funzione o un'impostazione "Do-Not-Track" (DNT) che è possibile attivare per segnalare la propria preferenza in materia di privacy, ovvero di non voler che i dati relativi alle proprie attività di navigazione online vengano monitorati e raccolti. Al momento, non è stato ancora definito uno standard tecnologico uniforme per il riconoscimento e l'implementazione dei segnali DNT. Pertanto, attualmente non rispondiamo ai segnali DNT dei browser né ad altri meccanismi che comunicano automaticamente la scelta di non essere tracciati online. Qualora in futuro venisse adottato uno standard per il tracciamento online che siamo tenuti a rispettare, vi informeremo di tale pratica tramite una versione aggiornata della presente Informativa sulla privacy.

La legge californiana ci impone di informarvi su come rispondiamo ai segnali DNT (Do Not Track) dei browser web. Poiché al momento non esiste uno standard di settore o legale per il riconoscimento o il rispetto dei segnali DNT, non rispondiamo a essi.
