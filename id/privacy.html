3. INFRASTRUKTUR SERVER MCP

Singkatnya: APIANT menyediakan infrastruktur server MCP (Model Context Protocol) yang digunakan pelanggan kami pada server dan domain khusus mereka sendiri. Saat data Anda diproses melalui server MCP berbasis APIANT milik pelanggan, kami hanya memproses data yang diperlukan untuk menjalankan tindakan yang diminta. Kami tidak menggunakan data interaksi MCP untuk melatih model AI, menayangkan iklan, atau membangun profil pengguna.

Cara kerja server APIANT MCP

APIANT memungkinkan pelanggannya ("pengembang") untuk menerapkan server yang kompatibel dengan MCP pada infrastruktur dan domain khusus mereka sendiri. Server MCP ini memungkinkan pengguna akhir pengembang untuk berinteraksi dengan integrasi dan otomatisasi pengembang melalui platform AI (seperti Claude dari Anthropic) menggunakan bahasa alami. Ketika pengguna akhir terhubung ke server MCP pengembang, platform AI mengirimkan permintaan panggilan alat ke server yang didukung APIANT milik pengembang. APIANT menyediakan infrastruktur platform yang mendasarinya; pengguna akhir terhubung ke server pengembang, bukan langsung ke APIANT.

Data apa yang diproses melalui server MCP?

Saat data diproses melalui server MCP yang didukung APIANT, kategori data berikut mungkin terlibat:

  • Kredensial autentikasi: Token OAuth 2.0 atau kredensial lain yang digunakan untuk memverifikasi identitas dan mengotorisasi akses ke server pengembang.
  • Parameter panggilan alat: Input spesifik yang diperlukan untuk menjalankan setiap tindakan yang diminta (misalnya, nama aplikasi, konfigurasi alur kerja, atau kueri pencarian).
  • Respons panggilan alat: Hasil yang dikembalikan oleh server pembuat situs web sebagai respons terhadap permintaan, yang kemudian diteruskan kembali ke platform AI untuk ditampilkan kepada pengguna akhir.

APIANT melakukan bukan Menerima teks lengkap percakapan antara pengguna akhir dan platform AI. Hanya data panggilan alat terstruktur yang diperlukan untuk menjalankan tindakan spesifik yang diproses di server berbasis APIANT milik pengembang.

Bagaimana kami menggunakan data MCP

APIANT, sebagai penyedia infrastruktur platform, menggunakan data yang diproses melalui server MCP semata-mata untuk:

  • Menyediakan dan mengoperasikan infrastruktur Platform atas nama pengembang.
  • Pantau kinerja server, waktu aktif, dan tingkat kesalahan.
  • Memperbaiki masalah dan meningkatkan keandalan infrastruktur server MCP.
  • Mematuhi kewajiban hukum yang berlaku

Bagaimana kami menyimpan dan mempertahankan data MCP

  • Token otentikasi Data tersebut disimpan dalam memori selama sesi berlangsung dan tidak akan tersimpan setelah koneksi terputus.
  • Catatan panggilan alat (Parameter dan respons) dapat disimpan untuk jangka waktu terbatas untuk keperluan debugging dan operasional. Log ini akan dihapus dalam waktu 90 hari kecuali jika periode penyimpanan yang lebih lama diwajibkan oleh hukum.
  • Tidak ada profil pengguna dibangun dari data interaksi MCP.

Apa yang TIDAK kami lakukan dengan data MCP

  • Kami melakukannya bukan Gunakan data interaksi MCP untuk melatih model AI atau pembelajaran mesin apa pun.
  • Kami melakukannya bukan menjual data interaksi MCP kepada pihak ketiga.
  • Kami melakukannya bukan menggunakan data interaksi MCP untuk tujuan periklanan, pembuatan profil, atau pemasaran.
  • Kami melakukannya bukan Membagikan data interaksi MCP dengan pihak ketiga kecuali jika diperlukan untuk menyediakan Layanan atau sebagaimana diwajibkan oleh hukum.

Hak Anda terkait data MCP
