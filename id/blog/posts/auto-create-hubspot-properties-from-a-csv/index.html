Buat properti HubSpot secara otomatis dari file CSV.

Fred Lumiere 18 September 2024 Waktu baca 3 menit
#HubSpot

Cara membuat properti HubSpot (kontak, kesepakatan, atau perusahaan) secara otomatis menggunakan otomatisasi impor gratis ini yang dibangun di atas APIANT.

Target Audiens: Admin HubSpot

Langkah-langkah untuk membuat properti HubSpot secara otomatis dengan file CSV menggunakan akun APIANT gratis untuk admin HubSpot.

Pertama-tama, Anda memerlukan akun APIANT…

Apakah Anda seorang Admin HubSpot dan ingin mendapatkan akun APIANT gratis untuk Admin HubSpot? Jika ya, Anda dapat mengirimkan aplikasi di bawah ini:

Nama depan*

Nama Belakang*

Judul Pekerjaan*

E-mail*

Nomor Ponsel*

Nama perusahaan*

Solusi target

Kemudian salin dan edit Google Sheet ini.

Ini dia tautan ke Google Sheet.

Tambahkan baris sebanyak yang Anda inginkan.

Pilih objek HubSpot yang ingin Anda buat propertinya:

  • Kontak
  • Kesepakatan
  • Perusahaan

Berikan nama grup properti

Anda selalu dapat mendaftarkan properti dan memilih "Tidak" untuk membuat properti khusus di HubSpot agar properti tersebut diabaikan untuk sementara waktu.

Pilih nama tampilan, nama API

Pilih jenis properti dari menu tarik-turun:

  • Pemilih tanggal
  • Tanggal dan waktu
  • Pilih menu tarik-turun
  • Teks multi-baris
  • Pilih beberapa
  • Bidang angka
  • Teks satu baris
  • Kotak centang tunggal untuk mengaktifkan/menonaktifkan
  • HubSpot asli

Terakhir, masukkan deskripsi properti Anda.

Setelah Anda memasukkan semua baris (satu baris per properti), unduh lembar kerja tersebut sebagai file CSV:

Instal otomatisasi template di akun APIANT Anda.

Ini dia link ke templat yang disebut Buat properti kustom HubSpot dari CSV

Setelah terinstal, hubungkan HubSpot Hub dari menu.

Pilih Aplikasi Publik Sistem, dan masuk ke Hub.

Aktifkan otomatisasi

Tekan tombol putar untuk otomatisasi karena ini adalah Formulir Aplikasi pemicu berbasis

Klik untuk mengunggah file CSV Anda

Properti Anda akan dibuat secara otomatis dan laporan akan dihasilkan.

Anda bebas mengedit otomatisasi sesuai keinginan (Anda bahkan dapat menambahkan nilai ke menu tarik-turun dan pilihan ganda).

Kunjungi forum.apiant.com untuk berbagi pengalaman dan saling membantu.
