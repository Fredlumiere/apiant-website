Fred Lumiere 17 Maret 2024 Waktu baca 14 menit

Pelajari cara mudah membuat Kartu CRM HubSpot yang disesuaikan tanpa perlu coding dengan APIANT.

Target Audiens: Admin HubSpot

Memahami Kartu CRM HubSpot

Kartu HubSpot CRM adalah alat dinamis yang meningkatkan alur kerja Anda dengan menyediakan akses cepat ke informasi dan interaksi penting dari berbagai sumber, langsung di dalam HubSpot. Dirancang untuk terintegrasi secara mulus dengan aplikasi eksternal dan ekosistem HubSpot yang lebih luas, kartu-kartu ini memungkinkan pengguna untuk melihat data penting seperti tiket dukungan, informasi penagihan, atau wawasan aplikasi khusus tanpa meninggalkan CRM mereka. Pada dasarnya, kartu-kartu ini berinteraksi dengan API.

Pada tutorial ini, kita akan membuat Kartu CRM yang mengambil informasi cuaca untuk kontak Anda dan menautkan ke peta cuaca menggunakan OpenWeatherMap.org API.

Membuat Aplikasi Publik HubSpot Anda Sendiri

Sebelum Anda dapat membuat kartu CRM khusus, Anda perlu... Buat aplikasi publik HubSpot Anda sendiriAnda tidak perlu mencantumkannya secara publik jika tidak mau, tetapi Anda bisa! 🤑 Ini akan memungkinkan Anda untuk menghubungkan HubSpot Hub klien Anda ke platform APIANT.

Untuk membuat aplikasi publik Anda sendiri, ikuti langkah-langkah sederhana berikut:

Jika Anda belum memiliki akun pengembang HubSpot, buatlah satu di sini. pengembang.hubspot.com

Anda ingin membuat sebuah Aplikasi:

Klik Kelola Aplikasi

Klik Buat Aplikasi di pojok kanan atas.

Beri nama aplikasi, deskripsi, dan logo jika Anda mau, lalu klik Otorisasi.

Masukkan URL Pengalihan Anda. Jika Anda menggunakan paket HubSpot Admin Free atau HubSpot Admin Pro di APIANT, Anda dapat memasukkan apiant.com/oauth. Jika Anda menggunakan paket tenant atau dedicated, masukkan URL server Anda. Jika Anda tidak mengetahuinya, masukkan nama domain Anda untuk sementara, dan sistem akan memberi tahu Anda saat Anda menghubungkan aplikasi ke server APIANT, di mana Anda dapat kembali dan memasukkannya.

Masukkan Cakupan Anda. Akun APIANT Anda memungkinkan Anda melakukan lebih dari sekadar Kartu CRM! (Seperti membangun Aplikasi API lengkap). Jadi, berikut adalah cakupan (lihat di bawah) yang kami rekomendasikan berdasarkan 24 pemicu dan 73 tindakan Saat ini kami memiliki yang tersedia (per tanggal 17 Maret 2024).

Cakupan (scopes) menentukan izin yang dimiliki aplikasi Anda untuk mengakses data atau melakukan tindakan di HubSpot. Orang yang menginstal aplikasi Anda harus menyetujui cakupan yang diminta. Sangat disarankan untuk meminta sesedikit mungkin cakupan agar aplikasi Anda dapat berfungsi dengan baik.

Simpan aplikasi Anda di bagian bawah layar:

Membuat Kartu CRM di Aplikasi Publik Anda

Setelah aplikasi publik HubSpot Anda siap, sekarang saatnya membuat kartu CRM. Ini akan menentukan tata letak dan konten kartu Anda.

Klik Buat Kartu CRM

Masukkan Nama Kartu CRM Anda. Kami akan menamainya Cuaca. Ini akan menjadi catatan Kontak, dan kami hanya akan mengirimkan hs_object_id catatan kontak dari HubSpot ke akun APIANT Anda.

Tempelkan URL Layanan Web Anda dari otomatisasi APIANT Anda di URL pengambilan data.

Klik pada Properti kartu dan masukkan properti ini dengan mengklik Tambah properti:

Max memastikan untuk mencocokkan tipe properti untuk masing-masing seperti yang terlihat di atas.

Yang kita miliki sekarang dalam otomatisasi hanyalah pemicu (Layanan Web):

Untuk contoh kita, sekarang kita perlu menambahkan hal berikut untuk menerima data dari HubSpot, mengambil data dari API openweathermap, dan mengembalikannya semua ke HubSpot:

  1. Ambil kontak dari HubSpot untuk mendapatkan Kode Pos.

  2. Konversikan Kode Pos ke Kode Geografis dengan OpenWeatherMap.

  3. Dapatkan kondisi cuaca terkini dari OpenWeatherMap berdasarkan Geocode.

  4. Isi properti Kartu CRM dengan data openweathermap.

  5. Buat opsi menu untuk Kartu CRM agar terhubung ke peta cuaca.

  6. Kembalikan JSON ke Kartu CRM HubSpot
