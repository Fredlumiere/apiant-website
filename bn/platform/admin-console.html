অ্যাকাউন্ট নেটওয়ার্কs

একটি মূল অ্যাকাউন্ট। শত শত উপ-অ্যাকাউন্ট।

একটি মাস্টার অ্যাকাউন্ট যার অধীনে ২৩২টি চাইল্ড অ্যাকাউন্ট রয়েছে, এবং প্রতিটি অ্যাকাউন্ট একটি নির্দিষ্ট স্থানের প্রতিনিধিত্ব করে। নতুন স্থানগুলো নেটওয়ার্কে যুক্ত হওয়ার সাথে সাথেই শেয়ার করা সংযোগ এবং সেটিংস পেয়ে যায়। এভাবেই ‘দ্য এক্সারসাইজ কোচ’ তাদের সমগ্র ফ্র্যাঞ্চাইজি জুড়ে মাইন্ডবডি ইন্টিগ্রেশনগুলো একটিমাত্র কন্ট্রোল প্লেন থেকে পরিচালনা করে।

জটিলতা ছাড়াই পরিমাপ করুন

Each চাইল্ড অ্যাকাউন্ট operates independently with its own source system connection (for example, its own MindBody site), but shares centrally managed resources like CRM connections and অটোমেশন codebases.

When a ফ্র্যাঞ্চাইজ adds five new লোকেশনs, those লোকেশনs get added to the অ্যাকাউন্ট নেটওয়ার্ক and immediately inherit shared connections, সেটিংস, and অটোমেশনs. No manual setup per লোকেশন.

সংযোগ ভাগাভাগি

একটি সংযোগ। প্রতিটি ঠিকানা।

‘চাইল্ড অ্যাকাউন্টের সাথে শেয়ার করুন’ টগলটির অর্থ হলো, একটিমাত্র CRM কানেকশন সমস্ত লোকেশন জুড়ে শেয়ার করা হবে। আপনার ২৩২টি আলাদা CRM ক্রেডেনশিয়ালের প্রয়োজন নেই। প্রতিটি চাইল্ড অ্যাকাউন্টের নিজস্ব সোর্স সিস্টেম কানেকশন থাকে (উদাহরণস্বরূপ, তার নিজস্ব MindBody সাইট), কিন্তু তারা CRM-টি শেয়ার করে।

যেখানে প্রয়োজন, সেখানে ভাগ করে নেওয়া। যেখানে বিচ্ছিন্ন থাকা আবশ্যক, সেখানে বিচ্ছিন্ন রাখা।

Some connections need to be shared -- your CRM, your মনিটরিং tools, your notification systems. Others must be isolated -- each লোকেশন's source system credentials stay private to that চাইল্ড অ্যাকাউন্ট.

The Admin Console gives you toggle-level control over what is shared and what is not. No code. No কনফিগারেশন files. Just a switch.

প্ল্যাটফর্ম-Level রেট লিমিটিং. No Code Required.

সরাসরি অ্যাডমিন কনসোলে "প্রতি ১০ সেকেন্ডে ১৮৫টি এপিআই কল" সেট করুন। প্ল্যাটফর্মটি স্বয়ংক্রিয়ভাবে সমস্ত ২৩২টি লোকেশনে এটি প্রয়োগ করে — কোনো কোড, বাহ্যিক রেট লিমিটিং টুল বা লোকেশন-ভিত্তিক কনফিগারেশনের প্রয়োজন নেই।

একবার কনফিগার করুন। সর্বত্র কার্যকর।

Rate limits are configured per connection at the প্ল্যাটফর্ম level. Every অটোমেশন, across every account in the network, respects the limit স্বয়ংক্রিয়ভাবে. When an API partner tells you "185 calls per 10 seconds," you type that number once and the প্ল্যাটফর্ম handles the rest.

The প্ল্যাটফর্ম queues requests, distributes them evenly across the time window, and backs off gracefully when limits are approached. No 429 errors reaching your গ্রাহকs. No custom throttling code in your অটোমেশনs.

মাস্টার অ্যাকাউন্ট Routing

When data comes from the CRM and needs to go back to the correct source system, the মাস্টার অ্যাকাউন্ট dispatches to the proper চাইল্ড অ্যাকাউন্ট. The প্ল্যাটফর্ম handles routing স্বয়ংক্রিয়ভাবে -- no manual mapping, no lookup tables, no guessing which লোকেশন a record belongs to.

হাবস্পটে একটি কন্টাক্ট আপডেট আসে। মাস্টার অ্যাকাউন্টটি ওয়েবহুকটি গ্রহণ করে, লোকেশন ফিল্ডের উপর ভিত্তি করে কন্টাক্টটি কোন মাইন্ডবডি সাইটের অন্তর্গত তা শনাক্ত করে এবং আপডেটটি সঠিক চাইল্ড অ্যাকাউন্টে পাঠিয়ে দেয়। চাইল্ড অ্যাকাউন্টটি তার নিজস্ব মাইন্ডবডি ক্রেডেনশিয়াল ব্যবহার করে নিজস্ব অটোমেশনের মাধ্যমে এটি প্রসেস করে। কন্টাক্টটি কখনোই জানতে পারে না যে নেপথ্যে ২৩২টি লোকেশন রয়েছে।

One-Click ডিপ্লয়মেন্ট to All Linked Accounts

Select the codebase group, deploy upgrades to all linked accounts simultaneously. No manual rollouts. No version drift. No missed লোকেশনs.

When you fix a bug or add a feature, every গ্রাহক gets it at the same time. The ডিপ্লয়মেন্ট ওয়ার্কফ্লো is built into the প্ল্যাটফর্ম -- not bolted on as an afterthought.

ডিপ্লয়মেন্ট is atomic. Either all accounts get the update, or none do. Rollback is one click away. You can also deploy to a subset of accounts for staged rollouts before going network-wide.
